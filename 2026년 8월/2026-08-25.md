## 1. 딕셔너리 기본 구조

딕셔너리는 값을 순서나 위치가 아니라 **키(key)** 로 구분해서 저장하는 자료구조다.

```python
student = {
    "name": "민수",
    "age": 20,
    "score": 85
}
```

리스트가 `0`, `1`, `2` 같은 위치를 이용해 값을 찾는다면, 딕셔너리는 `name`, `age`, `score`처럼 의미 있는 이름으로 값을 찾을 수 있다.

```python
print(student["name"])
print(student["score"])
```

따라서 학생 정보나 상품 정보처럼 **한 대상이 여러 속성을 가지고 있을 때** 딕셔너리가 읽기 쉽다.

## 2. 딕셔너리 항목 추가와 수정

딕셔너리에서는 같은 대입 문법으로 항목을 추가하거나 수정한다.

```python
student["city"] = "서울"
student["score"] = 95
```

- 없는 키에 값을 넣으면 새 항목이 추가된다.
- 이미 존재하는 키에 값을 넣으면 기존 값이 수정된다.

즉, `딕셔너리[키] = 값`이라는 같은 문법이라도 현재 그 키가 존재하는지에 따라 추가 또는 수정으로 동작한다.

## 3. 딕셔너리 항목 삭제

항목을 삭제할 때는 `del`이나 `pop()`을 사용할 수 있다.

```python
del student["city"]
removed = student.pop("score")
```

`del`은 항목을 삭제하고, `pop()`은 항목을 삭제하면서 그 값을 반환한다.

## 4. 없는 키를 안전하게 처리하기

없는 키를 대괄호로 조회하면 `KeyError`가 발생한다.

```python
student["city"]
```

키가 없을 수도 있는 상황에서는 `get()`을 사용할 수 있다.

```python
student.get("city")
student.get("city", "정보 없음")
```

키 존재 여부를 먼저 확인하고 싶을 때는 `in`을 사용할 수 있다.

```python
if "score" in student:
    print(student["score"])
```

정리하면 다음과 같다.

- 반드시 있어야 하는 키 → `[]`
- 없을 수도 있는 키 → `get()`
- 먼저 존재 여부를 확인 → `in`

## 5. keys(), values(), items()

딕셔너리에 들어 있는 내용을 확인할 때 다음 메서드를 사용할 수 있다.

```python
student.keys()
student.values()
student.items()
```

- `keys()` : 키만 가져온다.
- `values()` : 값만 가져온다.
- `items()` : `(키, 값)` 쌍을 가져온다.

특히 `items()`는 반복문과 함께 많이 사용한다.

```python
for key, value in student.items():
    print(key, value)
```

한 번 반복할 때마다 `(키, 값)` 한 쌍이 나오고, 그것이 각각 `key`, `value` 변수에 저장된다.

## 6. 리스트와 딕셔너리 함께 사용하기

딕셔너리 하나는 한 명의 학생처럼 **한 대상**을 표현하기 좋고, 여러 명의 학생은 딕셔너리 여러 개를 리스트 안에 넣어 표현할 수 있다.

```python
students = [
    {"name": "민수", "score": 85},
    {"name": "지영", "score": 92},
    {"name": "서준", "score": 78}
]
```

```python
for student in students:
    print(student["name"], student["score"])
```

이 구조를 이용하면 조건문과 반복문을 함께 사용해 특정 학생만 찾을 수 있다.

예를 들어 점수가 80점 이상인 학생만 출력하는 방식으로 확장할 수 있다.

## 7. 중첩 딕셔너리

딕셔너리 안에 또 다른 딕셔너리를 넣을 수도 있다.

```python
student = {
    "name": "민수",
    "contact": {
        "email": "minsu@example.com",
        "phone": "010-1234-5678"
    }
}
```

안쪽 값을 가져올 때는 바깥 구조부터 한 단계씩 접근한다.

```python
student["contact"]["email"]
```

복잡한 구조에서 오류가 나면 한 번에 전체를 보려고 하기보다 중간 값을 직접 출력하면서 확인하는 것이 좋다.

```python
print(student.keys())
print(student["contact"])
print(student["contact"].keys())
```

## 8. 자료구조 선택 기준

지금까지 배운 주요 자료구조를 간단히 정리하면 다음과 같다.

- 리스트 `[]` : 순서가 있고 수정 가능
- 튜플 `()` : 순서가 있지만 요소를 직접 수정하지 않는 경우
- 집합 `{값}` : 중복 제거가 중요할 때
- 딕셔너리 `{키: 값}` : 값의 의미를 이름으로 표현하고 싶을 때

자료구조를 고를 때는 **순서가 중요한지, 수정이 필요한지, 중복 제거가 필요한지, 값에 의미 있는 이름이 필요한지**를 생각하면 된다.

# 이미지 알고리즘 퀴즈 정리

## 9. 이번 퀴즈에서 평가하는 것

이번 알고리즘 퀴즈는 정답 코드만 빠르게 작성하는 것이 목적이 아니다.

중요하게 보는 부분은 다음과 같다.

- 문제를 작은 단계로 나누는 능력
- 2차원 배열을 이해하고 다루는 능력
- 반복문, 조건문, 함수, 재귀 활용
- AI를 정답 생성기가 아니라 학습 도구로 사용하는 능력
- 오류 원인을 스스로 좁혀가는 과정
- 초보자에게 자신의 알고리즘을 설명하는 능력
- 테스트 케이스로 코드를 직접 검증하는 능력

즉, **정답보다 해결 과정과 설명이 중요한 과제**다.

## 10. AI 사용 규칙

ChatGPT, Claude, Gemini, Copilot 같은 생성형 AI 사용은 허용된다.

다만 완성된 정답 코드를 직접 요구하면 안 된다.

좋은 질문 방식은 한 번에 하나의 작은 개념만 질문하는 것이다.

예를 들면 다음과 같은 방식이다.

- 2차원 리스트에서 정사각형 영역을 확인하는 순서 질문
- 재귀 종료 조건의 의미 질문
- 정사각형을 4등분할 때 좌표를 계산하는 방법 질문
- 내가 작성한 조건문의 실행 순서 추적 요청
- 오류 메시지의 개념만 설명 요청

AI에게 답을 받아 그대로 사용하는 것이 아니라, **직접 생각 → 질문 → 실행 → 확인 → 기록**하는 흐름을 유지해야 한다.

## 13. 문제 1 - 흑백 이미지 압축

흑백 이미지를 `0`과 `1`로 표현한다.

- `0` : 흰색
- `1` : 검은색

정사각형 영역의 모든 값이 같으면 하나의 숫자로 압축한다.

- 모두 `0` → `0`
- 모두 `1` → `1`

0과 1이 섞여 있다면 영역을 정확히 네 부분으로 나눈다.

처리 순서는 반드시 다음과 같다.

1. 왼쪽 위
2. 오른쪽 위
3. 왼쪽 아래
4. 오른쪽 아래

그리고 각 영역을 같은 방법으로 다시 검사한다.

같은 작업을 작은 영역에서도 반복하기 때문에 **재귀**를 사용하는 문제다.

이 문제에서 특히 이해해야 할 것은 다음과 같다.

- 2차원 데이터에서 행과 열 접근하기
- 특정 정사각형 영역의 값이 모두 같은지 검사하기
- 영역을 4등분했을 때 시작 좌표 계산하기
- 재귀 함수의 종료 조건
- 네 영역을 정확한 순서로 처리하기

## 14. 문제 2 - 컬러 이미지를 흑백 이미지로 변환

컬러 이미지의 각 픽셀은 `(R, G, B)` 값으로 표현한다.

각 픽셀의 밝기는 다음 방식으로 계산한다.

```text
brightness = (R + G + B) // 3
```

모든 픽셀의 밝기를 계산한 뒤 전체 평균 밝기를 임계값으로 사용한다.

```text
threshold = 모든 픽셀 밝기의 합 // 전체 픽셀 수
```

그 다음 각 픽셀을 다음 규칙으로 흑백으로 변환한다.

- `brightness >= threshold` → `1`
- `brightness < threshold` → `0`

이 문제에서 이해해야 할 핵심은 다음과 같다.

- RGB 구조
- 문자열 `"255,0,0"`을 숫자로 분리하는 방법
- `split()` 사용
- 문자열을 정수로 변환하기
- 중첩 반복문
- 전체 밝기의 합과 평균 계산
- `//` 정수 나눗셈
- 결과를 원본과 같은 크기의 2차원 구조로 만드는 방법

## 오늘 배운 점

딕셔너리는 단순히 여러 값을 저장하는 자료구조가 아니라 **각 값에 의미 있는 이름을 붙여 데이터를 구조화하는 방법**이라는 점을 이해했다.

특히 `get()`, `in`, `items()`를 이용하면 없는 키를 안전하게 처리하거나 반복문과 연결해 실제 데이터를 다루기 쉬워진다.

알고리즘 문제에서는 코드를 바로 작성하는 것보다 먼저 문제를 작은 단계로 나누는 것이 중요하다. 이미지 전체를 한 번에 생각하면 복잡하지만, **한 영역 검사 → 같은 값인지 확인 → 필요하면 4등분 → 작은 영역에서 반복**처럼 나누면 이해하기 쉬워진다.

또한 AI를 사용할 때 완성 코드를 바로 받는 것보다 내가 현재 어디까지 이해했는지 설명하고 작은 질문을 반복하는 방식이 실제 학습에 더 도움이 된다는 점을 확인했다.
