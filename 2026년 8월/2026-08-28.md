# 2. NumPy - 숫자 데이터를 배열로 다루기

Python에는 리스트가 있지만 대량의 숫자 데이터를 계산할 때는 NumPy 배열을 많이 사용한다.

```python
import numpy as np

numbers = np.array([10, 20, 30, 40])
print(numbers)
```

NumPy 배열은 `ndarray`라고 부른다.

## 리스트와 NumPy 배열의 차이

Python 리스트에서는 다음 코드가 리스트 자체를 두 번 반복한다.

```python
numbers = [1, 2, 3]
print(numbers * 2)
```

결과:

```text
[1, 2, 3, 1, 2, 3]
```

반면 NumPy에서는 각 요소에 계산이 적용된다.

```python
numbers = np.array([1, 2, 3])
print(numbers * 2)
```

결과:

```text
[2 4 6]
```

즉 NumPy는 배열 전체에 연산을 한 번에 적용할 수 있다.

이를 **벡터화 연산(vectorized operation)**이라고 이해할 수 있다.

# 3. shape와 dtype 확인하기

데이터를 받으면 값만 보는 것이 아니라 배열의 구조와 자료형도 확인해야 한다.

```python
arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(arr.shape)
print(arr.dtype)
```

`shape`는 데이터의 모양을 알려 준다.

```text
(2, 3)
```

이는 다음을 의미한다.

```text
2개의 행
3개의 열
```

이미지 역시 컴퓨터에서는 숫자 배열이기 때문에 shape가 중요하다.

예를 들어 컬러 이미지의 배열은 보통 다음과 비슷한 구조를 가진다.

```text
(높이, 너비, 채널)
```

RGB 이미지라면 마지막 채널이 3인 경우가 많다.

```text
(512, 512, 3)
```

따라서 이미지 AI를 다룰 때도 결국 배열을 이해하는 것이 기본이 된다.

# 4. 인덱싱과 슬라이싱

NumPy 배열에서도 필요한 일부 데이터만 선택할 수 있다.

```python
arr = np.array([10, 20, 30, 40, 50])

print(arr[0])
print(arr[1:4])
```

2차원 배열에서는 행과 열을 함께 선택할 수 있다.

```python
arr = np.array([
    [10, 20, 30],
    [40, 50, 60],
    [70, 80, 90]
])

print(arr[0, 1])
print(arr[:, 0])
```

`arr[:, 0]`은 모든 행에서 첫 번째 열을 선택한다.

이런 방식은 이미지의 일부 영역이나 표 데이터의 특정 열을 선택할 때도 활용된다.

# 5. Pandas - 표 형태의 데이터를 다루기

Pandas에서는 표 형태 데이터를 `DataFrame`으로 다룬다.

```python
import pandas as pd

data = {
    "name": ["A", "B", "C"],
    "score": [80, 95, 70],
    "passed": [True, True, True]
}

df = pd.DataFrame(data)
print(df)
```

DataFrame을 간단히 생각하면 다음과 같다.

```text
엑셀 표와 비슷한 구조

행(row)    → 하나의 데이터
열(column) → 데이터의 속성
```

예를 들어 학생 데이터라면 한 행은 한 학생을 의미하고, `name`, `score` 등의 열은 학생의 속성을 의미한다.

# 6. DataFrame을 받으면 먼저 확인할 것

데이터를 처음 받았을 때 바로 계산부터 하기보다 구조를 먼저 확인하는 습관이 중요하다.

대표적으로 다음 내용을 확인할 수 있다.

```python
print(df.head())
print(df.shape)
print(df.columns)
print(df.info())
print(df.describe())
```

각각의 목적은 다음과 같다.

```text
head()      → 앞부분 데이터 확인
shape       → 행과 열 개수 확인
columns     → 열 이름 확인
info()      → 자료형과 결측치 여부 확인

describe() → 숫자형 데이터의 기초 통계 확인
```

특히 데이터 분석에서 자주 발생하는 문제는 다음과 같다.

- 숫자처럼 보이지만 실제 자료형은 문자열인 경우
- 값이 비어 있는 경우
- 같은 데이터가 중복되어 있는 경우
- 예상하지 못한 값이 들어 있는 경우
- 열 이름이 생각한 것과 다른 경우

따라서 **코드가 실행되지 않을 때 무조건 코드 문법만 보는 것이 아니라 데이터 자체도 확인해야 한다.**

# 7. Matplotlib - 데이터를 눈으로 확인하기

숫자만 보고 데이터의 특징을 판단하기 어려울 때 그래프를 사용한다.

```python
import matplotlib.pyplot as plt

x = [1, 2, 3, 4]
y = [10, 25, 20, 40]

plt.plot(x, y)
plt.show()
```

시각화를 하는 이유는 단순히 결과를 꾸미기 위해서가 아니다.

그래프를 보면 다음과 같은 내용을 빠르게 확인할 수 있다.

- 값이 어느 구간에 많이 몰려 있는지
- 갑자기 튀는 값이 있는지
- 두 값이 같이 증가하거나 감소하는지
- 그룹별 차이가 있는지
- 데이터가 한쪽으로 심하게 치우쳐 있는지

즉 시각화는 **데이터를 이해하기 위한 분석 과정**이다.

# 8. Seaborn - 데이터 분석용 시각화를 조금 더 편하게

Seaborn은 Matplotlib을 기반으로 하면서 데이터 분석에 자주 사용하는 그래프를 편하게 만들 수 있도록 도와준다.

```python
import seaborn as sns

sns.histplot(data=df, x="score")
plt.show()
```

히스토그램을 사용하면 점수가 어느 구간에 많이 모여 있는지 확인할 수 있다.

```text
표의 숫자 확인
    ↓
그래프로 분포 확인
    ↓
이상한 값이나 특징 발견
    ↓
전처리 또는 분석 방향 결정
```

이런 탐색 과정을 **EDA(Exploratory Data Analysis, 탐색적 데이터 분석)**라고 부른다.

# 9. 오늘 실제로 막힌 부분 - 이미지가 왜 안 불러와지는가

오늘 실습 중 이미지 파일을 불러오는 과정에서도 오류가 발생했다.

처음에는 코드 자체의 문제처럼 보였지만, 실제로는 **파일 경로와 URL이 가리키는 대상이 무엇인지 확인하는 과정**이 중요했다.

예를 들어 GitHub에서 다음과 같은 주소는 사람이 보는 웹페이지 주소다.

```text
https://github.com/사용자/저장소/blob/main/image.png
```

브라우저에서는 이미지가 보이지만 실제 응답에는 GitHub의 HTML 페이지가 포함될 수 있다.

이미지 파일 자체가 필요한 코드에서는 Raw 파일 주소를 사용해야 한다.

```text
https://raw.githubusercontent.com/사용자/저장소/main/image.png
```

정리하면 다음과 같다.

```text
GitHub blob URL
→ 사람이 보는 GitHub 페이지
→ HTML이 반환될 수 있음

GitHub raw URL
→ 실제 파일 내용
→ 이미지 로딩에 사용 가능
```

# 10. plt.imread()와 파일 경로

로컬 이미지라면 파일 경로를 정확히 지정해야 한다.

```python
import matplotlib.pyplot as plt

img = plt.imread("images/cat.png")
plt.imshow(img)
plt.axis("off")
plt.show()
```

이 코드가 실패한다면 먼저 다음을 확인해야 한다.

```text
1. 현재 실행 중인 폴더가 어디인가?
2. images 폴더가 실제로 존재하는가?
3. 파일명이 정확한가?
4. 확장자가 .png인지 .jpg인지 맞는가?
5. 대소문자가 맞는가?
6. URL이라면 실제 이미지 파일 주소인가?
```

오류가 났을 때 무작정 코드를 계속 바꾸기보다 **입력 파일이 실제로 존재하고 코드가 그 위치를 정확히 보고 있는지부터 확인하는 것이 빠르다.**

# 11. 인터넷 이미지를 읽는 한 가지 방법

이미지 파일의 Raw URL이 있다면 `requests`로 파일을 받아 PIL 이미지로 열 수도 있다.

```python
import requests
from PIL import Image
from io import BytesIO
import matplotlib.pyplot as plt

url = "https://raw.githubusercontent.com/user/repository/main/image.png"

response = requests.get(url)
response.raise_for_status()

img = Image.open(BytesIO(response.content))

plt.imshow(img)
plt.axis("off")
plt.show()
```

여기서 중요한 흐름은 다음과 같다.

```text
URL 요청
→ 이미지의 실제 byte 데이터 수신
→ PIL로 이미지 해석
→ Matplotlib으로 화면에 표시
```

단순히 URL 문자열을 이미지라고 생각하는 것이 아니라, **그 URL에서 실제로 어떤 데이터가 반환되는지** 생각해야 한다.


따라서 오늘 배운 데이터 처리 과정이 어제 공부한 머신러닝의 실제 입력 단계라고 연결해서 이해할 수 있었다.

# 오늘 헷갈렸던 부분 정리

## Python 리스트와 NumPy 배열은 같은 것이 아니다

겉으로는 숫자 여러 개가 들어 있지만 연산 방식이 다르다.

```python
[1, 2, 3] * 2
# [1, 2, 3, 1, 2, 3]
```

```python
np.array([1, 2, 3]) * 2
# [2, 4, 6]
```

## 그래프는 마지막 결과를 꾸미기 위한 것만이 아니다

모델을 학습하기 전에 데이터의 분포와 이상치를 확인하는 분석 도구다.

## 웹에서 이미지가 보인다고 코드가 바로 읽을 수 있는 것은 아니다

브라우저가 보여 주는 GitHub 페이지와 실제 파일 데이터는 다를 수 있다.

## 오류가 발생하면 코드만 볼 것이 아니라 입력 데이터도 봐야 한다

특히 데이터 분석에서는 경로, 열 이름, 자료형, 결측치 등 입력 문제 때문에 오류가 발생하는 경우가 많다.
