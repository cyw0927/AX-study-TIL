# 함수로 코드를 묶고 재사용하기

## 1. 함수가 왜 필요한가

같은 코드를 여러 번 복사하면 수정할 곳도 같이 늘어난다.

```python
print("안녕하세요!")
print("파이썬 공부를 시작합니다.")
print("안녕하세요!")
print("파이썬 공부를 시작합니다.")
```

함수로 묶으면 같은 역할을 이름으로 다시 사용할 수 있다.

```python
def greet():
    print("안녕하세요!")
    print("파이썬 공부를 시작합니다.")


greet()
greet()
```

함수는 단순히 코드 줄 수를 줄이는 문법이 아니라 **관련된 작업을 하나의 이름으로 묶는 방법**이라고 이해하는 것이 중요하다.

## 2. 함수 정의와 함수 호출은 다르다

함수는 `def`로 만든다.

```python
def say_hello():
    print("Hello, Python!")
```

이 상태는 함수를 **정의한 것**이다. 아직 실행된 것은 아니다.

실제로 실행하려면 괄호를 붙여 호출해야 한다.

```python
say_hello()
```

즉 다음처럼 구분할 수 있다.

```text
def say_hello():  → 함수 만들기
say_hello()       → 함수 실행하기
```

함수 이름만 적은 `say_hello`와 실제 호출인 `say_hello()`도 다르다는 점을 기억해야 한다.

## 3. 함수 이름은 역할이 드러나게 작성하기

아래처럼 이름이 너무 짧으면 역할을 알기 어렵다.

```python
def f():
    print("학생 정보를 출력합니다.")
```

역할이 드러나는 이름이 읽기 쉽다.

```python
def show_student_info():
    print("학생 정보를 출력합니다.")
```

함수 이름은 보통 `snake_case`를 사용한다.

```python
show_menu()
calculate_total()
get_average()
print_profile()
```

함수 이름만 보고도 대략 어떤 일을 하는지 알 수 있게 만드는 것이 좋다.

## 4. 매개변수와 인자

함수는 값을 받아 사용할 수 있다.

```python
def greet(name):
    print(f"안녕하세요, {name}님!")


greet("민수")
greet("지영")
```

여기서:

```text
name   → 매개변수(parameter)
"민수" → 인자(argument)
```

쉽게 정리하면 다음과 같다.

```text
매개변수 = 함수가 값을 받을 자리
인자     = 실제로 함수에 넣어 주는 값
```

여러 값을 받을 수도 있다.

```python
def show_profile(name, age, city):
    print(f"이름: {name}")
    print(f"나이: {age}")
    print(f"도시: {city}")


show_profile("민수", 20, "서울")
```

기본적으로 첫 번째 인수는 첫 번째 매개변수에, 두 번째 인수는 두 번째 매개변수에 들어간다.

## 5. return은 값을 함수 밖으로 돌려준다

```python
def add(a, b):
    return a + b


total = add(10, 20)
print(total)
```

실행 흐름은 다음과 같다.

```text
10, 20 전달
→ a, b가 값을 받음
→ a + b 계산
→ return 30
→ total에 30 저장
```

`return`된 값은 변수에 저장하고 다시 계산에 사용할 수 있다.

```python
def multiply(a, b):
    return a * b


price = multiply(12000, 3)
final_price = price + 3000

print(price)
print(final_price)
```

## 6. print()와 return은 다르다

두 함수는 겉으로 보면 비슷하지만 역할이 다르다.

```python
def add_print(a, b):
    print(a + b)


def add_return(a, b):
    return a + b
```

`print()`는 화면에 보여준다.

`return`은 결과를 함수 밖으로 전달한다.

```python
result = add_return(10, 20)
print(result)
```

반면 다음 코드는 화면에 30이 보이더라도 함수가 30을 반환한 것이 아니다.

```python
def show_total(a, b):
    print(a + b)


result = show_total(10, 20)
print(result)
```

함수가 `return`을 하지 않으면 호출 결과에는 계산값 대신 `None`이 들어갈 수 있다.

정리하면:

```text
사용자에게 보여 주기 → print()
다른 코드에서 다시 쓰기 → return
```

## 7. 여러 값을 반환할 수도 있다

함수는 하나가 아니라 여러 값을 반환할 수 있다.

```python
def calculate(a, b):
    total = a + b
    difference = a - b
    return total, difference
```

결과를 하나로 받을 수도 있다.

```python
result = calculate(10, 3)
print(result)
```

또는 언패킹해서 따로 받을 수 있다.

```python
total, difference = calculate(10, 3)
print(total)
print(difference)
```

함수의 여러 반환값이 튜플과 언패킹 개념과 연결된다는 점이 중요하다.

## 8. 기본값 매개변수

자주 사용하는 값을 기본값으로 지정할 수 있다.

```python
def greet(name, message="안녕하세요"):
    print(f"{message}, {name}님!")
```

기본값을 그대로 쓰는 경우:

```python
greet("민수")
```

다른 값을 전달하는 경우:

```python
greet("민수", "반갑습니다")
```

인수를 전달하지 않았을 때만 기본값이 사용된다.

## 9. 키워드 인자

인수는 위치 순서대로 넣을 수도 있고, 이름을 직접 지정할 수도 있다.

```python
show_profile("민수", 20, "서울")
```

키워드 인자를 사용하면 어떤 값이 어느 매개변수로 가는지 더 분명해진다.

```python
show_profile(
    name="민수",
    age=20,
    city="서울"
)
```

순서를 바꾸어도 이름을 지정하면 연결할 수 있다.

```python
show_profile(city="부산", name="지영", age=22)
```

## 10. 지역 변수

함수 안에서 만든 변수는 보통 함수 안에서만 사용한다.

```python
def calculate_total():
    price = 12000
    quantity = 3
    total = price * quantity
    print(total)
```

여기서 `price`, `quantity`, `total`은 함수 안에서 만든 지역 변수다.

함수 밖에서 필요한 값은 `return`으로 전달하는 방식이 이해하기 쉽다.

```python
def calculate_total(price, quantity):
    total = price * quantity
    return total


result = calculate_total(12000, 3)
print(result)
```

`total`과 `result`는 같은 변수가 아니다.

```text
price, quantity → 함수가 받은 값
total           → 함수 안에서 만든 지역 변수
result          → 함수 밖에서 반환값을 받은 변수
```

## 11. 함수 안에서도 if와 for를 사용할 수 있다

함수라고 해서 새로운 규칙이 생기는 것은 아니다. 지금까지 배운 조건문과 반복문을 그대로 함수 안에 넣을 수 있다.

조건문 예시:

```python
def get_grade(score):
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    else:
        return "C"
```

반복문과 리스트 예시:

```python
def calculate_total(scores):
    total = 0

    for score in scores:
        total += score

    return total
```

즉 함수는 기존 문법을 **하나의 역할로 묶는 그릇**처럼 생각할 수 있다.

## 12. 긴 코드를 역할별 함수로 나누기

한 프로그램 안에 여러 역할이 섞이면 코드가 길고 읽기 어려워진다.

예를 들어 주문 계산에는 다음 역할이 있다.

- 상품 금액 계산
- 할인 금액 계산
- 최종 결과 출력

각 역할을 함수로 분리할 수 있다.

```python
def calculate_product_total(price, quantity):
    return price * quantity


def calculate_discount(total, rate):
    return total * rate


def show_result(total):
    print(f"최종 금액: {total}원")
```

하지만 모든 한 줄을 무조건 함수로 만들 필요는 없다.

**반복되는 작업이 있거나, 역할을 나누면 읽기 쉬워지는 경우에 함수로 분리한다**는 기준이 중요하다.

## 13. 함수 오류를 확인하는 순서

함수에서 오류가 생기면 한꺼번에 전체를 고치기보다 입력과 출력부터 확인한다.

```text
1. 함수가 실제로 호출되었는가?
2. 인수 개수는 맞는가?
3. 인수 순서는 맞는가?
4. 매개변수에 실제로 어떤 값이 들어갔는가?
5. 지역 변수를 함수 밖에서 사용하지 않았는가?
6. 필요한 값을 return하고 있는가?
7. return된 값을 어디에 저장했는가?
```

자주 생기는 실수도 정리했다.

### 함수 이름만 적고 호출하지 않음

```python
greet
```

실행하려면:

```python
greet()
```

### 인수 개수 부족

```python
def add(a, b):
    return a + b


add(10)
```

`b`에 들어갈 값이 없으므로 오류가 발생한다.

### 함수 안의 지역 변수를 밖에서 사용

```python
def calculate():
    total = 30


print(total)
```

`total`은 함수 안에서 만든 변수이므로 범위를 확인해야 한다.

### 계산은 했지만 return하지 않음

```python
def add(a, b):
    a + b
```

함수 호출 결과가 필요하다면 `return`이 있어야 한다.

## 14. 함수로 생각하는 방식

함수를 만들 때는 먼저 다음 세 가지를 생각하면 이해하기 쉽다.

```text
입력 → 처리 → 출력
```

예를 들면:

```text
scores 입력
→ 평균 계산
→ average 반환
```

함수 이름도 이 흐름에 맞게 작성하면 읽기 쉽다.

```python
calculate_average(scores)
get_grade(score)
show_report(name, average, grade)
```

학생 점수 보고서라면 다음과 같이 연결할 수 있다.

```text
scores
→ calculate_average()
→ average
→ get_grade()
→ grade
→ show_report()
```

```text
height, width→ 두 변수에 나누어 저장하기
```

처럼 단계별로 이해하는 방식으로 정리했다.

# 오늘 배운 점

함수를 처음 보면 `def`, 괄호, 매개변수, 인자, `return` 같은 용어가 한꺼번에 나와 어렵게 느껴질 수 있다.

하지만 함수 하나를 다음처럼 보면 훨씬 단순해진다.

```text
값을 받는다
→ 필요한 작업을 한다
→ 필요한 결과를 돌려준다
```

그리고 함수를 만드는 이유도 무조건 코드를 짧게 만들기 위해서가 아니라 **역할을 분리하고 이름을 붙여서 코드를 읽기 쉽게 만들기 위해서**라는 점이 중요했다.

오늘 파이썬 학습 노트를 정리하면서도 같은 원칙이 적용됐다. 한 문서에 모든 내용을 넣는 것보다 자료형, 반복문, 함수, 오류 처리, 데이터 분석처럼 역할별로 나누니 필요한 내용을 다시 찾기 쉬워졌다.

또한 함수의 `print()`와 `return`을 구분하는 것이 특히 중요했다. 화면에 값이 보였다고 해서 그 값이 함수 밖으로 반환된 것은 아니며, 다른 계산에 다시 사용하려면 `return`을 통해 값을 전달해야 한다.
