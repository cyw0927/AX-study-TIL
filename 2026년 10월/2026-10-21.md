# 2. const와 let

값을 다시 할당하지 않을 때는 const, 이후 값이 바뀔 수 있을 때는 let을 사용했다.

```javascript
const memberName = '홍길동';
const age = 27;
const active = true;

let memberCount = 3;
memberCount = 4;
```

기본적으로 값을 바꿀 이유가 없다면 const를 먼저 사용하는 습관을 들이는 것이 좋다.

# 4. 연산자와 조건문

산술·비교·논리 연산자를 회원 조건 판단에 사용했다.

```javascript
age >= 20
age === 27
age >= 20 && active
```

if / else를 이용해 회원이 이용 가능한 성인 회원인지 판단했다.

```javascript
if (age >= 20 && active) {
  console.log(`${memberName}님은 이용 가능한 성인 회원입니다.`);
} else {
  console.log(`${memberName}님은 이용 조건을 확인해야 합니다.`);
}
```

# 5. for와 for...of

배열 반복에서는 for와 for...of를 모두 사용했다.

for...of는 배열의 값을 하나씩 꺼낼 때 간단하다.

```javascript
for (const member of members) {
  console.log(member);
}
```

반면 for는 인덱스가 필요할 때 유용하다.

```javascript
for (let i = 0; i < members.length; i++) {
  console.log(`${i + 1}번 회원: ${members[i]}`);
}
```

배열 인덱스는 0부터 시작하지만 사람에게 보여주는 번호는 1부터 시작하기 때문에 i + 1을 사용했다.

# 6. 회원 5명 판별 과제

독립 과제에서는 회원 이름과 나이를 배열에 저장하고 반복문 안에서 조건문을 사용해 성인/미성년을 판별했다.

```text

```

조건문은 한 번의 판단이고, 반복문은 그 판단을 여러 데이터에 반복 적용하는 구조라는 점을 확인했다.

# 15. date spine의 의미

월별 분석에서는 데이터가 없는 달도 0건으로 남길 수 있도록 generate_series 기반 date spine을 사용하는 구조를 학습했다.

단순 GROUP BY만 사용하면 데이터가 없는 달은 결과 자체에서 사라질 수 있다.

```text
date spine
→ 모든 월 먼저 생성
→ LEFT JOIN
→ 데이터 없는 달도 0으로 표시
```

이 방식은 LAG 같은 전월 비교를 사용할 때 중간 월이 빠져 잘못된 비교가 생기는 문제도 줄여준다.
