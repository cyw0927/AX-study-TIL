# 1. 못난이마켓 콘텐츠 품질 개선

오늘은 KANT-2/group_6_vegetable_project에서 단순 기능 추가보다 사용자가 실제로 보는 콘텐츠 품질을 개선하는 작업을 많이 했다.

특히 농가 이야기, 레시피, 모바일 필터 화면을 중심으로 수정했다.

핵심 방향은 다음과 같았다.

- 같은 이미지가 반복되는 느낌 줄이기
- 실제 농장·농작업 분위기가 느껴지는 사진 사용
- 모바일 화면에서 불필요한 설명 줄이기
- 필터를 손가락으로 넘기기 쉬운 구조로 만들기
- 이미지 출처와 사용 조건은 코드/문서에 남기기

# 2. 농가 이야기 실제 사진 적용

농가 이야기의 큰 이미지를 단순 상품 사진이 아니라 실제 한국 농작업·농촌 풍경 사진으로 교체했다.

사용한 이미지 종류는 농작업 현장, 온실, 농촌 전경 등이다.

중요한 점은 이 사진을 시연 농가의 실제 현장이라고 오해하지 않도록 문서에 구분해 둔 것이다.

또한 모바일 전송량을 줄이기 위해 이미지를 WebP로 변환하고 최대 크기를 줄였다.

오늘 배운 점:

- 이미지도 기능의 일부다.
- 보기 좋은 사진만 찾는 것으로 끝나지 않고 출처·라이선스를 함께 관리해야 한다.
- 모바일 서비스에서는 화질뿐 아니라 파일 크기도 중요하다.

# 3. 레시피 24개 추가

채소 중심의 쉬운 집밥 레시피 24개를 추가했다.

레시피 데이터에는 다음 정보가 포함된다.

- 이름
- 설명
- 조리 시간
- 난이도
- 인분
- 재료와 양
- 조리 단계
- 주재료 채소
- 연결할 상품 채소 ID
- 이미지

레시피를 단순 텍스트 목록으로 넣는 것이 아니라 상품과 연결될 수 있도록 vegetable ID를 같이 관리했다.

이 구조 덕분에 나중에 특정 채소 상품에서 관련 레시피를 연결하거나 채소별 필터를 적용할 수 있다.

# 4. 레시피 이미지 중복 문제 해결

레시피 수가 늘어나면서 같은 사진이나 비슷한 사진이 반복되는 문제가 생겼다.

그래서 인터넷 공개 라이선스 이미지를 추가하고 각 레시피에 다른 사진을 연결했다.

사진마다 다음 정보를 기록했다.

- 원본 URL
- 작가
- 라이선스
- 로컬 이미지 경로
- WebP 변환 여부

최종적으로 화면에 사용하는 레시피 이미지가 서로 겹치지 않도록 정리했다.

# 5. 모바일 레시피 필터 개선

모바일에서는 채소 종류가 많아지면 필터 버튼이 여러 줄로 쌓여 화면을 많이 차지한다.

이를 해결하기 위해 상품 목록 화면에서 사용하던 가로 스크롤형 탭 구조를 레시피 화면에도 적용했다.

변경 전:

- 둥근 필터 버튼이 길게 나열됨
- 항목이 많으면 화면이 복잡해짐

변경 후:

- 가로 탭 형태
- 선택한 탭에 밑줄 표시
- 좌우 넘기기 화살표 제공
- 손가락 스크롤 유지
- 선택 상태와 검색 조건을 URL로 유지

모바일 UI에서는 정보를 많이 보여주는 것보다 한 줄 안에서 탐색 가능하게 만드는 것이 더 중요하다는 점을 다시 확인했다.

# 8. Vercel 프리뷰 확인

GitHub PR과 Vercel이 연결되어 있어서 변경사항마다 프리뷰 배포가 생성됐다.

오늘은 PR #30, #37, #39 등의 배포 상태를 확인하면서 코드가 GitHub에 올라간 것과 실제 웹 화면에서 동작하는 것을 따로 확인했다.

즉:

GitHub 반영 = 코드 기록

Vercel Preview = 실제 화면 확인

두 단계가 다르다는 점을 확인했다.
