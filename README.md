# AX Study TIL

AX 교육과 프로젝트를 진행하면서 매일 배운 내용과 문제 해결 과정을 기록하는 저장소입니다.

## 정리 규칙

- 월별 폴더를 생성합니다. 예: `2026년 8월/`
- 각 날짜의 TIL은 `YYYY-MM-DD.md` 형식으로 저장합니다.
- 달이 바뀌면 새 월 폴더를 만들고 같은 방식으로 계속 기록합니다.

## 폴더 구조

```text
AX-study-TIL/
├─ README.md
├─ 2026년 8월/
│  ├─ 2026-08-20.md
│  ├─ 2026-08-21.md
│  └─ ...
├─ 2026년 9월/
│  ├─ 2026-09-01.md
│  └─ ...
└─ ...
```
