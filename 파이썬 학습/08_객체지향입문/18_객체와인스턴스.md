# 18. 객체와 인스턴스

`class`, 객체, 인스턴스라는 말은 처음 보면 괜히 어려워 보인다. 아주 단순하게 시작하면 된다.

## 클래스는 설계도

```python
class Cat:
    pass
```

이 코드는 `Cat`이라는 종류를 하나 만든 것이다.

아직 실제 고양이가 생긴 것은 아니다.

## 인스턴스는 실제로 만든 것

```python
cat1 = Cat()
cat2 = Cat()
```

`Cat`이라는 설계도로 `cat1`, `cat2`를 만들었다.

둘은 같은 클래스로 만들었지만 서로 다른 객체다.

## `__init__`

객체를 만들 때 처음 값을 넣고 싶으면 `__init__`을 쓴다.

```python
class Cat:
    def __init__(self, name):
        self.name = name
```

이제:

```python
cat1 = Cat("나비")
cat2 = Cat("냥이")
```

라고 만들 수 있다.

## `self`는 누구인가?

`self`는 **지금 이 객체 자신**이라고 생각하면 된다.

```python
cat1 = Cat("나비")
```

이 객체의 `self.name`은 `"나비"`가 된다.

```python
print(cat1.name)
```

결과:

```text
나비
```

## 객체마다 값이 다를 수 있다

```python
print(cat1.name)
print(cat2.name)
```

결과:

```text
나비
냥이
```

같은 `Cat` 클래스로 만들었지만 저장된 값은 다르다.

## 메서드

클래스 안에 만든 함수를 메서드라고 부른다.

```python
class Cat:
    def __init__(self, name):
        self.name = name

    def hello(self):
        print(self.name, "야옹")
```

사용:

```python
cat1 = Cat("나비")
cat1.hello()
```

결과:

```text
나비 야옹
```

## 클래스와 객체를 한 줄로 구분

```text
class Cat       → 설계도
Cat("나비")    → 실제 객체 생성
cat1            → 만들어진 객체를 가리키는 변수
cat1.name       → 그 객체가 가지고 있는 값
cat1.hello()    → 그 객체가 사용할 수 있는 기능
```

처음에는 상속 같은 내용보다 **설계도 하나로 여러 객체를 만들 수 있다**는 감각만 잡으면 충분하다.
