# 19. 클래스 연습

클래스는 설명만 읽으면 잘 안 잡힌다. 작은 예제를 직접 만들어 보는 편이 빠르다.

## 연습 1: 학생 만들기

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score
```

객체 만들기:

```python
student1 = Student("철수", 80)
student2 = Student("영희", 95)
```

확인:

```python
print(student1.name)
print(student1.score)
print(student2.name)
print(student2.score)
```

## 연습 2: 합격 여부 기능 추가

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def show_result(self):
        if self.score >= 60:
            print(self.name, "합격")
        else:
            print(self.name, "불합격")
```

사용:

```python
student1 = Student("철수", 80)
student1.show_result()
```

## 연습 3: 값을 바꿀 수도 있다

```python
student1.score = 50
student1.show_result()
```

객체 안의 값은 필요하면 바뀔 수 있다.

## 연습 4: 게임 캐릭터

```python
class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp

    def damage(self, amount):
        self.hp -= amount
        print(self.name, "남은 체력:", self.hp)
```

사용:

```python
hero = Character("용사", 100)
hero.damage(20)
hero.damage(30)
```

결과:

```text
용사 남은 체력: 80
용사 남은 체력: 50
```

## 여기서 중요한 것

`self.hp -= amount`는 현재 객체가 가지고 있는 체력에서 받은 피해량을 빼는 것이다.

## 직접 바꿔 보기

다음 기능을 하나씩 추가해 본다.

- 학생에게 `age` 추가
- 캐릭터에게 `attack` 값 추가
- `heal()` 메서드 만들기
- 체력이 0 이하이면 `쓰러짐` 출력하기

처음부터 거대한 클래스를 만들 필요 없다. 변수 2개와 메서드 1개 정도로 시작하면 충분하다.
