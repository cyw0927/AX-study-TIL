# 17. 클래스가 뭔가요?

클래스는 처음 보면 굉장히 어려워 보이지만, 아주 단순하게는 **비슷한 모양의 데이터를 계속 만들기 위한 틀**이라고 생각하면 된다.

예를 들어 게임 캐릭터를 여러 명 만든다고 해보자.

```python
name1 = "철수"
hp1 = 100

name2 = "영희"
hp2 = 100
```

사람이 많아질수록 변수 이름이 계속 늘어난다. 이럴 때 클래스를 사용할 수 있다.

```python
class Character:
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp
```

이 코드는 `Character`라는 틀을 만든 것이다.

```python
chulsoo = Character("철수", 100)
younghee = Character("영희", 100)

print(chulsoo.name)
print(younghee.hp)
```

## `class`

새로운 종류의 객체를 만들기 위한 틀을 선언한다.

```python
class Dog:
    pass
```

여기서 `Dog`는 클래스 이름이다.

## 객체

클래스를 이용해서 실제로 만든 하나의 값을 객체라고 부른다.

```python
class Dog:
    pass

my_dog = Dog()
```

`Dog`는 틀이고 `my_dog`는 그 틀로 만든 실제 객체다.

붕어빵으로 비유하면:

```text
붕어빵 틀 = class
실제 붕어빵 = object(객체)
```

## `__init__`

객체를 만들 때 처음 실행되는 특별한 함수다.

```python
class Dog:
    def __init__(self, name):
        self.name = name
```

```python
my_dog = Dog("초코")
print(my_dog.name)
```

`Dog("초코")`를 실행하면 `__init__`이 실행되고 이름이 저장된다.

## `self`

초보가 클래스에서 가장 많이 막히는 단어다.

`self`는 **지금 만들어진 그 객체 자신**을 뜻한다고 생각하면 된다.

```python
self.name = name
```

이 문장은 "이 객체 안에 name이라는 값을 저장한다" 정도로 이해하면 된다.

## 메서드

클래스 안에 들어 있는 함수를 메서드라고 부른다.

```python
class Dog:
    def __init__(self, name):
        self.name = name

    def bark(self):
        print(self.name, "멍멍")
```

```python
my_dog = Dog("초코")
my_dog.bark()
```

결과:

```text
초코 멍멍
```

## 지금 당장 외울 필요 없는 것

상속, 오버라이딩, 다형성 같은 말은 처음부터 외우지 않아도 된다. 먼저 아래 네 가지 정도만 구분할 수 있으면 충분하다.

```text
class = 틀
object = 그 틀로 만든 실제 값
__init__ = 처음 만들 때 실행
self = 지금 그 객체 자신
```

## 직접 연습

```python
class Student:
    def __init__(self, name, score):
        self.name = name
        self.score = score

    def show(self):
        print("이름:", self.name)
        print("점수:", self.score)

student1 = Student("철수", 80)
student2 = Student("영희", 95)

student1.show()
student2.show()
```

처음에는 코드를 외우려고 하지 말고 `student1.name`, `student2.score`가 각각 어떤 값을 가리키는지만 따라가 본다.
