# 03. 조건문과 반복문

프로그램은 단순히 위에서 아래로 한 번만 실행되는 것이 아니다. 어떤 조건에 따라 다른 행동을 하기도 하고, 같은 일을 여러 번 반복하기도 한다.

## 1. `if`

`if`는 **조건이 맞으면 코드를 실행하는 문법**이다.

```python
age = 20

if age >= 19:
    print("성인입니다")
```

`age >= 19`가 참이면 아래 들여쓴 코드가 실행된다.

쉽게 읽으면:

> 만약 age가 19 이상이면 `성인입니다`를 출력한다.

---

## 2. 비교 연산자

조건을 만들 때 자주 쓴다.

```text
==   같다
!=   다르다
>    크다
<    작다
>=   크거나 같다
<=   작거나 같다
```

예:

```python
score = 80
print(score >= 60)
```

결과:

```text
True
```

---

## 3. `else`

`if` 조건이 거짓일 때 실행한다.

```python
age = 15

if age >= 19:
    print("성인")
else:
    print("미성년자")
```

결과:

```text
미성년자
```

즉:

> 조건이 맞으면 위쪽, 아니면 else 쪽.

---

## 4. `elif`

조건이 여러 개일 때 사용한다.

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
else:
    print("C")
```

결과는 `B`다.

`elif`는 '그게 아니면 이 조건은?' 정도로 생각하면 된다.

---

## 5. 조건문의 순서

위에서부터 차례로 검사한다.

```python
score = 95

if score >= 80:
    print("B 이상")
elif score >= 90:
    print("A")
```

이 코드는 첫 조건 `score >= 80`이 이미 참이라 `B 이상`만 출력된다.

따라서 더 구체적이거나 높은 기준을 먼저 쓰는 경우가 많다.

```python
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
```

---

## 6. `and`

두 조건이 **둘 다 참**이어야 할 때 쓴다.

```python
age = 20
has_ticket = True

if age >= 19 and has_ticket:
    print("입장 가능")
```

---

## 7. `or`

둘 중 **하나만 참이어도** 된다.

```python
is_admin = False
is_manager = True

if is_admin or is_manager:
    print("관리 화면 접근 가능")
```

---

## 8. `not`

참과 거짓을 반대로 뒤집는다.

```python
is_closed = False

if not is_closed:
    print("영업 중")
```

---

## 9. `for`

`for`는 **여러 값을 하나씩 꺼내면서 같은 코드를 반복**하는 문법이다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]

for food in foods:
    print(food)
```

결과:

```text
짜장면
짬뽕
탕수육
```

쉽게 읽으면:

> foods에서 하나씩 꺼내서 food라고 부르고, 매번 출력한다.

---

## 10. 반복문 변수는 계속 바뀐다

```python
numbers = [10, 20, 30]

for number in numbers:
    print("현재 값:", number)
```

반복할 때마다 `number`에는 10, 20, 30이 차례대로 들어간다.

---

## 11. `range()`

숫자를 일정한 범위로 만들어 반복할 때 자주 사용한다.

```python
for i in range(5):
    print(i)
```

결과:

```text
0
1
2
3
4
```

`range(5)`는 0부터 4까지다. 끝 숫자 5는 포함하지 않는다.

---

## 12. `range(시작, 끝)`

```python
for i in range(1, 5):
    print(i)
```

결과:

```text
1
2
3
4
```

역시 끝 숫자 5는 포함하지 않는다.

---

## 13. `range(시작, 끝, 간격)`

```python
for i in range(0, 10, 2):
    print(i)
```

결과:

```text
0
2
4
6
8
```

2씩 증가한다.

---

## 14. 중첩 반복문

`for` 안에 또 `for`가 들어갈 수 있다.

```python
board = [
    [1, 2, 3],
    [4, 5, 6]
]

for row in board:
    for number in row:
        print(number)
```

첫 번째 `for`는 행을 하나씩 꺼내고, 두 번째 `for`는 그 행 안의 값을 하나씩 꺼낸다.

이미지나 표처럼 2차원 데이터를 처리할 때 자주 나온다.

---

## 15. `while`

`while`은 **조건이 참인 동안 계속 반복**한다.

```python
count = 0

while count < 3:
    print(count)
    count += 1
```

결과:

```text
0
1
2
```

조건이 계속 참이면 끝없이 반복할 수 있으므로 주의해야 한다.

---

## 16. 무한 반복

```python
while True:
    print("계속 실행")
```

이 코드는 멈추는 조건이 없어서 계속 실행된다.

초보 때 `while`을 쓸 때는 **언제 조건이 False가 되는지** 꼭 확인해야 한다.

---

## 17. `break`

반복문을 중간에 끝낸다.

```python
for i in range(10):
    if i == 3:
        break
    print(i)
```

결과:

```text
0
1
2
```

3이 되면 반복문 자체를 끝낸다.

---

## 18. `continue`

현재 한 번만 건너뛰고 다음 반복으로 넘어간다.

```python
for i in range(5):
    if i == 2:
        continue
    print(i)
```

결과:

```text
0
1
3
4
```

2일 때만 출력하지 않는다.

---

## 19. 들여쓰기 다시 보기

```python
for i in range(3):
    print(i)
    print("반복 중")

print("끝")
```

앞의 두 `print()`는 반복문 안에 있고 마지막 `print("끝")`은 반복문 밖이다.

Python에서는 **들여쓰기가 코드 구조 그 자체**다.

---

## 20. 지금 기억할 핵심

```text
if        조건이 맞으면 실행
elif      다른 조건도 검사
else      위 조건이 전부 아니면 실행
for       하나씩 꺼내 반복
range()   반복할 숫자 범위 만들기
while     조건이 참인 동안 반복
break     반복문 종료
continue  이번 반복만 건너뛰기
```

다음 편에서는 반복해서 쓰는 코드를 묶는 `함수`를 자세히 설명한다.
