# 04. 함수와 코드 묶기

함수는 초보 때 처음 보면 괜히 어려워 보이지만, 사실은 **자주 쓰는 코드를 한 묶음으로 만들어 이름을 붙이는 것**이다.

## 1. 함수가 왜 필요한가?

같은 코드를 여러 번 쓴다고 생각해 보자.

```python
print("안녕하세요")
print("반갑습니다")

print("안녕하세요")
print("반갑습니다")

print("안녕하세요")
print("반갑습니다")
```

이렇게 반복해서 쓰면 길고 귀찮다.

함수로 만들면:

```python
def hello():
    print("안녕하세요")
    print("반갑습니다")
```

이제:

```python
hello()
hello()
hello()
```

처럼 사용할 수 있다.

---

## 2. `def`

`def`는 **함수를 만들겠다**는 뜻이다.

```python
def hello():
    print("안녕")
```

쉽게 읽으면:

> hello라는 이름의 함수를 만든다.

---

## 3. 함수 정의와 함수 실행은 다르다

```python
def hello():
    print("안녕")
```

이 코드는 함수를 만든 것뿐이다.

실제로 실행하려면:

```python
hello()
```

라고 따로 호출해야 한다.

---

## 4. 함수 호출

함수를 사용하는 것을 보통 **호출한다**고 말한다.

```python
print("hello")
```

여기서도 사실 `print`라는 함수를 호출하고 있는 것이다.

직접 만든 함수도 똑같다.

```python
def hello():
    print("hello")

hello()
```

---

## 5. 매개변수

함수에게 값을 전달할 수 있다.

```python
def hello(name):
    print("안녕하세요", name)
```

사용할 때:

```python
hello("철수")
hello("영희")
```

결과:

```text
안녕하세요 철수
안녕하세요 영희
```

여기서 `name`은 함수가 값을 받을 자리다.

이런 변수를 **매개변수**라고 한다.

---

## 6. 인자

```python
hello("철수")
```

여기서 실제로 넣어 준 `"철수"`를 인자라고 한다.

처음에는 너무 구분해서 외우지 않아도 된다.

대충:

```text
매개변수 = 함수 만들 때 받는 자리
인자 = 함수를 사용할 때 실제로 넣는 값
```

정도로 이해하면 된다.

---

## 7. 매개변수 여러 개

```python
def add(a, b):
    print(a + b)

add(3, 5)
```

결과:

```text
8
```

함수에 여러 값을 전달할 수도 있다.

---

## 8. `return`

`return`은 **함수에서 계산한 값을 밖으로 돌려준다.**

```python
def add(a, b):
    return a + b
```

이제:

```python
result = add(3, 5)
print(result)
```

결과:

```text
8
```

---

## 9. `print()`와 `return`의 차이

이 부분은 초보가 정말 많이 헷갈린다.

```python
def add1(a, b):
    print(a + b)
```

이 함수는 화면에 보여주기만 한다.

반면:

```python
def add2(a, b):
    return a + b
```

이 함수는 값을 돌려준다.

그래서:

```python
result = add2(3, 5)
```

처럼 결과를 변수에 저장해서 다시 사용할 수 있다.

쉽게 생각하면:

```text
print  = 화면에 보여준다
return = 함수 밖으로 값을 넘겨준다
```

---

## 10. `return`을 만나면 함수가 끝난다

```python
def test():
    print("1")
    return
    print("2")
```

실행하면:

```python
test()
```

결과는:

```text
1
```

`return` 뒤의 코드는 실행되지 않는다.

---

## 11. 함수 안의 변수

```python
def test():
    x = 10
    print(x)
```

여기서 `x`는 함수 안에서 만들어졌다.

보통 함수 밖에서는 그대로 사용할 수 없다.

```python
test()
print(x)
```

이렇게 하면 오류가 날 수 있다.

이것을 이해할 때는 우선:

> 함수 안에서 만든 변수는 그 함수 안에서 쓰는 값이다.

라고 기억하면 충분하다.

---

## 12. 함수 이름은 역할이 보이게 짓기

```python
def a(x, y, z):
    return (x + y + z) // 3
```

실행은 되지만 무슨 함수인지 바로 알기 어렵다.

```python
def calc_brightness(r, g, b):
    return (r + g + b) // 3
```

이렇게 이름을 지으면 '밝기를 계산하는 함수'라는 뜻을 바로 알 수 있다.

---

## 13. 함수로 나누면 오류 찾기도 쉽다

예를 들어 프로그램 전체가:

1. 입력 받기
2. RGB 나누기
3. 밝기 계산하기
4. 평균 계산하기
5. 흑백으로 바꾸기

를 한다면 전부 한 덩어리로 써도 된다.

하지만 다음처럼 나눌 수도 있다.

```python
def parse_pixel(...):
    ...

def calc_brightness(...):
    ...

def calc_threshold(...):
    ...
```

그러면 오류가 났을 때 어느 기능이 문제인지 확인하기 쉬워진다.

## 14. 함수가 많다고 무조건 좋은 것은 아니다

한 줄짜리 코드까지 무조건 전부 함수로 만들 필요는 없다.

중요한 것은:

> 이 함수가 무슨 일을 하는지 한 문장으로 설명할 수 있는가?

이다.

---

## 15. `main()`

Python 코드에서 자주 보는 이름이다.

```python
def main():
    print("프로그램 시작")
```

`main`은 특별한 마법 단어는 아니다. 그냥 사람들이 프로그램의 **전체 실행 흐름을 담는 함수 이름**으로 자주 사용하는 것이다.

---

## 16. `if __name__ == "__main__":`

초보 입장에서는 매우 이상하게 생긴 코드다.

```python
if __name__ == "__main__":
    main()
```

처음에는 이렇게만 이해해도 된다.

> 이 Python 파일을 직접 실행했을 때 main()을 실행한다.

다른 파일에서 이 파일을 가져다 쓸 때는 자동으로 `main()`이 실행되는 일을 막아준다.

지금 당장 완전히 이해하지 못해도 괜찮다.

---

## 17. 간단한 함수 연습

```python
def square(number):
    return number * number

print(square(3))
print(square(5))
```

결과:

```text
9
25
```

여기서 순서를 따라가 보면:

1. `square(3)` 호출
2. `number`에 3이 들어감
3. `3 * 3` 계산
4. `return`으로 9를 돌려줌
5. `print()`가 9를 출력

이다.

---

## 18. 지금 기억할 핵심

```text
def       함수 만들기
호출      함수 사용하기
매개변수  함수가 값을 받을 자리
인자      실제로 넣는 값
return    계산 결과를 함수 밖으로 돌려주기
main()    프로그램 전체 흐름에 자주 쓰는 함수 이름
```

처음에는 `def`, 매개변수, `return` 세 가지만 제대로 이해해도 충분하다.
