# 기본값 인자

함수를 만들 때 어떤 값을 안 줘도 기본으로 쓰게 만들 수 있다.

```python
def hello(name="친구"):
    print("안녕하세요", name)
```

```python
hello("철수")
hello()
```

결과:

```text
안녕하세요 철수
안녕하세요 친구
```

`name="친구"`가 기본값이다.

값을 넣으면 내가 넣은 값이 사용되고, 값을 안 넣으면 기본값이 사용된다.

## 왜 쓰나?

매번 같은 값을 넣는 게 귀찮을 때 편하다.

```python
def power(number, exponent=2):
    return number ** exponent

print(power(3))
print(power(3, 3))
```

결과:

```text
9
27
```

첫 번째 호출은 지수를 안 줬기 때문에 2를 사용한다.

## 주의할 점

기본값이 없는 매개변수는 앞쪽에 둔다.

```python
def student(name, age=20):
    print(name, age)
```

이건 자연스럽다.

초보 단계에서는 `기본값 = 안 넣었을 때 대신 쓰는 값` 정도로 기억하면 된다.
