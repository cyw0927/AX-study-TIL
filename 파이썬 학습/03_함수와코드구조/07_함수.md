# 07. 함수 완전 기초

함수는 **자주 쓰는 코드를 하나의 이름으로 묶어 둔 것**이다.

## 함수가 왜 필요한가?

같은 계산을 여러 번 해야 한다고 해보자.

```python
print((255 + 0 + 0) // 3)
print((0 + 255 + 0) // 3)
print((0 + 0 + 255) // 3)
```

계속 비슷한 코드를 반복하고 있다.

함수로 만들면:

```python
def calc_brightness(r, g, b):
    return (r + g + b) // 3

print(calc_brightness(255, 0, 0))
print(calc_brightness(0, 255, 0))
print(calc_brightness(0, 0, 255))
```

훨씬 읽기 쉬워진다.

## `def`

함수를 만들 때 사용한다.

```python
def hello():
    print("안녕하세요")
```

여기서 `hello`는 함수 이름이다.

함수를 만들었다고 바로 실행되는 것은 아니다.

```python
hello()
```

이렇게 불러야 실행된다.

## 매개변수

함수에게 값을 전달하기 위해 함수 정의 안에 적는 변수다.

```python
def hello(name):
    print("안녕하세요", name)
```

`name`이 매개변수다.

```python
hello("철수")
hello("영희")
```

각각 다른 값으로 같은 함수를 사용할 수 있다.

## 인자

실제로 함수에 넣어 주는 값을 말한다.

```python
hello("철수")
```

여기서 `"철수"`가 인자다.

처음에는 매개변수와 인자를 완벽히 구분해서 외울 필요는 없다.

- 함수 만들 때 괄호 안 이름 → 매개변수
- 함수 부를 때 실제로 넣는 값 → 인자

정도로 이해하면 된다.

## `return`

함수에서 계산한 값을 밖으로 돌려준다.

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
```

결과:

```text
8
```

## `print()`와 `return`은 다르다

```python
def add1(a, b):
    print(a + b)


def add2(a, b):
    return a + b
```

`print()`는 화면에 보여준다.

`return`은 값을 함수 밖으로 보내서 다른 계산에 다시 쓸 수 있게 한다.

```python
x = add2(3, 5)
print(x * 10)
```

## return을 만나면 함수가 끝난다

```python
def test():
    return 10
    print("여기는 실행 안 됨")
```

`return` 뒤의 코드는 실행되지 않는다.

## 지역변수

함수 안에서 만든 변수는 보통 함수 안에서만 사용한다.

```python
def test():
    x = 10
    print(x)
```

함수 밖에서 바로 `x`를 사용하면 오류가 날 수 있다.

## 함수 이름은 의미 있게

```python
def f(a, b, c):
    return (a + b + c) // 3
```

보다:

```python
def calc_brightness(r, g, b):
    return (r + g + b) // 3
```

이 더 알아보기 쉽다.

## 한 함수에 너무 많은 일을 넣지 않기

예를 들어:

```text
입력 받기
RGB 나누기
밝기 계산
평균 계산
흑백 변환
출력
```

을 한 함수에 전부 넣을 수도 있지만, 초보일수록 작은 역할로 나누면 이해하기 쉽다.

## 직접 연습

```python
def multiply(a, b):
    result = a * b
    return result

x = multiply(3, 4)
print(x)
print(x + 10)
```

그 다음 `multiply`를 `add`, `subtract` 같은 함수로 직접 바꿔 만들어 본다.
