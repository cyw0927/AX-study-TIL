# 매개변수와 인자

함수를 배우다 보면 `parameter`, `argument`, 매개변수, 인자라는 말이 나온다.

처음에는 이름이 어려워 보이지만 뜻은 단순하다.

```python
def hello(name):
    print("안녕", name)

hello("철수")
```

여기서 `name`은 **매개변수**, `"철수"`는 **인자**라고 부른다.

쉽게 말하면:

```text
매개변수 = 함수가 값을 받을 자리의 이름
인자     = 실제로 함수에 넣어 주는 값
```

## 함수는 값을 받을 수 있다

```python
def add(a, b):
    print(a + b)

add(3, 5)
```

실행할 때는 대략 이렇게 생각하면 된다.

```text
a에 3이 들어감
b에 5가 들어감
3 + 5 계산
8 출력
```

## 매개변수가 두 개면 인자도 보통 두 개 필요하다

```python
def add(a, b):
    print(a + b)
```

아래처럼 하나만 넣으면 오류가 난다.

```python
add(3)
```

왜냐하면 `b`에 들어갈 값이 없기 때문이다.

## 순서가 중요하다

```python
def introduce(name, age):
    print("이름:", name)
    print("나이:", age)

introduce("철수", 20)
```

첫 번째 값은 `name`, 두 번째 값은 `age`로 들어간다.

## 이름을 지정해서 넣을 수도 있다

```python
introduce(age=20, name="철수")
```

이런 방식을 키워드 인자라고 한다.

초보 단계에서는 우선 **순서대로 넣는 방식**부터 익혀도 충분하다.

## 기본값

함수를 만들 때 미리 기본값을 정할 수 있다.

```python
def hello(name="손님"):
    print("안녕하세요", name)

hello()
hello("철수")
```

결과:

```text
안녕하세요 손님
안녕하세요 철수
```

## `input()`과 연결하기

```python
def greet(name):
    print("반가워요", name)

user_name = input("이름: ")
greet(user_name)
```

이 흐름을 보면:

```text
키보드 입력
→ user_name 변수에 저장
→ greet 함수에 전달
→ 함수 안의 name에 들어감
→ 출력
```

## 자주 헷갈리는 것

함수 밖의 변수 이름과 매개변수 이름이 같을 필요는 없다.

```python
def double(number):
    print(number * 2)

x = 10
double(x)
```

`x`의 값 10이 함수의 `number`로 전달되는 것이다.

## 직접 연습

```python
def multiply(a, b):
    print(a * b)

multiply(2, 3)
multiply(10, 5)
```

그다음 매개변수 이름을 `x`, `y`로 바꿔도 결과가 같은지 확인해 본다.
