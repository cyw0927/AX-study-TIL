# 함수를 이용해서 문제를 쪼개는 법

초보자는 코드가 길어지면 어디서부터 봐야 할지 막막해지기 쉽다.

이럴 때는 문제를 **작은 일 여러 개로 나누고, 각 일을 함수 하나씩 맡긴다**고 생각하면 된다.

## 예시: 숫자 3개의 평균 구하기

처음에는 이렇게 한 번에 쓸 수 있다.

```python
a = int(input())
b = int(input())
c = int(input())

average = (a + b + c) / 3
print(average)
```

짧을 때는 괜찮다.

하지만 해야 할 일이 늘어나면 코드를 나누는 게 좋다.

```python
def calc_average(a, b, c):
    return (a + b + c) / 3


def main():
    a = int(input())
    b = int(input())
    c = int(input())

    average = calc_average(a, b, c)
    print(average)


if __name__ == "__main__":
    main()
```

## 왜 이렇게 나누나?

`calc_average()`는 평균 계산만 담당한다.

`main()`은 입력을 받고, 함수를 부르고, 결과를 출력한다.

역할이 분리되면 어디서 오류가 났는지 찾기도 쉬워진다.

## 문제를 쪼개는 순서

문제를 읽고 다음처럼 질문해 본다.

1. 입력을 받는 부분은 어디인가?
2. 계산하는 부분은 어디인가?
3. 조건을 판단하는 부분은 어디인가?
4. 결과를 만드는 부분은 어디인가?
5. 출력하는 부분은 어디인가?

예를 들어 RGB 밝기 문제라면 이렇게 나눌 수 있다.

```text
문자열 RGB 나누기
→ 밝기 계산하기
→ 전체 평균 구하기
→ 0/1로 바꾸기
→ 출력하기
```

각 일을 함수로 만들면:

```python
def parse_pixel(text):
    ...


def calc_brightness(r, g, b):
    ...


def calc_threshold(brightness_map):
    ...


def to_black_white(brightness_map, threshold):
    ...
```

처럼 나눌 수 있다.

## 함수를 너무 잘게 쪼개면?

함수 하나에 코드 한 줄만 있다고 무조건 좋은 것은 아니다.

초보 단계에서는 **이 함수가 무슨 일을 하는지 한 문장으로 설명할 수 있느냐**를 기준으로 생각하면 된다.

예:

```text
parse_pixel() → "255,0,0"을 255, 0, 0으로 나눈다
calc_brightness() → RGB 세 값으로 밝기 하나를 계산한다
```

이렇게 역할이 분명하면 좋은 편이다.

## 함수로 나누면 테스트도 쉽다

```python
def calc_brightness(r, g, b):
    return (r + g + b) // 3

print(calc_brightness(255, 0, 0))
print(calc_brightness(0, 0, 0))
print(calc_brightness(255, 255, 255))
```

전체 프로그램을 실행하지 않고 특정 계산만 확인할 수 있다.

## 초보자가 자주 하는 실수

### 함수 안에서 print만 하고 return을 안 하는 경우

```python
def add(a, b):
    print(a + b)

result = add(3, 4)
print(result)
```

첫 번째 출력은 7이지만 `result`에는 `None`이 들어간다.

계산 결과를 밖에서 쓰려면:

```python
def add(a, b):
    return a + b
```

라고 해야 한다.

## 직접 연습

아래 코드를 함수 2개로 나눠 본다.

```python
numbers = [10, 20, 30, 40]

total = 0
for number in numbers:
    total += number

average = total / len(numbers)
print(average)
```

추천 역할:

```text
calc_total()   → 합계 계산
calc_average() → 평균 계산
```

함수를 나누는 목적은 코드를 멋있게 보이게 하는 것이 아니라 **한 부분씩 이해하고 고치기 쉽게 만드는 것**이다.
