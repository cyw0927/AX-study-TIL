# 지역변수와 전역변수

변수는 아무 데서나 항상 쓸 수 있는 것이 아니다.

변수를 **어디에서 만들었는지**에 따라 사용할 수 있는 범위가 달라진다.

## 함수 밖에서 만든 변수

```python
name = "철수"

print(name)
```

이런 변수는 함수 바깥에서 만들어졌다.

보통 전역변수라고 부른다.

## 함수 안에서 만든 변수

```python
def hello():
    message = "안녕하세요"
    print(message)

hello()
```

`message`는 함수 안에서 만들어졌다.

이런 변수는 지역변수라고 한다.

## 함수 밖에서는 지역변수를 바로 쓸 수 없다

```python
def hello():
    message = "안녕하세요"

hello()
print(message)
```

이 코드는 오류가 난다.

왜냐하면 `message`는 `hello()` 함수 안에서만 살아 있는 이름이기 때문이다.

## 같은 이름이어도 서로 다른 변수일 수 있다

```python
x = 100

def test():
    x = 10
    print("함수 안:", x)

print("함수 밖:", x)
test()
```

결과:

```text
함수 밖: 100
함수 안: 10
```

이름은 둘 다 `x`지만 범위가 다르다.

## 초보 단계에서는 전역변수 변경을 피하는 편이 좋다

함수 안에서 함수 밖 변수를 직접 바꾸려고 하면 코드 흐름이 헷갈릴 수 있다.

가능하면 값을 함수에 전달하고 `return`으로 다시 받는 방식이 이해하기 쉽다.

예:

```python
def add_one(number):
    return number + 1

x = 10
x = add_one(x)
print(x)
```

## `global`은 무엇인가?

Python에는 함수 안에서 전역변수를 직접 바꾸게 하는 `global` 문법도 있다.

```python
x = 10

def change():
    global x
    x = 20

change()
print(x)
```

하지만 입문 단계에서는 꼭 필요한 경우가 아니면 남발하지 않는 것이 좋다.

## 왜 이런 구분이 필요한가?

큰 프로그램에서는 변수 이름이 아주 많아진다.

함수마다 자기 안에서만 사용하는 변수가 따로 있으면 다른 함수의 변수와 충돌할 가능성이 줄어든다.

## 직접 연습

```python
score = 100

def test():
    score = 50
    print("함수 안 score:", score)

print("함수 밖 score:", score)
test()
print("함수 실행 후 score:", score)
```

실행 전에 세 줄에 각각 어떤 값이 나올지 예상해 본다.
