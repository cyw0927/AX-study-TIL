# 25. API가 뭔가요?

API는 프로그램끼리 서로 정보를 주고받을 때 사용하는 약속 같은 것이다.

처음에는 이름이 어려워 보이지만, 쉽게 생각하면 **프로그램끼리 주문하고 답을 받는 창구**다.

## 예를 들어 날씨 앱

날씨 앱이 세상의 모든 기온을 직접 측정하는 것은 아니다.

보통은 다른 서버에 이렇게 요청한다.

```text
서울 날씨 알려줘
```

그러면 서버가 결과를 돌려준다.

```text
기온 28도, 맑음
```

이때 앱과 서버 사이에서 정해진 방식으로 요청하고 응답받는 것이 API다.

## 요청과 응답

API를 공부할 때 가장 먼저 기억할 두 단어다.

```text
request  = 요청
response = 응답
```

흐름은 보통 이렇게 생각하면 된다.

```text
Python 프로그램
   ↓ request
API 서버
   ↓ response
Python 프로그램
```

## URL

API도 인터넷 주소를 사용한다.

예를 들어 이런 모양을 볼 수 있다.

```text
https://example.com/api/users
```

브라우저 주소와 비슷해 보이지만, 사람이 보는 웹페이지 대신 프로그램이 읽을 데이터를 주는 경우가 많다.

## JSON

API 응답에서 아주 자주 보는 데이터 모양이다.

```json
{
  "name": "철수",
  "age": 20
}
```

Python의 딕셔너리와 생김새가 매우 비슷하다.

Python으로 바뀌면 대충 이런 느낌이다.

```python
user = {
    "name": "철수",
    "age": 20
}

print(user["name"])
```

## GET

데이터를 가져오고 싶을 때 많이 쓴다.

쉽게 말하면:

```text
GET = 보여줘
```

예:

```text
회원 목록 보여줘
오늘 날씨 보여줘
게시글 3번 보여줘
```

## POST

새 데이터를 보내거나 만들 때 많이 쓴다.

```text
POST = 이 데이터를 받아줘 / 새로 만들어줘
```

예를 들어 회원가입 정보를 서버에 보내는 경우다.

## 상태 코드

서버가 요청을 처리한 결과를 숫자로 알려주기도 한다.

자주 보는 예:

```text
200 = 잘 됨
201 = 새로 만들어짐
400 = 요청이 이상함
401 = 인증이 필요함
403 = 권한이 없음
404 = 찾을 수 없음
500 = 서버 쪽 오류
```

처음에는 전부 외우지 않아도 된다. `200` 계열은 대체로 성공, `400` 계열은 요청 쪽 문제, `500` 계열은 서버 쪽 문제라고만 알아도 도움이 된다.

## Python에서는 어떻게 요청하나?

`requests`라는 라이브러리를 자주 사용한다.

```python
import requests

response = requests.get("https://example.com")
print(response.status_code)
```

실제 API마다 주소와 사용법은 다르다.

중요한 점은 무조건 코드부터 복사하지 말고 문서에서 다음을 확인하는 것이다.

```text
어느 주소로 보내는가?
GET인가 POST인가?
어떤 값을 보내야 하는가?
응답은 어떤 모양인가?
API 키가 필요한가?
```

## API 키

일부 API는 누가 사용하는지 확인하기 위해 비밀키 같은 문자열을 준다.

이런 값은 GitHub에 그대로 올리면 안 된다.

잘못된 예:

```python
API_KEY = "진짜비밀키"
```

실제 프로젝트에서는 `.env` 같은 별도 환경설정 파일에 두고 Git에서 제외하는 방법을 많이 쓴다.

## 처음에는 이것만 기억

```text
API      = 프로그램끼리 정보를 주고받는 창구
request  = 요청
response = 응답
GET      = 가져오기
POST     = 보내기/생성
JSON     = 데이터를 주고받을 때 자주 쓰는 모양
200      = 대체로 성공
404      = 못 찾음
500      = 서버 오류
```

API 코드를 볼 때는 요청 주소, 보내는 값, 응답 데이터를 하나씩 출력해 보면 흐름이 훨씬 쉽게 보인다.
