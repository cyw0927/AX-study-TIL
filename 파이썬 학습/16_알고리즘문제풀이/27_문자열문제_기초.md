# 문자열 문제 기초

문자열 문제는 글자를 한 글자씩 보거나, 나누거나, 특정 글자가 있는지 확인하는 문제가 많다.

## 문자열도 반복할 수 있다

```python
text = "abc"

for ch in text:
    print(ch)
```

결과:

```text
a
b
c
```

리스트처럼 한 글자씩 꺼낼 수 있다.

## 길이 구하기

```python
text = "hello"
print(len(text))
```

결과는 5다.

## 특정 글자 세기

```python
text = "banana"
count = 0

for ch in text:
    if ch == "a":
        count += 1

print(count)
```

여기서 중요한 건 `count = 0`으로 시작하고 조건이 맞을 때마다 1씩 늘리는 구조다.

## 대문자와 소문자

```python
text = "Hello"
print(text.lower())
print(text.upper())
```

문자 비교 문제에서는 대소문자를 통일한 뒤 비교하면 편할 때가 있다.

## 문자열 뒤집기

처음에는 고급 문법보다 반복문으로 해보는 것도 좋다.

```python
text = "abc"
result = ""

for ch in text:
    result = ch + result

print(result)
```

결과는 `cba`다.

## `in`

문자열 안에 특정 내용이 있는지 확인할 수 있다.

```python
text = "python"
print("py" in text)
print("java" in text)
```

결과는 `True`, `False`다.

## `split()`

```python
sentence = "사과 바나나 포도"
words = sentence.split()
print(words)
```

결과:

```python
['사과', '바나나', '포도']
```

문자열 문제에서 입력을 단어 단위로 나눌 때 자주 쓴다.

## 연습 문제

1. 문자열 하나를 입력받고 글자 수를 출력해 보기.
2. 입력된 문자열에서 `a`가 몇 개인지 세어 보기.
3. 입력 문자열을 한 글자씩 줄바꿈해서 출력해 보기.
4. 입력 문자열에 `python`이라는 단어가 들어 있는지 확인해 보기.
5. 문자열을 거꾸로 만들어 보기.

문제를 풀 때는 한 번에 정답 코드를 쓰려고 하지 말고, 먼저 `print()`로 한 글자씩 잘 꺼내지는지부터 확인하는 게 좋다.
