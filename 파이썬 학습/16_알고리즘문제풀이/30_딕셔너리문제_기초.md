# 30. 딕셔너리 문제 기초

딕셔너리는 **이름표와 값을 짝으로 저장하는 자료형**이다.

```python
student = {
    "name": "철수",
    "score": 90
}
```

여기서 `name`, `score`는 key이고 `철수`, `90`은 value다.

## 언제 딕셔너리를 떠올리면 좋을까?

문제에서 다음과 같은 상황이 나오면 딕셔너리를 생각해 볼 수 있다.

- 이름별 점수를 저장한다
- 상품별 가격을 저장한다
- 단어가 몇 번 나왔는지 센다
- 지역별 인원 수를 센다
- 메뉴 이름으로 가격을 찾는다

## 값 꺼내기

```python
menu = {
    "짜장면": 7000,
    "짬뽕": 8000
}

print(menu["짜장면"])
```

결과:

```text
7000
```

## 값 추가하기

```python
menu["탕수육"] = 18000
```

없는 key를 사용하면 새 항목이 추가된다.

## 기존 값 바꾸기

```python
menu["짜장면"] = 7500
```

이미 있는 key를 사용하면 값이 바뀐다.

## 단어 개수 세기

딕셔너리가 알고리즘 문제에서 자주 나오는 이유 중 하나다.

```python
words = ["사과", "바나나", "사과", "포도", "사과"]
count = {}

for word in words:
    if word in count:
        count[word] += 1
    else:
        count[word] = 1

print(count)
```

결과:

```text
{'사과': 3, '바나나': 1, '포도': 1}
```

생각 순서:

```text
사과 처음 등장 → 사과: 1
바나나 처음 등장 → 바나나: 1
사과 다시 등장 → 사과: 2
포도 처음 등장 → 포도: 1
사과 다시 등장 → 사과: 3
```

## `in`은 왜 쓰나?

```python
if word in count:
```

이 뜻은:

> 이 단어가 딕셔너리에 이미 있나?

이다.

## `get()`을 사용하는 방법

같은 개수 세기를 더 짧게 쓸 수도 있다.

```python
count[word] = count.get(word, 0) + 1
```

하지만 처음 배우는 동안에는 다음 코드가 더 이해하기 쉽다.

```python
if word in count:
    count[word] += 1
else:
    count[word] = 1
```

먼저 긴 방법을 이해하고 나중에 `get()`을 쓰는 것이 좋다.

## 딕셔너리 반복하기

key만 반복:

```python
for key in menu:
    print(key)
```

key와 value 같이 보기:

```python
for key, value in menu.items():
    print(key, value)
```

## 가장 많이 나온 값 찾기

```python
count = {
    "사과": 3,
    "바나나": 1,
    "포도": 2
}

best_word = ""
best_count = 0

for word, number in count.items():
    if number > best_count:
        best_count = number
        best_word = word

print(best_word)
print(best_count)
```

이 코드는 딕셔너리와 최댓값 찾기를 연결한 예다.

## 자주 하는 실수

### 없는 key를 바로 꺼내기

```python
menu["라면"]
```

`라면`이 없으면 `KeyError`가 난다.

그래서 먼저 확인할 수 있다.

```python
if "라면" in menu:
    print(menu["라면"])
```

또는:

```python
print(menu.get("라면"))
```

## 직접 연습

1. 학생 이름과 점수를 딕셔너리로 만들기
2. 메뉴 이름과 가격 저장하기
3. 단어 목록에서 각 단어의 개수 세기
4. 숫자 목록에서 각 숫자가 몇 번 나왔는지 세기
5. 가장 많이 나온 단어 찾기

딕셔너리 문제의 핵심은 **무엇을 key로 잡고 무엇을 value로 저장할지** 결정하는 것이다.
