# 29. 반복문 문제 기초

반복문 문제는 처음 보면 어렵지만 대부분은 **같은 일을 여러 번 시키는 문제**다.

## 가장 먼저 볼 것

문제에서 이런 표현이 나오면 반복문을 떠올린다.

- N번 반복한다
- 여러 숫자를 하나씩 확인한다
- 모든 학생의 점수를 검사한다
- 리스트의 모든 값을 더한다
- 한 줄씩 입력받는다

## 예제 1: 1부터 5까지 출력

```python
for i in range(1, 6):
    print(i)
```

`range(1, 6)`은 1, 2, 3, 4, 5를 만든다.

## 예제 2: 리스트 값 전부 출력

```python
numbers = [10, 20, 30]

for number in numbers:
    print(number)
```

반복할 때마다 `number` 안의 값이 바뀐다.

```text
1회 → 10
2회 → 20
3회 → 30
```

## 예제 3: 합계 구하기

```python
numbers = [10, 20, 30]
total = 0

for number in numbers:
    total += number

print(total)
```

`total`은 값을 계속 모으는 상자다.

처음:

```text
total = 0
```

10을 만난 뒤:

```text
total = 10
```

20을 만난 뒤:

```text
total = 30
```

30을 만난 뒤:

```text
total = 60
```

이런 방식을 **누적**이라고 많이 부른다.

## 예제 4: 조건과 같이 사용하기

짝수만 출력한다.

```python
numbers = [1, 2, 3, 4, 5, 6]

for number in numbers:
    if number % 2 == 0:
        print(number)
```

여기서는 반복문이 숫자를 하나씩 꺼내고, `if`가 그 숫자가 짝수인지 검사한다.

## 자주 나오는 구조

```python
total = 0

for value in data:
    if 조건:
        total += value
```

이 구조는 정말 자주 나온다.

의미는:

```text
값을 하나씩 확인한다
→ 조건에 맞는지 본다
→ 맞으면 합계에 더한다
```

## 몇 개인지 세기

```python
count = 0

for number in [1, 7, 10, 3, 12]:
    if number >= 10:
        count += 1

print(count)
```

`count += 1`은 조건에 맞는 값을 하나 찾을 때마다 개수를 1 증가시킨다는 뜻이다.

## 최댓값 찾기

처음에는 Python의 `max()`를 쓰지 않고 직접 해 보는 것도 도움이 된다.

```python
numbers = [5, 2, 9, 4]

largest = numbers[0]

for number in numbers:
    if number > largest:
        largest = number

print(largest)
```

생각 순서:

```text
일단 첫 번째 숫자를 가장 크다고 생각
→ 다음 숫자와 비교
→ 더 큰 숫자를 만나면 largest 교체
```

## 중첩 반복문

2차원 데이터에서는 반복문 안에 반복문이 들어갈 수 있다.

```python
board = [
    [1, 2, 3],
    [4, 5, 6]
]

for row in board:
    for number in row:
        print(number)
```

바깥쪽 `for`는 행을 하나씩 꺼내고, 안쪽 `for`는 그 행 안의 값을 하나씩 꺼낸다.

## 반복문 문제를 풀 때 종이에 먼저 적어 볼 것

```text
무엇을 반복하지?
몇 번 반복하지?
반복할 때마다 어떤 값이 바뀌지?
합계가 필요한가?
개수를 세야 하나?
조건이 필요한가?
```

## 초보가 자주 하는 실수

### 합계 변수를 반복문 안에서 0으로 만드는 경우

잘못된 예:

```python
for number in numbers:
    total = 0
    total += number
```

반복할 때마다 `total`이 다시 0이 되므로 이전 값이 사라진다.

보통은 이렇게 쓴다.

```python
total = 0

for number in numbers:
    total += number
```
