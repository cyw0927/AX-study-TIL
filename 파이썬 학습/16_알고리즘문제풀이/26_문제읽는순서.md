# 26. 알고리즘 문제는 어떤 순서로 읽나요?

알고리즘 문제를 처음 보면 코드보다 문제 설명이 더 무섭게 느껴질 수 있다. 숫자도 많고 입력 예제도 있고 조건도 길다.

이때 바로 코드를 쓰려고 하지 말고 **문제에서 시키는 일을 순서대로 잘라서 보는 것**이 좋다.

## 1. 입력이 뭔지 찾기

먼저 프로그램이 무엇을 받는지 본다.

예를 들어:

```text
첫 줄에 숫자 N이 주어진다.
둘째 줄에 N개의 정수가 주어진다.
```

그러면 머릿속에 이렇게 적어 본다.

```text
입력 1: N
입력 2: 숫자 N개
```

아직 코드는 생각하지 않아도 된다.

## 2. 출력이 뭔지 찾기

문제가 마지막에 무엇을 출력하라고 하는지 확인한다.

예:

```text
숫자의 합을 출력한다.
```

그러면 목표는 일단 이것이다.

```text
숫자 여러 개를 받는다
→ 더한다
→ 합을 출력한다
```

## 3. 예제를 손으로 계산하기

입력:

```text
5
1 2 3 4 5
```

손으로 계산하면:

```text
1 + 2 + 3 + 4 + 5 = 15
```

출력:

```text
15
```

코드보다 먼저 이 계산이 이해되어야 한다.

## 4. 한 단계씩 코드로 바꾸기

먼저 숫자를 직접 써서 해 본다.

```python
numbers = [1, 2, 3, 4, 5]
print(numbers)
```

그다음 합을 구한다.

```python
total = 0

for number in numbers:
    total += number

print(total)
```

마지막에 입력으로 바꾼다.

```python
N = int(input())
numbers = list(map(int, input().split()))
```

초보 단계에서는 **입력 코드부터 완성하려고 하지 않는 것**도 좋은 방법이다. 먼저 고정된 숫자로 계산이 되는지 확인하면 문제를 나눠서 볼 수 있다.

## 5. 변수의 역할을 말로 적기

예:

```python
N = 5
numbers = [1, 2, 3, 4, 5]
total = 0
```

각 변수는:

```text
N       = 숫자가 몇 개인지
numbers = 실제 숫자들
total   = 더한 결과를 저장할 값
```

이렇게 말로 설명할 수 있어야 한다.

## 6. 반복문이 왜 필요한지 보기

숫자 5개면 직접 이렇게 쓸 수도 있다.

```python
total = numbers[0] + numbers[1] + numbers[2] + numbers[3] + numbers[4]
```

하지만 숫자가 100개면 매우 힘들다.

그래서:

```python
for number in numbers:
    total += number
```

처럼 반복문을 사용한다.

## 7. 조건문이 필요한 문제

예를 들어 10 이상인 숫자만 세라고 한다면:

```python
count = 0

for number in numbers:
    if number >= 10:
        count += 1
```

흐름은:

```text
숫자 하나 꺼냄
→ 10 이상인지 확인
→ 맞으면 count를 1 늘림
→ 다음 숫자
```

## 8. 문제에서 자주 보는 표현 바꾸기

### "각각"

반복문이 필요할 가능성이 높다.

```text
각 학생의 점수
각 픽셀의 밝기
각 숫자를 확인
```

### "이상 / 이하"

비교 연산자를 확인한다.

```text
이상 = >=
이하 = <=
초과 = >
미만 = <
```

### "합"

누적 변수가 자주 필요하다.

```python
total = 0
```

### "개수"

카운트 변수가 자주 필요하다.

```python
count = 0
```

### "가장 큰 값"

최댓값을 찾는 문제일 수 있다.

```python
max_value = numbers[0]
```

## 9. 틀렸을 때 바로 전체 코드를 고치지 않기

예를 들어 결과가 이상하면 중간값을 출력한다.

```python
for number in numbers:
    total += number
    print("현재 number:", number)
    print("현재 total:", total)
```

이렇게 하면 어느 순간부터 값이 이상해지는지 볼 수 있다.

## 10. 문제 풀이 체크리스트

문제를 보면 다음 순서로 확인한다.

```text
1. 입력은 무엇인가?
2. 출력은 무엇인가?
3. 예제를 손으로 계산할 수 있는가?
4. 필요한 변수는 무엇인가?
5. 반복이 필요한가?
6. 조건이 필요한가?
7. 중간값은 무엇을 print해 볼 수 있는가?
8. 마지막 출력 형식이 정확한가?
```

## 가장 중요한 습관

처음부터 멋진 한 줄짜리 코드를 만들 필요가 없다.

```python
height, width = map(int, input().split())
```

이 한 줄이 어렵다면:

```python
text = input()
parts = text.split()
height = int(parts[0])
width = int(parts[1])
```

처럼 쪼개서 이해해도 된다.

코드를 짧게 쓰는 것보다 **무슨 일이 일어나는지 이해하는 것**이 먼저다.
