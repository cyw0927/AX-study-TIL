# 2차원 리스트 문제 기초

2차원 리스트는 **리스트 안에 리스트가 들어 있는 구조**다.

표, 좌표, 이미지, 게임판처럼 행과 열이 있는 데이터를 표현할 때 자주 쓴다.

## 가장 간단한 모양

```python
board = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

눈으로 보면:

```text
1 2 3
4 5 6
7 8 9
```

## 첫 번째 행 꺼내기

```python
print(board[0])
```

결과:

```text
[1, 2, 3]
```

## 한 칸 꺼내기

```python
print(board[1][2])
```

먼저 `board[1]`은 두 번째 행 `[4, 5, 6]`이다.

그 안의 `[2]`는 6이다.

## 왜 for문을 두 번 쓰나?

```python
for row in board:
    for value in row:
        print(value)
```

바깥 `for`는 행을 하나씩 꺼내고, 안쪽 `for`는 그 행 안의 값을 하나씩 꺼낸다.

## 행별 합계

```python
for row in board:
    total = 0
    for value in row:
        total += value
    print(total)
```

결과:

```text
6
15
24
```

중요한 점은 `total = 0`의 위치다.

행마다 새로 합계를 계산하려면 바깥 반복문 안에서 0으로 초기화해야 한다.

## 전체 합계

```python
total = 0

for row in board:
    for value in row:
        total += value

print(total)
```

이번에는 `total = 0`이 반복문 밖에 있다.

## 인덱스로 접근하기

```python
height = len(board)
width = len(board[0])

for r in range(height):
    for c in range(width):
        print(r, c, board[r][c])
```

여기서:

```text
r = 행 번호
c = 열 번호
```

이라고 생각하면 된다.

## 이미지 문제와 연결

RGB 이미지 데이터도 이런 식으로 여러 행과 여러 픽셀로 생각할 수 있다.

```text
첫 번째 행 → 픽셀 여러 개
두 번째 행 → 픽셀 여러 개
세 번째 행 → 픽셀 여러 개
```

그래서 이미지 알고리즘에서 중첩 `for`문이 자주 나온다.

## 자주 하는 실수

### 행과 열 순서를 반대로 생각함

보통 `board[row][column]` 순서다.

### 매 행마다 초기화해야 할 변수를 밖에 둠

행별 결과를 만들 때는 위치를 잘 봐야 한다.

```python
results = []

for row in board:
    row_total = 0
    for value in row:
        row_total += value
    results.append(row_total)
```

## 직접 연습

```python
numbers = [
    [10, 20],
    [30, 40],
    [50, 60]
]

for row in numbers:
    print("행:", row)
    for value in row:
        print("값:", value)
```
