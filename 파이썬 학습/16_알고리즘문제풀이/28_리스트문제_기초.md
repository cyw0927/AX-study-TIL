# 리스트 문제 기초

리스트 문제는 여러 값을 저장해 두고 합계, 평균, 최댓값, 조건에 맞는 값 개수 등을 구하는 경우가 많다.

## 리스트 만들기

```python
numbers = [10, 20, 30, 40]
```

## 하나씩 꺼내기

```python
for number in numbers:
    print(number)
```

## 합계 구하기

처음에는 `sum()`보다 반복문으로 직접 해보면 흐름을 이해하기 좋다.

```python
numbers = [10, 20, 30]
total = 0

for number in numbers:
    total += number

print(total)
```

## 평균 구하기

```python
average = total / len(numbers)
print(average)
```

## 조건에 맞는 값 세기

```python
numbers = [10, 80, 55, 30, 90]
count = 0

for number in numbers:
    if number >= 60:
        count += 1

print(count)
```

60 이상인 값이 몇 개인지 센다.

## 최댓값 직접 찾기

```python
numbers = [30, 10, 70, 20]
max_value = numbers[0]

for number in numbers:
    if number > max_value:
        max_value = number

print(max_value)
```

처음 값을 기준으로 잡고 더 큰 값이 나오면 바꾸는 방식이다.

## 인덱스가 필요할 때

```python
foods = ["짜장면", "짬뽕", "탕수육"]

for i in range(len(foods)):
    print(i, foods[i])
```

하지만 단순히 번호와 값을 같이 보고 싶다면 `enumerate()`가 더 읽기 쉽다.

```python
for i, food in enumerate(foods):
    print(i, food)
```

## 리스트에 값 추가하기

```python
result = []

for number in [1, 2, 3]:
    result.append(number * 2)

print(result)
```

결과는 `[2, 4, 6]`이다.

## 연습 문제

1. 숫자 5개를 리스트에 넣고 모두 출력하기.
2. 숫자들의 합계를 구하기.
3. 평균을 구하기.
4. 50 이상인 숫자 개수를 세기.
5. 가장 큰 숫자를 찾기.
6. 짝수만 새 리스트에 담기.

막히면 먼저 리스트가 제대로 만들어졌는지 `print(numbers)`부터 확인한다.
