# 08. 중첩 반복문 더 자세히

중첩 반복문은 **반복문 안에 반복문이 들어 있는 것**이다.

처음 보면 복잡하지만, 바깥 반복문이 한 번 돌 때 안쪽 반복문이 처음부터 끝까지 돈다고 생각하면 된다.

## 가장 작은 예제

```python
for i in range(2):
    for j in range(3):
        print(i, j)
```

결과:

```text
0 0
0 1
0 2
1 0
1 1
1 2
```

왜 이렇게 나올까?

바깥 `i = 0`일 때 안쪽 `j`는 0, 1, 2를 전부 돈다.
그 다음 바깥 `i = 1`이 되고 다시 `j`가 0, 1, 2를 돈다.

## 순서를 글로 쓰면

```text
i = 0
  j = 0
  j = 1
  j = 2

i = 1
  j = 0
  j = 1
  j = 2
```

## 2차원 리스트와 같이 쓰기

```python
board = [
    [1, 2, 3],
    [4, 5, 6]
]

for row in board:
    for number in row:
        print(number)
```

바깥 반복문은 한 행을 고른다.
안쪽 반복문은 그 행 안의 숫자를 하나씩 꺼낸다.

## 행과 열 번호가 필요할 때

```python
board = [
    [10, 20, 30],
    [40, 50, 60]
]

for r in range(2):
    for c in range(3):
        print(r, c, board[r][c])
```

여기서 `r`은 행 번호, `c`는 열 번호처럼 쓸 수 있다.

## `len()`을 같이 쓰면 더 안전하다

```python
for r in range(len(board)):
    for c in range(len(board[r])):
        print(board[r][c])
```

행과 열 개수를 직접 2, 3처럼 적지 않아도 된다.

## 누적합과 같이 쓰기

```python
board = [
    [1, 2, 3],
    [4, 5, 6]
]

total = 0

for row in board:
    for number in row:
        total += number

print(total)
```

결과는 `21`이다.

## 자주 하는 실수 1: 안쪽 변수 이름 헷갈리기

```python
for row in board:
    for number in row:
        print(row)
```

이 코드는 숫자 하나가 아니라 행 전체를 계속 출력한다.
숫자를 보고 싶으면 `print(number)`여야 한다.

## 자주 하는 실수 2: 들여쓰기

```python
for row in board:
    for number in row:
        print(number)
    print("한 행 끝")
```

`print("한 행 끝")`은 안쪽 반복문이 끝날 때마다 한 번 실행된다.

## 중첩 반복문을 읽는 요령

한 번에 두 개를 보지 말고 이렇게 읽는다.

```text
1. 바깥 반복문이 무엇을 하나씩 꺼내는가?
2. 그 하나 안에서 안쪽 반복문이 무엇을 꺼내는가?
3. 실제 계산은 어느 반복문 안에서 이루어지는가?
```

2차원 데이터, 이미지 픽셀, 표 형태 데이터를 다룰 때 자주 나온다.
