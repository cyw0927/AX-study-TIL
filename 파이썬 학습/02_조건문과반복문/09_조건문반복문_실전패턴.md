# 09. 조건문과 반복문 실전 패턴

조건문과 반복문은 따로 배우지만 실제 코드에서는 같이 쓰는 경우가 많다.

예를 들어 여러 학생의 점수와 출석률을 검사한다고 해보자.

```python
students = [
    {"name": "조조", "score": 100, "attendance": 100},
    {"name": "유비", "score": 33, "attendance": 4},
    {"name": "손권", "score": 64, "attendance": 77},
    {"name": "제갈량", "score": 88, "attendance": 84}
]
```

리스트 안에 딕셔너리가 여러 개 들어 있는 구조다.

## 1. for로 학생 한 명씩 꺼내기

```python
for student in students:
    print(student)
```

`student`에는 반복할 때마다 학생 한 명의 딕셔너리가 들어온다.

## 2. 딕셔너리에서 필요한 값 꺼내기

```python
for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]
```

즉:

```text
student
-> 학생 한 명의 전체 정보

student["name"]
-> 그 학생의 이름
```

## 3. if / elif / else

```python
if score < 60 or attendance < 70:
    grade = "F"
elif score >= 95 and attendance >= 80:
    grade = "A+"
else:
    grade = "PASS"
```

`elif`는 말 그대로 `else if`라고 생각하면 된다.

```text
if
-> 첫 번째 조건

elif
-> 앞 조건이 아니면 다음 조건 확인

else
-> 위 조건에 모두 해당하지 않으면 실행
```

## 4. 조건 순서가 중요한 이유

조건문은 위에서 아래로 검사한다.

예를 들어:

```python
score = 100

if score >= 60:
    grade = "PASS"
elif score >= 95:
    grade = "A+"
```

이 경우 100점이어도 첫 번째 조건에서 이미 참이므로 `PASS`가 된다.

그래서 더 구체적인 조건을 위에 두는 것이 좋다.

```python
if score >= 95:
    grade = "A+"
elif score >= 60:
    grade = "PASS"
else:
    grade = "F"
```

## 5. and와 or

```python
if score >= 95 and attendance >= 80:
```

두 조건이 모두 참이어야 한다.

```python
if score < 60 or attendance < 70:
```

둘 중 하나만 참이어도 된다.

## 6. 반복문 안의 조건문

실전에서는 이런 구조가 매우 자주 나온다.

```python
for student in students:
    name = student["name"]
    score = student["score"]
    attendance = student["attendance"]

    if score < 60 or attendance < 70:
        grade = "F"
    elif score >= 95 and attendance >= 80:
        grade = "A+"
    else:
        grade = "PASS"

    print(name, grade)
```

읽는 순서:

```text
학생을 한 명 꺼낸다
↓
이름, 점수, 출석률을 꺼낸다
↓
조건을 검사한다
↓
등급을 정한다
↓
출력한다
↓
다음 학생으로 이동한다
```

## 7. 들여쓰기 오류

파이썬에서는 들여쓰기가 문법이다.

```python
for student in students:
    print(student)
```

위 코드는 정상이다.

하지만:

```python
for student in students:
print(student)
```

처럼 쓰면 오류가 난다.

## 핵심

조건문과 반복문을 따로 외우기보다 다음 흐름으로 이해한다.

```text
for
-> 여러 개를 하나씩 꺼냄

if / elif / else
-> 꺼낸 값을 조건에 따라 분류
```

실제 데이터 처리에서도 이 사고방식은 계속 사용된다.
