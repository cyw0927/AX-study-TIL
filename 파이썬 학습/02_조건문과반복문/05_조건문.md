# 05. 조건문 if

조건문은 **조건이 맞을 때만 특정 코드를 실행하는 문법**이다.

## 가장 기본적인 if

```python
age = 20

if age >= 19:
    print("성인입니다")
```

읽는 방법:

> 만약 age가 19 이상이라면 `성인입니다`를 출력한다.

## 조건이 거짓이면?

```python
age = 15

if age >= 19:
    print("성인입니다")
```

아무것도 출력되지 않는다.

## `else`

조건이 거짓일 때 실행할 코드를 적는다.

```python
age = 15

if age >= 19:
    print("성인")
else:
    print("미성년자")
```

## `elif`

조건이 여러 개일 때 사용한다.

```python
score = 85

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("D")
```

Python은 위에서부터 조건을 확인하고 처음으로 참이 된 부분을 실행한다.

## 비교 연산자

```text
==  같다
!=  다르다
>   크다
<   작다
>=  이상
<=  이하
```

예:

```python
x = 10

print(x == 10)
print(x != 10)
print(x >= 5)
```

## `and`

두 조건이 모두 참이어야 한다.

```python
age = 25
money = 10000

if age >= 19 and money >= 5000:
    print("조건 통과")
```

## `or`

둘 중 하나만 참이어도 된다.

```python
is_student = True
is_teacher = False

if is_student or is_teacher:
    print("학교 구성원")
```

## `not`

참과 거짓을 뒤집는다.

```python
is_raining = False

if not is_raining:
    print("비가 안 옵니다")
```

## 들여쓰기

Python에서는 들여쓰기가 문법이다.

```python
if 10 > 5:
    print("실행됨")
```

아래처럼 쓰면 오류가 난다.

```python
if 10 > 5:
print("실행됨")
```

보통 스페이스 4칸을 사용한다.

## 조건문 안에 조건문

```python
age = 25
money = 10000

if age >= 19:
    if money >= 5000:
        print("둘 다 만족")
```

처음에는 너무 많이 겹쳐 쓰지 않는 것이 좋다.

## 자주 하는 실수

### `=`와 `==` 혼동

```python
if x == 10:
```

조건 비교에는 `==`를 쓴다.

### `>`와 `>=` 혼동

`10 이상`이면 10도 포함하므로 `>= 10`이다.

`10 초과`면 10은 포함하지 않으므로 `> 10`이다.

## 직접 연습

```python
number = int(input("숫자 입력: "))

if number > 0:
    print("양수")
elif number == 0:
    print("0")
else:
    print("음수")
```

5, 0, -3을 각각 넣어 결과를 확인해 본다.
