# 07. 문자열 — 글자를 다루는 방법

문자열은 글자나 문장을 다루는 자료형이다. Python에서는 따옴표 안에 들어 있는 값을 문자열이라고 생각하면 된다.

```python
name = "철수"
message = '안녕하세요'
```

둘 다 문자열이다.

## 1. 따옴표는 왜 쓰나?

Python은 `철수`라고만 쓰면 이것을 변수 이름으로 볼 수 있다. 그래서 글자 자체를 뜻한다는 표시로 따옴표를 붙인다.

```python
name = "철수"
print(name)
```

결과:

```text
철수
```

## 2. 숫자처럼 생겨도 문자열일 수 있다

```python
a = "100"
b = 100

print(type(a))
print(type(b))
```

결과:

```text
<class 'str'>
<class 'int'>
```

화면에는 둘 다 100처럼 보이지만 완전히 다른 자료형이다.

## 3. 문자열 더하기

문자열끼리 `+`를 하면 계산이 아니라 이어 붙인다.

```python
first = "안녕"
second = "하세요"
print(first + second)
```

결과:

```text
안녕하세요
```

숫자 문자열도 마찬가지다.

```python
print("2" + "3")
```

결과:

```text
23
```

숫자 계산을 하고 싶다면 `int()`로 바꿔야 한다.

```python
print(int("2") + int("3"))
```

결과는 `5`다.

## 4. 문자열의 글자 하나 꺼내기

문자열도 리스트처럼 순서 번호를 사용할 수 있다.

```python
word = "python"
print(word[0])
print(word[1])
```

결과:

```text
p
y
```

Python은 첫 번째를 0번부터 센다.

## 5. 문자열 길이 `len()`

```python
word = "hello"
print(len(word))
```

결과는 `5`다.

## 6. `split()` — 문자열 나누기

```python
text = "사과 바나나 포도"
print(text.split())
```

결과:

```python
['사과', '바나나', '포도']
```

공백을 기준으로 나눈 것이다.

쉼표를 기준으로 나누고 싶다면:

```python
pixel = "255,0,0"
print(pixel.split(","))
```

결과:

```python
['255', '0', '0']
```

## 7. `strip()` — 앞뒤 공백 지우기

```python
text = "   hello   "
print(text.strip())
```

결과는 `hello`다.

문자열 앞뒤의 불필요한 공백을 제거할 때 쓴다.

## 8. `replace()` — 글자 바꾸기

```python
text = "나는 사과를 좋아한다"
print(text.replace("사과", "바나나"))
```

결과:

```text
나는 바나나를 좋아한다
```

## 9. `in` — 포함되어 있는지 확인하기

```python
text = "python 공부"
print("python" in text)
```

결과:

```text
True
```

## 10. f-string — 변수와 글자를 같이 출력하기

```python
name = "철수"
age = 20

print(f"이름은 {name}이고 나이는 {age}살입니다.")
```

결과:

```text
이름은 철수이고 나이는 20살입니다.
```

`f`를 따옴표 앞에 붙이고 `{}` 안에 변수를 넣는다.

## 처음에는 이것만 기억

- 따옴표 안의 값은 문자열이다.
- 문자열끼리 `+`하면 이어 붙는다.
- `split()`은 문자열을 나눈다.
- `strip()`은 앞뒤 공백을 없앤다.
- 문자열도 `[0]`, `[1]`처럼 한 글자씩 꺼낼 수 있다.
- 숫자처럼 보여도 문자열이면 계산 전에 `int()`가 필요하다.
