# 13. 파일 읽기와 쓰기

Python은 메모장 파일 같은 텍스트 파일을 읽거나 새로 만들 수 있다.

## 파일 열기 `open()`

```python
file = open("memo.txt", "r", encoding="utf-8")
```

여기서:

- `memo.txt` : 파일 이름
- `"r"` : 읽기 모드
- `encoding="utf-8"` : 한글 같은 문자를 정상적으로 읽기 위한 인코딩 설정

## 파일 내용 전체 읽기

```python
file = open("memo.txt", "r", encoding="utf-8")
text = file.read()
print(text)
file.close()
```

## `close()`를 왜 하나?

파일 사용이 끝났다고 운영체제에 알려주는 것이다.

하지만 초보 단계에서는 `with`를 쓰는 방법이 더 편하다.

## `with open(...)`

```python
with open("memo.txt", "r", encoding="utf-8") as file:
    text = file.read()
    print(text)
```

`with` 블록이 끝나면 파일을 자동으로 닫아 준다.

## 한 줄씩 읽기

```python
with open("memo.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line)
```

## 줄 끝 공백 없애기

파일에서 한 줄을 읽으면 줄바꿈 문자 `\n`이 같이 들어올 수 있다.

```python
with open("memo.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

## 파일 쓰기 `w`

```python
with open("result.txt", "w", encoding="utf-8") as file:
    file.write("안녕하세요")
```

`w`는 새로 쓰기 모드다.

주의: 같은 이름의 파일이 이미 있으면 기존 내용을 덮어쓸 수 있다.

## 줄바꿈 넣기

```python
with open("result.txt", "w", encoding="utf-8") as file:
    file.write("첫 번째 줄\n")
    file.write("두 번째 줄\n")
```

## 이어쓰기 `a`

기존 내용을 지우지 않고 뒤에 추가한다.

```python
with open("result.txt", "a", encoding="utf-8") as file:
    file.write("새로운 줄\n")
```

## 파일 경로

```python
open("memo.txt")
```

이라고 쓰면 현재 실행 위치에서 `memo.txt`를 찾는다.

파일이 다른 폴더에 있다면 경로를 적어야 한다.

```python
open("data/memo.txt")
```

Windows에서는 경로 때문에 헷갈릴 수 있어서 현재 폴더를 먼저 확인하는 습관이 좋다.

## `FileNotFoundError`

```python
with open("없는파일.txt", "r", encoding="utf-8") as file:
    print(file.read())
```

파일을 찾을 수 없으면 오류가 난다.

이때 확인할 것:

1. 파일 이름이 정확한가?
2. 확장자가 맞는가?
3. 현재 터미널 위치가 맞는가?
4. 상대경로가 맞는가?

## CSV도 결국 파일이다

CSV 파일은 보통 쉼표로 구분된 텍스트 데이터다.

```text
name,score
철수,80
영희,90
```

Python 기본 기능으로 읽을 수도 있지만, 표 데이터는 보통 pandas를 사용하면 더 편하다.
