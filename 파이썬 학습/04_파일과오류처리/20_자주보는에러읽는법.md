# 20. 자주 보는 파이썬 에러 읽는 법

파이썬을 배우면서 가장 답답한 순간은 코드가 틀렸다는 것보다 **에러 메시지가 무슨 말인지 모를 때**다.

하지만 에러는 대부분 몇 가지 패턴으로 반복된다.

중요한 것은 에러 전체를 겁내지 말고 **마지막 줄부터 보는 습관**이다.

---

## 1. 에러는 마지막 줄부터 본다

예를 들어:

```text
Traceback (most recent call last):
  ...
  ...
ModuleNotFoundError: No module named 'src'
```

제일 중요한 부분은 마지막 줄이다.

```text
ModuleNotFoundError
```

그리고 뒤에 붙은 설명을 본다.

```text
No module named 'src'
```

즉 `src`라는 모듈을 못 찾았다는 뜻이다.

---

## 2. ModuleNotFoundError

```text
ModuleNotFoundError: No module named 'src'
```

뜻:

```text
import하려는 모듈을 파이썬이 찾지 못함
```

먼저 확인:

```python
from pathlib import Path
import sys

print(Path.cwd())
print(sys.path)
```

주요 원인:

```text
현재 실행 위치가 예상과 다름
프로젝트 루트가 import 경로에 없음
파일/폴더 이름이 다름
가상환경이 다름
패키지가 설치되지 않음
```

---

## 3. ImportError

예:

```text
ImportError: cannot import name 'DATA_DIR' from 'paths'
```

모듈 자체는 찾았지만 그 안에서 원하는 이름을 못 찾은 경우다.

확인할 것:

```text
DATA_DIR이 실제로 정의되어 있는가?
이름 철자가 정확한가?
다른 paths.py를 불러온 것은 아닌가?
순환 import가 생긴 것은 아닌가?
```

---

## 4. KeyError

pandas에서 매우 자주 본다.

```text
KeyError: 'city'
```

뜻:

```text
city라는 컬럼 또는 키를 찾지 못함
```

바로 확인:

```python
print(df.columns.tolist())
```

그리고:

```python
print([repr(col) for col in df.columns])
```

도 확인할 수 있다.

숨은 공백이 있을 수도 있기 때문이다.

---

## 5. TypeError

예:

```text
TypeError: can only concatenate str (not "int") to str
```

문자열과 숫자를 잘못 섞은 경우다.

```python
age = "30"
print(age + 5)
```

해결:

```python
print(int(age) + 5)
```

헷갈리면:

```python
print(type(age))
```

부터 본다.

---

## 6. ValueError

형식은 맞는 것 같지만 값 자체가 변환에 맞지 않을 때 자주 나온다.

```python
int("삼십")
```

이런 값은 정수로 바꿀 수 없다.

pandas에서는 다음처럼 처리하기도 한다.

```python
pd.to_numeric(
    df["price"],
    errors="coerce"
)
```

단, 실패한 값이 `NaN`이 되므로 반드시 확인한다.

```python
print(df["price"].isna().sum())
```

---

## 7. NameError

```text
NameError: name 'customers' is not defined
```

뜻:

```text
customers라는 변수를 아직 만들지 않았거나
현재 실행 환경에 존재하지 않음
```

Notebook에서는 위 셀을 실행하지 않았을 때도 자주 생긴다.

---

## 8. AttributeError

```text
AttributeError: 'list' object has no attribute 'columns'
```

뜻:

```text
지금 변수는 DataFrame이 아니라 list인데
DataFrame용 기능을 쓰려고 함
```

확인:

```python
print(type(data))
```

---

## 9. SyntaxError

문법 자체가 틀린 경우다.

예:

```python
if score >= 60
    print("합격")
```

콜론 `:`이 빠졌다.

```python
if score >= 60:
    print("합격")
```

처럼 고쳐야 한다.

---

## 10. IndentationError

들여쓰기가 잘못됐을 때 발생한다.

```python
if score >= 60:
print("합격")
```

수정:

```python
if score >= 60:
    print("합격")
```

파이썬에서는 들여쓰기도 문법이다.

---

## 11. pandas에서 결과가 안 나오는 것은 에러가 아닐 수도 있다

예를 들어:

```python
result = df[df["age"] == 30]
```

실행은 됐는데 빈 DataFrame이 나올 수 있다.

이건 코드 오류라기보다 실제 데이터에 30이 없을 수도 있다.

확인:

```python
print(df["age"].value_counts(dropna=False))
```

즉:

```text
오류가 발생함
!=
결과가 비어 있음
```

이다.

---

## 12. 오류를 만났을 때 확인 순서

```text
1. 에러 마지막 줄 확인
2. 에러 종류 확인
3. 문제가 난 변수 type 확인
4. 컬럼명/키 확인
5. 현재 경로 확인
6. 실제 값 확인
7. 직전에 바꾼 코드 확인
```

자주 쓰는 확인 코드:

```python
print(type(value))
print(df.shape)
print(df.columns.tolist())
print(df.dtypes)
print(df.isna().sum())
```

경로 문제라면:

```python
from pathlib import Path
import sys

print(Path.cwd())
print(sys.path)
```

---

## 핵심

에러 메시지는 전부 읽으려고 하지 말고 먼저 마지막 줄을 본다.

```text
무슨 에러인가?
↓
무엇을 못 찾았거나 잘못 사용했는가?
↓
해당 변수, 타입, 컬럼, 경로를 직접 확인한다.
```

코드를 무작정 바꾸는 것보다 **현재 상태를 출력해서 확인하는 습관**이 더 중요하다.
