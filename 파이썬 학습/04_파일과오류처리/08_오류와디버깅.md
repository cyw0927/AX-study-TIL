# 08. 오류 메시지와 디버깅

코드를 배우다 보면 오류는 반드시 만난다. 오류가 뜨는 것은 이상한 일이 아니라 **Python이 어디가 문제인지 알려주는 것**이다.

## 디버깅이란?

코드에서 문제를 찾아 고치는 과정을 디버깅이라고 한다.

처음에는 오류 메시지가 길어서 무섭게 보이지만, 전부 읽으려고 하지 않아도 된다.

가장 먼저 볼 것은 보통 마지막 줄이다.

## `SyntaxError`

문법을 잘못 썼을 때 자주 나온다.

```python
print("hello"
```

괄호를 닫지 않았다.

또는:

```python
if 10 > 5
    print("yes")
```

콜론 `:`이 빠졌다.

## `NameError`

없는 변수 이름을 사용했을 때 나온다.

```python
print(age)
```

`age`를 만들지 않았다면 오류가 난다.

오타도 자주 원인이다.

```python
name = "철수"
print(nmae)
```

## `TypeError`

자료형이 맞지 않는 연산을 했을 때 자주 나온다.

```python
age = "20"
print(age + 1)
```

문자열과 정수를 더하려 해서 오류가 난다.

이럴 때:

```python
print(type(age))
```

로 자료형을 확인하면 도움이 된다.

## `ValueError`

자료형 변환은 가능한 종류지만 실제 값이 변환될 수 없을 때 자주 나온다.

```python
number = int("abc")
```

`abc`는 정수로 바꿀 수 없다.

## `IndexError`

리스트에 없는 위치를 찾았을 때 나온다.

```python
numbers = [10, 20, 30]
print(numbers[5])
```

리스트에는 0, 1, 2번만 있다.

## `KeyError`

딕셔너리에 없는 key를 대괄호 방식으로 찾았을 때 나온다.

```python
student = {"name": "철수"}
print(student["age"])
```

## `FileNotFoundError`

열려고 한 파일을 찾지 못했을 때 나온다.

```python
open("없는파일.txt")
```

파일 이름이나 현재 폴더 위치를 확인한다.

## `IndentationError`

들여쓰기가 잘못되었을 때 나온다.

```python
if True:
print("hello")
```

## Traceback은 어떻게 보나?

예를 들어 오류가 길게 나와도 마지막 부분에 이런 식으로 적힌다.

```text
ValueError: invalid literal for int() with base 10: 'abc'
```

처음에는 `ValueError`와 `'abc'`만 봐도 힌트가 된다.

## 초보 디버깅 1단계: print 찍기

```python
text = "255,0,0"
parts = text.split(',')

print("text:", text)
print("parts:", parts)
print("type(parts):", type(parts))
print("첫 값:", parts[0])
print("첫 값 자료형:", type(parts[0]))
```

중간값을 출력하면 어디까지 정상인지 확인할 수 있다.

## 초보 디버깅 2단계: 코드를 줄이기

긴 코드에서 오류가 나면 전체를 한꺼번에 고치려 하지 않는다.

예를 들어 입력 처리 문제라면 계산과 출력은 잠시 빼고 입력 부분만 실행해 본다.

```python
line = "3 3"
parts = line.split()
print(parts)
```

그 다음:

```python
height, width = map(int, parts)
print(height, width)
```

처럼 한 단계씩 늘린다.

## 초보 디버깅 3단계: `type()`과 `len()` 확인

```python
print(type(value))
print(len(values))
```

문자열인지 숫자인지, 리스트 길이가 예상한 만큼인지 확인한다.

## 프로그램이 멈춘 것처럼 보일 때

`input()`에서 입력을 기다리고 있을 수도 있다.

```python
name = input()
```

이 줄에서 프로그램은 사용자가 Enter를 칠 때까지 기다린다.

이 상태에서 `Ctrl + C`를 누르면 `KeyboardInterrupt`가 보일 수 있다. 이것은 반드시 코드 자체의 버그라는 뜻은 아니다.

## 직접 연습

아래 코드는 일부러 오류가 있다.

```python
age = "20"
print(age + 1)
```

바로 고치기 전에 먼저:

```python
print(type(age))
```

를 추가해서 원인을 확인한다.

그 다음 `int(age)`를 사용해 고쳐 본다.
