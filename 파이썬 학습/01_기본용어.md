# 01. 가장 먼저 알아야 할 기본 용어

Python을 처음 보면 영어 단어와 괄호가 너무 많이 나와서 코드가 외계어처럼 보일 수 있다. 이 문서는 가장 자주 보는 것부터 아주 쉽게 설명한다.

## 1. `print()`

`print()`는 **화면에 값을 보여주는 함수**다.

```python
print("안녕하세요")
```

결과:

```text
안녕하세요
```

숫자도 출력할 수 있다.

```python
print(10)
print(3 + 5)
```

결과:

```text
10
8
```

초보 때 `print()`가 중요한 이유는 단순히 결과를 보여주기 위해서만이 아니다. **지금 변수 안에 무엇이 들어 있는지 확인할 때 가장 많이 쓰는 도구**이기 때문이다.

---

## 2. `input()`

`input()`은 **사용자가 키보드로 입력한 값을 받는 함수**다.

```python
name = input()
print(name)
```

프로그램을 실행하면 입력을 기다린다. 사용자가 `철수`라고 입력하면 `name`에 `"철수"`가 저장된다.

중요한 점은 `input()`으로 받은 값은 기본적으로 **문자열**이라는 것이다.

```python
age = input()
print(type(age))
```

사용자가 `20`을 입력해도 결과는:

```text
<class 'str'>
```

이다.

숫자로 계산하려면 다음처럼 바꾼다.

```python
age = int(input())
```

---

## 3. 변수

변수는 **값을 담아 두고 이름을 붙인 것**이라고 생각하면 쉽다.

```python
age = 20
```

뜻은 대충 이렇게 이해하면 된다.

> `age`라는 이름으로 20을 기억해 둔다.

나중에:

```python
print(age)
```

하면 20이 나온다.

변수의 값은 바꿀 수도 있다.

```python
age = 20
age = 30
print(age)
```

결과는 30이다.

---

## 4. `=`

Python의 `=`는 수학에서 말하는 '같다'와 조금 다르다.

```python
x = 10
```

이 코드는 **오른쪽의 10을 왼쪽의 x에 저장한다**는 뜻이다.

그래서 처음에는 다음처럼 읽어도 된다.

> x에 10을 넣는다.

---

## 5. `==`

`==`는 **두 값이 같은지 비교**하는 기호다.

```python
print(10 == 10)
print(10 == 5)
```

결과:

```text
True
False
```

정리:

```text
=   값을 저장한다
==  같은지 물어본다
```

이 둘을 혼동하면 조건문에서 오류가 나기 쉽다.

---

## 6. 문자열 `str`

문자열은 글자 데이터다.

```python
name = "철수"
```

`"철수"`가 문자열이다.

숫자처럼 생겼어도 따옴표가 있으면 문자열이다.

```python
a = "100"
```

이것은 숫자 100이 아니라 글자 `"100"`이다.

그래서:

```python
print("2" + "3")
```

결과는 5가 아니라:

```text
23
```

이다. 문자열끼리 `+`를 하면 이어 붙이기 때문이다.

---

## 7. 정수 `int`

정수는 소수점이 없는 숫자다.

```text
0
10
-3
1000
```

문자열 숫자를 실제 숫자로 바꿀 때도 `int()`를 사용한다.

```python
number = int("100")
print(number + 1)
```

결과:

```text
101
```

---

## 8. 실수 `float`

실수는 소수점이 있는 숫자다.

```python
pi = 3.14
score = 92.5
```

나눗셈을 하면 `float`가 자주 나온다.

```python
print(10 / 4)
```

결과:

```text
2.5
```

---

## 9. `type()`

`type()`은 **값의 종류를 확인**하는 함수다.

```python
a = "100"
b = 100

print(type(a))
print(type(b))
```

결과:

```text
<class 'str'>
<class 'int'>
```

오류가 났는데 이유를 모르겠으면 `type()`으로 자료형을 확인하는 습관이 도움이 된다.

---

## 10. `True`와 `False`

`True`는 참, `False`는 거짓이다.

```python
print(10 > 5)
print(10 < 5)
```

결과:

```text
True
False
```

조건문은 이 참/거짓 결과를 이용해서 실행할 코드를 정한다.

---

## 11. 주석 `#`

`#` 뒤의 글자는 Python이 실행하지 않는다.

```python
# 이 줄은 설명이다
age = 20  # age에 20 저장
```

주석은 코드를 설명하기 위해 쓴다.

하지만 모든 줄을 한국어로 그대로 번역하듯 주석을 달 필요는 없다. **왜 이렇게 했는지 헷갈리는 부분에 쓰는 것이 더 좋다.**

---

## 12. 괄호 `()`

함수를 사용할 때 자주 보인다.

```python

type(100)
```

`print`, `int`, `type` 뒤에 있는 괄호 안에 함수에게 줄 값을 넣는다.

처음에는 이렇게 생각해도 된다.

## 13. 코드 블록과 들여쓰기

Python은 들여쓰기가 매우 중요하다.

```python
if 10 > 5:
    print("맞음")
```

`print()` 앞에 빈칸이 들어가 있다.

이 들여쓰기는 `print()`가 `if` 안에 들어 있다는 뜻이다.

잘못 쓰면:

```python
if 10 > 5:
print("맞음")
```

오류가 난다.

---

## 14. 함수

함수는 **어떤 일을 하도록 만들어 놓은 코드 묶음**이다.

이미 사용하고 있는 `print()`, `input()`, `int()`도 모두 함수다.

직접 만들 수도 있다.

```python
def hello():
    print("안녕")
```

그리고:

```python
hello()
```

라고 하면 함수 안의 코드가 실행된다.

함수는 04편에서 더 자세히 다룬다.

---

## 15. 지금 당장 기억할 것

처음부터 모든 내용을 외울 필요는 없다. 일단 아래만 익숙해져도 된다.

```python
print()    # 보여주기
input()    # 입력받기
int()      # 정수로 바꾸기
type()     # 자료형 확인하기
=          # 저장하기
==         # 같은지 비교하기
str        # 문자열
int        # 정수
float      # 실수
```

다음 편에서는 여러 값을 한꺼번에 저장하는 **리스트**를 중심으로 설명한다.
