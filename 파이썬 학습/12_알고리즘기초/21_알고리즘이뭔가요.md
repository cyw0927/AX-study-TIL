# 21. 알고리즘이 뭔가요?

알고리즘이라는 말은 어렵게 들리지만, 아주 쉽게 말하면 **문제를 푸는 순서**다.

라면을 끓이는 것도 순서가 있다.

```text
1. 물을 끓인다.
2. 면을 넣는다.
3. 스프를 넣는다.
4. 기다린다.
5. 먹는다.
```

컴퓨터 문제도 비슷하다.

예를 들어 숫자 3개의 평균을 구한다면:

```text
1. 숫자 3개를 받는다.
2. 세 숫자를 더한다.
3. 3으로 나눈다.
4. 결과를 출력한다.
```

이 순서가 알고리즘이다.

## 코드를 바로 쓰지 말고 순서부터 적기

```python
a = 10
b = 20
c = 30

# 1. 합계
sum_value = a + b + c

# 2. 평균
average = sum_value / 3

# 3. 출력
print(average)
```

복잡한 문제일수록 먼저 한국말로 순서를 적는 것이 좋다.

## 입력 → 처리 → 출력

초보 때는 대부분의 문제를 세 덩어리로 보면 편하다.

```text
입력: 무엇을 받는가?
처리: 받은 값으로 무엇을 계산하는가?
출력: 마지막에 무엇을 보여주는가?
```

예를 들어 짝수 판별:

```text
입력: 숫자 하나
처리: 2로 나눈 나머지가 0인지 확인
출력: 짝수 또는 홀수
```

코드:

```python
number = int(input())

if number % 2 == 0:
    print("짝수")
else:
    print("홀수")
```

## 순서도처럼 생각하기

```text
숫자 입력
   ↓
2로 나눈 나머지 확인
   ↓
0인가?
 ↙   ↘
예    아니오
↓      ↓
짝수   홀수
```

## 완전탐색

처음 배우는 알고리즘에서 자주 나오는 방식이다. 가능한 값을 하나씩 전부 확인하는 것이다.

```python
numbers = [7, 3, 10, 5]

for number in numbers:
    if number == 10:
        print("찾았다")
```

데이터가 작을 때는 이렇게 단순하게 전부 확인하는 방법도 충분히 좋다.

## 최댓값 찾기

```python
numbers = [7, 3, 10, 5]
max_number = numbers[0]

for number in numbers:
    if number > max_number:
        max_number = number

print(max_number)
```

처음에는 `max()`를 바로 쓰기보다 이 과정을 직접 따라가 보면 반복문과 조건문을 같이 이해하기 좋다.

## 누적 합계

```python
numbers = [1, 2, 3, 4]
total = 0

for number in numbers:
    total += number

print(total)
```

`total`이 0 → 1 → 3 → 6 → 10으로 바뀐다.

## 시간 복잡도는 나중에

`O(n)`, `O(n²)` 같은 말도 중요하지만 처음부터 그것만 붙잡을 필요는 없다. 먼저 **내 코드가 몇 번 반복되는지**부터 보는 게 좋다.

```python
for number in numbers:
    print(number)
```

숫자가 5개면 5번, 100개면 100번 돈다.

중첩 반복문은 반복 횟수가 더 많이 늘어난다.

```python
for i in range(3):
    for j in range(3):
        print(i, j)
```

총 9번 실행된다.

## 문제 풀 때 순서

1. 입력이 무엇인지 적는다.
2. 출력이 무엇인지 적는다.
3. 중간에 필요한 계산을 한국말로 적는다.
4. 작은 예제로 손으로 해 본다.
5. 그다음 코드로 옮긴다.
6. `print()`로 중간값을 확인한다.

처음부터 짧고 멋진 코드를 만드는 것보다, 왜 그렇게 되는지 설명할 수 있는 코드가 훨씬 중요하다.
