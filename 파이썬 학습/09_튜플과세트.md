# 09. 튜플과 세트 — 리스트와 비슷하지만 다른 자료형

Python에는 리스트 말고도 여러 값을 묶어서 저장하는 방법이 있다. 그중 초보가 자주 마주치는 것이 `tuple`과 `set`이다.

## 1. 튜플 `tuple`

튜플은 리스트와 비슷하지만 보통 한 번 만든 값을 바꾸지 않을 때 쓴다.

```python
rgb = (255, 0, 0)
print(rgb)
```

리스트는 `[]`, 튜플은 `()`를 쓴다.

## 2. 튜플 값 꺼내기

```python
rgb = (255, 0, 0)
print(rgb[0])
print(rgb[1])
```

결과는 255, 0이다.

## 3. 튜플은 값 변경이 안 된다

```python
rgb = (255, 0, 0)
rgb[0] = 100
```

이 코드는 오류가 난다.

리스트는 값을 바꿀 수 있지만 튜플은 기본적으로 바꿀 수 없다고 생각하면 된다.

## 4. 튜플 언패킹

```python
rgb = (255, 0, 0)
r, g, b = rgb

print(r)
print(g)
print(b)
```

한 묶음 안의 값을 여러 변수에 나눠 담는 것을 언패킹이라고 부른다.

## 5. 세트 `set`

세트는 중복을 없애고 값을 모아둘 때 쓴다.

```python
numbers = {1, 2, 2, 3}
print(numbers)
```

중복된 2가 하나로 정리된다.

## 6. 세트의 특징

세트는 순서를 중요하게 생각하지 않는다. 그래서 리스트처럼 `numbers[0]`으로 값을 꺼내는 용도로 쓰지 않는다.

## 7. 중복 제거할 때 쓰기

```python
names = ["철수", "영희", "철수", "민수"]
unique_names = set(names)
print(unique_names)
```

이렇게 하면 중복 이름을 없앨 수 있다.

## 8. 다시 리스트로 바꾸기

```python
names = ["철수", "영희", "철수"]
unique_names = list(set(names))
print(unique_names)
```

다만 세트는 순서를 보장하려고 쓰는 자료형이 아니므로 원래 순서가 중요하다면 다른 방법을 생각해야 한다.

## 리스트, 튜플, 세트 비교

```text
list   []  순서 있음, 값 변경 가능
 tuple ()  순서 있음, 값 변경 불가
 set   {}  중복 제거, 순서 중심 아님
```

## 처음에는 이것만 기억

- 리스트는 가장 자주 쓰는 여러 값 저장소다.
- 튜플은 리스트와 비슷하지만 값을 바꾸지 않을 때 쓴다.
- RGB 같은 `(255, 0, 0)`도 튜플로 볼 수 있다.
- 세트는 중복을 없애는 데 자주 쓴다.
