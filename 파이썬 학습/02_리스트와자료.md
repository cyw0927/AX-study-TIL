# 02. 리스트와 자료 모으기

Python을 배우다 보면 값 하나만 저장하는 것보다 **여러 값을 한꺼번에 저장**해야 할 일이 많다. 그때 가장 먼저 배우는 것이 리스트다.

## 1. 리스트 `list`

리스트는 여러 값을 순서대로 담는 자료형이다.

```python
numbers = [10, 20, 30]
```

`numbers` 안에는 10, 20, 30 세 값이 들어 있다.

문자도 넣을 수 있다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]
```

서로 다른 종류를 섞을 수도 있다.

```python
data = [10, "hello", True]
```

하지만 처음에는 같은 종류끼리 모으는 경우가 많다.

---

## 2. 인덱스 `index`

리스트 안의 위치 번호를 인덱스라고 한다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]
```

Python은 **0부터 센다.**

```text
짜장면   짬뽕   탕수육
  0       1       2
```

그래서:

```python
print(foods[0])
print(foods[2])
```

결과는:

```text
짜장면
탕수육
```

이다.

처음 배울 때 가장 자주 하는 실수 중 하나가 첫 번째 값을 `foods[1]`로 생각하는 것이다.

---

## 3. 음수 인덱스

뒤에서부터 셀 수도 있다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]

print(foods[-1])
```

결과:

```text
탕수육
```

`-1`은 맨 마지막 값이다.

---

## 4. `len()`

`len()`은 길이를 센다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]
print(len(foods))
```

결과:

```text
3
```

리스트에 값이 몇 개 들어 있는지 확인할 때 아주 많이 쓴다.

문자열에도 사용할 수 있다.

```python
print(len("hello"))
```

결과는 5다.

---

## 5. `append()`

리스트 끝에 값을 하나 추가한다.

```python
foods = []

foods.append("짜장면")
foods.append("짬뽕")

print(foods)
```

결과:

```text
['짜장면', '짬뽕']
```

처음에는 빈 리스트를 만들어 놓고 반복문으로 값을 하나씩 추가하는 경우가 많다.

```python
numbers = []

for i in range(3):
    numbers.append(i)

print(numbers)
```

결과:

```text
[0, 1, 2]
```

---

## 6. 리스트 값 바꾸기

인덱스로 위치를 지정해서 값을 바꿀 수 있다.

```python
numbers = [10, 20, 30]
numbers[1] = 999
print(numbers)
```

결과:

```text
[10, 999, 30]
```

---

## 7. `split()`

`split()`은 문자열을 나누는 함수다.

```python
text = "사과 바나나 포도"
parts = text.split()
print(parts)
```

결과:

```text
['사과', '바나나', '포도']
```

아무것도 안 적으면 기본적으로 공백을 기준으로 나눈다.

쉼표를 기준으로 나누고 싶으면:

```python
pixel = "255,0,0"
print(pixel.split(','))
```

결과:

```text
['255', '0', '0']
```

여기서 중요한 점은 결과가 **리스트**라는 것이다.

---

## 8. 문자열을 리스트처럼 보기

문자열도 순서가 있는 자료라 인덱스를 사용할 수 있다.

```python
word = "python"
print(word[0])
print(word[1])
```

결과:

```text
p
y
```

하지만 문자열은 리스트와 달리 특정 글자를 직접 바꾸는 방식이 제한된다.

---

## 9. 2차원 리스트

리스트 안에 리스트가 들어갈 수도 있다.

```python
board = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

표처럼 생각하면 쉽다.

```text
1 2 3
4 5 6
7 8 9
```

특정 값을 꺼내려면:

```python
print(board[1][2])
```

결과는 6이다.

`board[1]`은 두 번째 행 `[4,5,6]`이고, 거기서 `[2]`는 세 번째 값 6이다.

이미지 픽셀이나 표 데이터에서 2차원 리스트가 많이 나온다.

---

## 10. 튜플 `tuple`

튜플도 여러 값을 묶는 자료형이다.

```python
rgb = (255, 0, 0)
```

리스트는 `[]`, 튜플은 `()`를 사용한다.

큰 차이는 튜플은 보통 **한 번 정한 값을 바꾸지 않을 때** 사용한다는 점이다.

RGB처럼 세 값이 한 세트일 때 자주 볼 수 있다.

---

## 11. 언패킹

여러 값을 한 번에 여러 변수에 나눠 넣는 것을 언패킹이라고 한다.

```python
rgb = (255, 0, 0)
r, g, b = rgb

print(r)
print(g)
print(b)
```

결과:

```text
255
0
0
```

이 문법은 이미지 과제처럼 RGB 세 값을 각각 꺼낼 때 매우 자주 사용한다.

---

## 12. 딕셔너리 `dict`

딕셔너리는 값을 **이름표와 함께 저장**하는 자료형이다.

```python
person = {
    "name": "철수",
    "age": 20
}
```

값을 꺼낼 때 숫자 위치 대신 이름을 쓴다.

```python
print(person["name"])
```

결과:

```text
철수
```

리스트가 '순서' 중심이라면 딕셔너리는 '이름' 중심이라고 생각하면 쉽다.

---

## 13. 지금 기억할 핵심

```text
list      여러 값을 순서대로 저장
index     리스트 안 위치 번호
len()     길이 세기
append()  리스트 끝에 값 추가
split()   문자열 쪼개기
tuple     여러 값을 묶어 두기
dict      이름표와 값으로 저장
```

다음 편에서는 조건에 따라 코드를 실행하는 `if`와 같은 일을 반복하는 `for`를 다룬다.
