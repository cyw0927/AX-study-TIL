# 10. 파일 읽기와 쓰기 — Python으로 메모장 파일 다루기

지금까지는 값을 코드 안에 직접 적었다. 이제는 `.txt` 같은 파일을 Python이 읽거나 새로 쓰는 방법을 본다.

## 1. 파일을 연다는 뜻

컴퓨터에 있는 파일을 Python이 사용할 수 있게 연결하는 것이다.

```python
file = open("memo.txt", "r", encoding="utf-8")
```

여기서:

- `memo.txt` → 파일 이름
- `r` → 읽기 모드
- `encoding="utf-8"` → 한글이 깨지지 않도록 문자 인코딩 지정

## 2. 파일 내용 전체 읽기

```python
file = open("memo.txt", "r", encoding="utf-8")
text = file.read()
print(text)
file.close()
```

`read()`는 파일 내용을 읽는다.

`close()`는 다 쓴 파일을 닫는다.

## 3. `with open()`을 더 많이 쓰는 이유

보통은 이렇게 쓴다.

```python
with open("memo.txt", "r", encoding="utf-8") as file:
    text = file.read()
    print(text)
```

`with`를 사용하면 작업이 끝난 뒤 Python이 파일을 알아서 닫아준다.

## 4. 한 줄씩 읽기

```python
with open("memo.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line)
```

파일이 여러 줄이면 한 줄씩 반복해서 읽을 수 있다.

## 5. 파일에 새 내용 쓰기

```python
with open("result.txt", "w", encoding="utf-8") as file:
    file.write("안녕하세요")
```

`w`는 쓰기 모드다.

주의할 점은 같은 파일이 이미 있으면 기존 내용을 새 내용으로 덮어쓸 수 있다는 것이다.

## 6. 줄바꿈 넣기

```python
with open("result.txt", "w", encoding="utf-8") as file:
    file.write("첫 번째 줄\n")
    file.write("두 번째 줄\n")
```

`\n`은 줄바꿈이다.

## 7. 기존 파일 뒤에 추가하기

```python
with open("result.txt", "a", encoding="utf-8") as file:
    file.write("새로운 내용\n")
```

`a`는 append의 뜻으로 기존 내용을 지우지 않고 맨 뒤에 추가한다.

## 8. 파일 모드 정리

```text
r = 읽기
w = 새로 쓰기, 기존 내용 덮어쓸 수 있음
a = 기존 파일 뒤에 추가
```

## 9. 파일을 못 찾는 오류

```python
with open("없는파일.txt", "r", encoding="utf-8") as file:
    print(file.read())
```

파일이 없으면 `FileNotFoundError`가 날 수 있다.

이때는 코드가 틀렸다기보다 현재 폴더에 그 파일이 있는지 먼저 확인해야 한다.

## 10. 현재 폴더가 중요한 이유

`open("memo.txt")`는 보통 현재 Python이 실행되고 있는 폴더에서 `memo.txt`를 찾는다.

그래서 VS Code에서 파일이 보인다고 해도 터미널의 현재 위치가 다르면 못 찾을 수 있다.

## 처음에는 이것만 기억

- 파일을 읽을 때는 `r`
- 파일을 새로 쓸 때는 `w`
- 기존 내용 뒤에 붙일 때는 `a`
- 한글 파일은 `encoding="utf-8"`을 자주 쓴다.
- 가능하면 `with open(...)` 형태를 사용한다.
- 파일을 못 찾으면 먼저 경로와 현재 폴더를 확인한다.
