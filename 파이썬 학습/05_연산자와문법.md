# 05. 자주 보는 연산자와 문법

Python 코드에는 `+`, `//`, `+=`, `in`처럼 짧지만 뜻을 모르면 바로 막히는 기호가 많다. 이 문서는 초보가 자주 마주치는 것부터 정리한다.

## 1. 사칙연산

```python
print(10 + 3)
print(10 - 3)
print(10 * 3)
print(10 / 3)
```

뜻은 각각 더하기, 빼기, 곱하기, 나누기다.

---

## 2. `/`

일반 나눗셈이다.

```python
print(7 / 3)
```

결과:

```text
2.3333333333333335
```

보통 결과가 실수 `float`로 나온다.

---

## 3. `//`

몫을 구한다.

```python
print(7 // 3)
```

결과:

```text
2
```

소수점 아래 부분을 사용하지 않고 몫만 남긴다고 생각하면 된다.

이미지 밝기 평균처럼 정수 결과가 필요할 때 자주 보게 된다.

---

## 4. `%`

나머지를 구한다.

```python
print(7 % 3)
```

결과:

```text
1
```

짝수인지 확인할 때도 많이 쓴다.

```python
number = 8

if number % 2 == 0:
    print("짝수")
```

---

## 5. `**`

거듭제곱이다.

```python
print(2 ** 3)
```

결과는 8이다.

`2 ** 3`은 2를 세 번 곱한 것과 같다.

---

## 6. `+=`

기존 값에 더한 뒤 다시 저장한다.

```python
total = 10
total += 3
print(total)
```

결과는 13이다.

아래 코드와 같은 뜻이다.

```python
total = total + 3
```

반복문에서 합계를 계속 더할 때 매우 자주 사용한다.

---

## 7. `-=`, `*=`, `/=`

비슷한 방식이다.

```python
x = 10
x -= 2
```

은:

```python
x = x - 2
```

와 같다.

---

## 8. `in`

어떤 값이 안에 들어 있는지 확인한다.

```python
foods = ["짜장면", "짬뽕"]

print("짜장면" in foods)
print("탕수육" in foods)
```

결과:

```text
True
False
```

문자열에도 쓸 수 있다.

```python
print("py" in "python")
```

결과는 `True`다.

---

## 9. `not in`

안 들어 있는지 확인한다.

```python
foods = ["짜장면", "짬뽕"]

print("탕수육" not in foods)
```

결과는 `True`다.

---

## 10. `map()`

여러 값에 같은 함수를 한꺼번에 적용할 때 쓴다.

```python
texts = ["10", "20", "30"]
numbers = map(int, texts)
print(list(numbers))
```

결과:

```text
[10, 20, 30]
```

초보에게 가장 자주 보이는 형태는 이것이다.

```python
height, width = map(int, input().split())
```

이 코드는 한 줄로 써서 복잡해 보이지만 실제로는:

```python
text = input()
parts = text.split()
numbers = map(int, parts)
height, width = numbers
```

를 줄여 쓴 것이다.

---

## 11. `list()`

다른 자료를 리스트로 바꿀 때 쓴다.

```python
numbers = list(range(5))
print(numbers)
```

결과:

```text
[0, 1, 2, 3, 4]
```

---

## 12. `str()`

값을 문자열로 바꾼다.

```python
number = 100
text = str(number)

print(text)
print(type(text))
```

결과:

```text
100
<class 'str'>
```

---

## 13. `float()`

값을 실수로 바꾼다.

```python
number = float("3.14")
print(number)
```

결과는 3.14다.

---

## 14. `sum()`

숫자 여러 개의 합을 구한다.

```python
numbers = [10, 20, 30]
print(sum(numbers))
```

결과는 60이다.

---

## 15. `min()`과 `max()`

가장 작은 값과 큰 값을 찾는다.

```python
numbers = [10, 3, 50, 7]

print(min(numbers))
print(max(numbers))
```

결과:

```text
3
50
```

---

## 16. `sorted()`

정렬된 새 리스트를 만든다.

```python
numbers = [3, 1, 2]
print(sorted(numbers))
```

결과:

```text
[1, 2, 3]
```

---

## 17. 문자열 `+`

문자열끼리 `+`를 하면 이어 붙인다.

```python
first = "hello"
second = "world"

print(first + second)
```

결과:

```text
helloworld
```

숫자 덧셈과는 완전히 다른 동작이다.

---

## 18. `join()`

여러 문자열을 하나로 합친다.

```python
letters = ["1", "1", "0"]
result = "".join(letters)
print(result)
```

결과:

```text
110
```

공백을 넣고 싶다면:

```python
print(" ".join(letters))
```

결과:

```text
1 1 0
```

---

## 19. f-string

문자열 안에 변수 값을 넣기 편한 문법이다.

```python
name = "철수"
age = 20

print(f"이름은 {name}이고 나이는 {age}살입니다.")
```

결과:

```text
이름은 철수이고 나이는 20살입니다.
```

`f`가 문자열 앞에 붙는 것이 특징이다.

---

## 20. 지금 기억할 핵심

```text
/      일반 나눗셈
//     몫
%      나머지
**     거듭제곱
+=     기존 값에 더해서 다시 저장
in     안에 있는지 확인
map()  여러 값에 같은 함수 적용
sum()  합계
join() 문자열 여러 개 합치기
```

모든 걸 외우기보다, 코드에서 다시 만났을 때 이 문서를 찾아보는 식으로 익히는 것이 좋다.
