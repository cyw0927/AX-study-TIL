# 16. 기초 연습문제

설명만 읽으면 금방 잊는다. 여기서는 지금까지 배운 문법을 아주 작은 문제로 반복한다.

정답을 바로 보기보다 먼저 직접 실행해 본다.

## 1. print 연습

다음 문장을 출력한다.

```text
Python 공부 시작
```

힌트:

```python
print(...)
```

## 2. 변수 연습

`name` 변수에 자기 이름을 저장하고 출력한다.

예:

```python
name = "철수"
```

## 3. input 연습

사용자에게 이름을 입력받고 그대로 출력한다.

## 4. input + int 연습

숫자 두 개를 입력받아 더한 결과를 출력한다.

예:

```text
첫 번째 숫자: 3
두 번째 숫자: 5
결과: 8
```

주의: `input()` 결과는 문자열이다.

## 5. if 연습

숫자를 하나 입력받고 10 이상이면 `크다`, 아니면 `작다`를 출력한다.

## 6. 홀수/짝수

숫자를 입력받아 짝수인지 홀수인지 출력한다.

힌트:

```python
number % 2
```

나머지가 0이면 짝수다.

## 7. 리스트 첫 번째 값

```python
numbers = [10, 20, 30, 40]
```

첫 번째 값과 마지막 값을 각각 출력한다.

## 8. 리스트 합계

아래 숫자의 합계를 for문으로 구한다.

```python
numbers = [10, 20, 30, 40]
```

`sum()`을 바로 쓰지 말고 `total = 0`부터 시작해서 직접 누적해 본다.

## 9. 리스트에 값 추가

빈 리스트를 만들고 `append()`로 10, 20, 30을 순서대로 넣는다.

## 10. 문자열 split

```python
text = "사과 바나나 포도"
```

공백을 기준으로 나눈 뒤 리스트를 출력한다.

## 11. RGB split

```python
pixel = "255,120,30"
```

쉼표를 기준으로 나누고 각 값의 자료형도 출력한다.

그다음 `map(int, ...)`를 사용해 정수로 바꾼다.

## 12. 함수 만들기

숫자 두 개를 받아 더한 결과를 `return`하는 함수 `add()`를 만든다.

```python
def add(a, b):
    ...
```

## 13. 밝기 계산 함수

R, G, B 세 값을 받아 다음 공식으로 밝기를 반환한다.

```text
(R + G + B) // 3
```

테스트:

```text
255,0,0 → 85
255,255,255 → 255
0,0,0 → 0
```

## 14. 딕셔너리

아래 메뉴를 딕셔너리로 만든다.

```text
짜장면 7000
짬뽕 8000
탕수육 18000
```

`짬뽕`의 가격을 출력한다.

## 15. 딕셔너리 반복

위 메뉴를 `items()`로 반복하면서 다음처럼 출력한다.

```text
짜장면 7000
짬뽕 8000
탕수육 18000
```

## 16. 중첩 반복문

```python
numbers = [
    [1, 2, 3],
    [4, 5, 6]
]
```

모든 숫자를 하나씩 출력한다.

## 17. threshold 연습

```python
brightness = [100, 200, 50, 150]
```

전체 평균을 정수 나눗셈으로 구하고, 평균 이상이면 1, 미만이면 0을 출력한다.

## 18. 오류 찾아보기

다음 코드가 왜 오류인지 설명하고 고친다.

```python
age = input()
print(age + 1)
```

## 19. 인덱스 오류

다음 코드가 왜 오류인지 설명한다.

```python
numbers = [10, 20, 30]
print(numbers[3])
```

## 20. 작은 종합 문제

세 과목 점수를 입력받는다.

```text
국어
영어
수학
```

세 점수의 평균을 구한다.

평균이 80 이상이면 `합격`, 아니면 `재학습`을 출력한다.

가능하면 다음 순서로 만든다.

```text
입력
↓
정수 변환
↓
합계 계산
↓
평균 계산
↓
if 조건
↓
출력
```

## 답을 확인하기 전에 할 것

코드가 안 되면 바로 정답을 찾지 말고 다음부터 확인한다.

```python
print(변수)
print(type(변수))
print(len(리스트))
```

그리고 오류 메시지 마지막 줄을 읽어 본다.

문제를 풀 때 가장 중요한 것은 정답 코드 자체보다 **내가 어느 단계에서 막혔는지 알아내는 것**이다.
