# 문자열 메서드 기초

문자열 메서드는 문자열에게 **어떤 작업을 시키는 기능**이라고 생각하면 된다.

예를 들어:

```python
text = "hello"
print(text.upper())
```

결과:

```text
HELLO
```

`.` 뒤에 붙는 `upper()`가 문자열 메서드다.

## `upper()`와 `lower()`

```python
text = "Hello Python"
print(text.upper())
print(text.lower())
```

결과:

```text
HELLO PYTHON
hello python
```

## `strip()`

문자열 양쪽의 불필요한 공백이나 줄바꿈을 없앤다.

```python
text = "   hello   "
print(text.strip())
```

결과는 `hello`다.

파일이나 사용자 입력을 다룰 때 자주 보게 된다.

## `replace()`

문자열 안의 일부 내용을 바꾼다.

```python
text = "나는 사과를 좋아해"
print(text.replace("사과", "바나나"))
```

## `split()`

문자열을 여러 조각으로 나눈다.

```python
text = "사과 바나나 포도"
print(text.split())
```

결과:

```text
['사과', '바나나', '포도']
```

쉼표 기준으로 자를 수도 있다.

```python
pixel = "255,0,0"
print(pixel.split(","))
```

## `join()`

`split()`과 반대로 여러 문자열을 하나로 이어 붙일 때 사용한다.

```python
words = ["사과", "바나나", "포도"]
print(", ".join(words))
```

결과:

```text
사과, 바나나, 포도
```

## `find()`

특정 글자가 어디에 있는지 찾는다.

```python
text = "hello"
print(text.find("e"))
```

결과는 `1`이다.

찾지 못하면 `-1`이 나온다.

## `count()`

몇 번 나오는지 센다.

```python
text = "banana"
print(text.count("a"))
```

결과는 `3`이다.

## `startswith()`와 `endswith()`

문자열이 특정 글자로 시작하거나 끝나는지 확인한다.

```python
filename = "report.csv"
print(filename.endswith(".csv"))
```

결과는 `True`다.

## 메서드는 원래 문자열을 자동으로 바꾸지 않는다

```python
text = "hello"
text.upper()
print(text)
```

결과는 여전히 `hello`다.

바뀐 결과를 저장하려면:

```python
text = text.upper()
```

처럼 다시 넣어야 한다.

## 직접 연습

```python
text = "  Python Study  "

print(text.strip())
print(text.lower())
print(text.replace("Study", "Practice"))
print(text.count("t"))
```

각 메서드가 **원본을 바꾸는지, 새로운 결과를 만들어 주는지** 확인해 본다.
