# 형변환을 아주 쉽게 이해하기

형변환은 **값의 종류를 다른 종류로 바꾸는 것**이다.

예를 들어 `input()`으로 숫자 20을 입력해도 Python은 처음에는 문자열로 받는다.

```python
age = input("나이: ")
print(age)
print(type(age))
```

20을 입력해도 자료형은 `str`이다.

```text
20
<class 'str'>
```

숫자 계산을 하려면 정수로 바꿔야 한다.

```python
age = int(age)
print(type(age))
```

이제 `int`가 된다.

## `int()`

정수로 바꾼다.

```python
x = int("10")
print(x + 5)
```

결과:

```text
15
```

하지만 아무 문자열이나 숫자로 바꿀 수 있는 것은 아니다.

```python
int("사과")
```

이 코드는 오류가 난다.

`"사과"`는 정수로 바꿀 수 없기 때문이다.

## `float()`

실수로 바꾼다.

```python
x = float("3.14")
print(x)
print(type(x))
```

## `str()`

문자열로 바꾼다.

```python
age = 20
text = str(age)
print(text)
print(type(text))
```

숫자와 문자를 이어 붙이고 싶을 때 자주 사용한다.

```python
age = 20
print("나이는 " + str(age) + "살입니다")
```

## `list()`

반복 가능한 값을 리스트로 바꿀 수 있다.

```python
letters = list("ABC")
print(letters)
```

결과:

```text
['A', 'B', 'C']
```

## 왜 형변환이 중요한가?

Python은 값의 종류가 다르면 계산이 안 되는 경우가 많다.

```python
age = "20"
print(age + 1)
```

이 코드는 문자열과 정수를 더하려고 해서 오류가 난다.

다음처럼 바꿔야 한다.

```python
age = "20"
age = int(age)
print(age + 1)
```

## `map(int, input().split())`는 뭘까?

초보자가 처음 보면 매우 복잡해 보인다.

```python
height, width = map(int, input().split())
```

사실 순서대로 보면 단순하다.

```python
text = input()          # 예: "3 5"
parts = text.split()    # ['3', '5']
numbers = map(int, parts)
height, width = numbers
```

즉 **문자열을 입력받고 → 공백으로 나누고 → 각각 정수로 바꾸는 것**이다.

## 직접 연습

```python
price = input("가격: ")
count = input("개수: ")

print(type(price))
print(type(count))

price = int(price)
count = int(count)

print("총 가격:", price * count)
```

여기서 `int()` 두 줄을 지우면 어떤 오류가 나는지도 직접 확인해 본다.
