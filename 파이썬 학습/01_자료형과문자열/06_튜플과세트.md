# 06. 튜플과 세트 완전 기초

리스트를 배우고 나면 `tuple`, `set`이라는 자료형도 자주 보게 된다. 처음에는 리스트와 뭐가 다른지만 이해하면 충분하다.

## 튜플 tuple

튜플은 여러 값을 순서대로 저장한다.

```python
point = (10, 20)
```

리스트와 모양이 비슷하다.

```python
list_data = [10, 20]
tuple_data = (10, 20)
```

가장 큰 차이는 튜플은 만든 뒤 값을 바꾸기 어렵다는 것이다.

```python
point = (10, 20)
print(point[0])
```

값을 읽는 것은 가능하다.

하지만:

```python
point[0] = 999
```

처럼 바꾸려고 하면 오류가 난다.

## 튜플을 왜 쓰나?

값이 바뀌지 않아야 하는 묶음을 표현할 때 사용할 수 있다.

예:

```python
rgb = (255, 0, 0)
```

또 함수가 여러 값을 돌려줄 때 튜플처럼 받을 수 있다.

```python
def get_point():
    return 10, 20

x, y = get_point()
print(x, y)
```

## 언패킹

여러 값을 변수 여러 개에 나누어 넣는 것이다.

```python
rgb = (255, 0, 0)
r, g, b = rgb

print(r)
print(g)
print(b)
```

`map(int, ...)` 결과를 여러 변수로 받을 때도 비슷한 느낌이다.

```python
r, g, b = map(int, "255,0,0".split(','))
```

## 세트 set

세트는 **중복을 허용하지 않는 값 모음**이다.

```python
numbers = {1, 2, 3}
```

중복값을 넣어 보면:

```python
numbers = {1, 1, 2, 2, 3}
print(numbers)
```

중복이 사라진다.

## 리스트의 중복 제거

```python
numbers = [1, 1, 2, 2, 3, 3]
unique = set(numbers)
print(unique)
```

필요하면 다시 리스트로 바꿀 수도 있다.

```python
unique_list = list(unique)
```

단, 세트는 리스트처럼 순서를 믿고 `set_data[0]`으로 접근하는 구조가 아니다.

## `add()`

세트에 값을 하나 추가한다.

```python
foods = {"짜장면", "짬뽕"}
foods.add("탕수육")
print(foods)
```

## `remove()`

값을 제거한다.

```python
foods.remove("짬뽕")
```

## 집합 연산

세트는 수학의 집합처럼 사용할 수 있다.

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)  # 합집합
print(a & b)  # 교집합
print(a - b)  # 차집합
```

## 리스트, 튜플, 세트 차이 간단 정리

```text
list  [1, 2, 3]   순서 있음, 값 변경 가능
 tuple (1, 2, 3)  순서 있음, 값 변경 불가에 가까움
set   {1, 2, 3}   중복 없음, 위치 번호로 접근하지 않음
```

## 직접 연습

```python
values = [1, 1, 2, 3, 3, 4]

print("원래 리스트:", values)
print("세트 변환:", set(values))

rgb = (255, 100, 50)
r, g, b = rgb
print(r, g, b)
```

리스트, 튜플, 세트의 출력 모양을 비교해 본다.
