# 슬라이싱 완전 기초

슬라이싱은 문자열이나 리스트에서 **일부분만 잘라서 가져오는 방법**이다.

처음 보면 `[:]` 모양 때문에 어려워 보이지만 뜻은 단순하다.

```python
text = "python"
print(text[0:3])
```

결과:

```text
pyt
```

`0:3`은 0번부터 시작해서 **3번 바로 전까지** 가져온다는 뜻이다.

## 왜 3번은 안 들어가나?

Python의 범위는 끝 번호를 보통 포함하지 않는다.

```text
p y t h o n
0 1 2 3 4 5
```

`text[0:3]`은 0, 1, 2번만 가져온다.

## 시작 번호 생략

```python
text = "python"
print(text[:3])
```

처음부터 3번 직전까지 가져온다.

결과:

```text
pyt
```

## 끝 번호 생략

```python
print(text[3:])
```

3번부터 끝까지 가져온다.

결과:

```text
hon
```

## 둘 다 생략

```python
print(text[:])
```

전체를 가져온다.

## 음수 인덱스

뒤에서부터 세고 싶을 때 음수를 쓸 수 있다.

```text
p  y  t  h  o  n
0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

```python
print(text[-1])
```

결과:

```text
n
```

마지막 두 글자:

```python
print(text[-2:])
```

결과:

```text
on
```

## 리스트도 똑같다

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[1:4])
```

결과:

```text
[20, 30, 40]
```

## 세 번째 값: 간격

```python
numbers = [0, 1, 2, 3, 4, 5, 6]
print(numbers[::2])
```

결과:

```text
[0, 2, 4, 6]
```

`[시작:끝:간격]` 구조다.

## 뒤집기

```python
text = "python"
print(text[::-1])
```

결과:

```text
nohtyp
```

`-1` 간격으로 뒤에서 앞으로 이동한다.

## 초보자가 자주 헷갈리는 점

### `text[0:3]`에 3번이 포함된다고 생각함

포함되지 않는다.

### 인덱스와 개수를 섞어서 생각함

`text[0:3]`은 "3개"라는 뜻이 아니라 0번부터 3번 직전까지라는 뜻이다. 우연히 3개가 나오는 것이다.

## 직접 연습

```python
word = "abcdefg"

print(word[0:2])
print(word[2:5])
print(word[:4])
print(word[4:])
print(word[-3:])
print(word[::2])
print(word[::-1])
```

실행하기 전에 각각 어떤 결과가 나올지 먼저 적어 본다.
