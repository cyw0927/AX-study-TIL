# 03. 문자열 완전 기초

문자열은 글자를 다루는 자료형이다. Python에서는 `str`이라고 부른다.

```python
name = "철수"
message = "안녕하세요"
number_text = "100"
```

`"100"`은 숫자처럼 보여도 따옴표 안에 있으므로 문자열이다.

## 문자열과 숫자는 다르다

```python
print("2" + "3")
print(2 + 3)
```

결과:

```text
23
5
```

문자열끼리 `+`를 사용하면 서로 붙는다.

## 문자열 길이 `len()`

```python
text = "hello"
print(len(text))
```

결과는 5다.

## 문자열에서 글자 하나 꺼내기

```python
text = "python"
print(text[0])
print(text[1])
```

결과:

```text
p
y
```

Python은 위치 번호를 0부터 센다.

## 음수 인덱스

뒤에서부터 셀 수도 있다.

```python
text = "python"
print(text[-1])
print(text[-2])
```

결과:

```text
n
o
```

## `split()`

문자열을 여러 조각으로 나눈다.

```python
text = "사과 바나나 포도"
print(text.split())
```

결과:

```python
['사과', '바나나', '포도']
```

쉼표 기준으로도 나눌 수 있다.

```python
pixel = "255,0,0"
print(pixel.split(','))
```

결과:

```python
['255', '0', '0']
```

중요: `split()` 결과는 문자열 하나가 아니라 **리스트**다.

## `strip()`

문자열 앞뒤의 불필요한 공백을 없앤다.

```python
text = "   hello   "
print(text.strip())
```

결과:

```text
hello
```

## `replace()`

문자열 일부를 바꾼다.

```python
text = "나는 사과를 좋아한다"
print(text.replace("사과", "포도"))
```

## `upper()`와 `lower()`

영문을 대문자 또는 소문자로 바꾼다.

```python
text = "Python"
print(text.upper())
print(text.lower())
```

## `in`

문자열 안에 특정 글자가 있는지 확인한다.

```python
text = "python study"
print("python" in text)
print("java" in text)
```

결과:

```text
True
False
```

## f-string

변수 값을 문장 안에 넣을 때 편하다.

```python
name = "철수"
age = 20

print(f"이름은 {name}이고 나이는 {age}살입니다.")
```

처음에는 꼭 써야 하는 문법은 아니지만 자주 보게 된다.

## 자주 하는 실수

### 숫자 문자열을 그대로 계산하기

```python
a = input()
b = input()
print(a + b)
```

2와 3을 입력하면 5가 아니라 23이 나온다.

숫자로 계산하려면:

```python
a = int(input())
b = int(input())
print(a + b)
```

## 직접 연습

```python
text = "255,120,30"

parts = text.split(',')
print(parts)
print(type(parts))
print(parts[0])
print(type(parts[0]))
```

여기서 `parts[0]`도 아직 문자열이라는 점을 확인한다.
