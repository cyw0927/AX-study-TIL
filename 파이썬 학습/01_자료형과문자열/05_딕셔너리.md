# 05. 딕셔너리 완전 기초

딕셔너리는 **이름표와 값을 한 쌍으로 저장하는 자료형**이다.

리스트가 순서대로 값을 저장한다면, 딕셔너리는 이름표를 붙여 저장한다고 생각하면 쉽다.

## 기본 모양

```python
student = {
    "name": "철수",
    "age": 20,
    "score": 85
}
```

여기서 `"name"`, `"age"`, `"score"`는 key이고, 그 오른쪽 값들은 value다.

## 값을 꺼내기

```python
print(student["name"])
print(student["age"])
```

결과:

```text
철수
20
```

리스트에서는 `0`, `1`, `2` 같은 위치 번호로 값을 찾지만, 딕셔너리에서는 key 이름으로 값을 찾는다.

## 값 바꾸기

```python
student["score"] = 90
print(student)
```

기존 값이 바뀐다.

## 새 값 추가하기

```python
student["city"] = "서울"
print(student)
```

원래 없던 key도 추가할 수 있다.

## `get()`

key로 값을 가져오는 또 다른 방법이다.

```python
print(student.get("name"))
```

`student["없는키"]`는 오류가 날 수 있지만:

```python
print(student.get("없는키"))
```

은 기본적으로 `None`을 돌려준다.

기본값을 직접 정할 수도 있다.

```python
print(student.get("phone", "전화번호 없음"))
```

## `keys()`

key만 확인한다.

```python
print(student.keys())
```

## `values()`

value만 확인한다.

```python
print(student.values())
```

## `items()`

key와 value를 같이 확인한다.

```python
for key, value in student.items():
    print(key, value)
```

## 메뉴처럼 사용할 수도 있다

```python
menu = {
    "짜장면": 7000,
    "짬뽕": 8000,
    "탕수육": 18000
}

print(menu["짬뽕"])
```

딕셔너리는 "이름 → 값" 구조가 필요한 상황에서 아주 편하다.

## 딕셔너리 안에 리스트

```python
student = {
    "name": "철수",
    "scores": [80, 90, 100]
}

print(student["scores"])
print(student["scores"][0])
```

자료구조는 서로 섞어서 사용할 수 있다.

## 리스트 안에 딕셔너리

```python
students = [
    {"name": "철수", "score": 80},
    {"name": "영희", "score": 90}
]

print(students[0]["name"])
```

실제 데이터에서는 이런 구조를 자주 본다.

## `in`으로 key 확인

```python
if "name" in student:
    print("name 키가 있음")
```

기본적으로 딕셔너리에 `in`을 쓰면 key를 확인한다.

## 자주 하는 실수

```python
student = {"name": "철수"}
print(student[0])
```

딕셔너리는 리스트처럼 0번, 1번으로 꺼내는 구조가 아니다.

또한 없는 key를 대괄호 방식으로 찾으면 오류가 날 수 있다.

```python
print(student["age"])
```

이럴 때 `get()`을 쓰면 더 안전하게 확인할 수 있다.

## 직접 연습

```python
menu = {}

menu["짜장면"] = 7000
menu["짬뽕"] = 8000
menu["탕수육"] = 18000

print(menu)
print(menu["짜장면"])

for name, price in menu.items():
    print(name, price)
```

그 다음 메뉴를 하나 추가하고 가격을 하나 수정해 본다.
