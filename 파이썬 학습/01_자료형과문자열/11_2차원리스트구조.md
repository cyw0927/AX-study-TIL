# 11. 2차원 리스트 구조

2차원 리스트는 **리스트 안에 리스트가 들어 있는 형태**다.

## 가장 작은 예제

```python
board = [
    [1, 2, 3],
    [4, 5, 6]
]
```

겉으로 보면 이렇게 생각하면 된다.

```text
첫 번째 줄 → [1, 2, 3]
두 번째 줄 → [4, 5, 6]
```

표처럼 보면:

```text
1 2 3
4 5 6
```

## `board[0]`

```python
print(board[0])
```

결과:

```text
[1, 2, 3]
```

첫 번째 행 전체가 나온다.

## `board[0][1]`

```python
print(board[0][1])
```

먼저 `board[0]`은 `[1, 2, 3]`이다.
그다음 그 안의 `[1]`을 찾는다.

결과는 `2`다.

## 왜 숫자가 두 개 붙나?

```python
board[행][열]
```

이라고 생각하면 된다.

```text
board[0][0] → 1
board[0][1] → 2
board[0][2] → 3
board[1][0] → 4
```

## 행 개수

```python
print(len(board))
```

결과는 `2`다.

## 한 행의 길이

```python
print(len(board[0]))
```

결과는 `3`이다.

## 반복문으로 행 보기

```python
for row in board:
    print(row)
```

결과:

```text
[1, 2, 3]
[4, 5, 6]
```

## 값 하나씩 보기

```python
for row in board:
    for number in row:
        print(number)
```

바깥 `for`가 행을 하나 고르고, 안쪽 `for`가 그 행의 값을 하나씩 꺼낸다.

## 이미지와 2차원 리스트

이미지도 보통 행과 열로 생각할 수 있다.

```text
픽셀 픽셀 픽셀
픽셀 픽셀 픽셀
```

그래서 밝기 값을 저장할 때 이런 구조가 자연스럽다.

```python
brightness = [
    [255, 200, 0],
    [120, 60, 30]
]
```

## 자주 하는 실수

`board[2]`를 찾으려는데 행이 두 개밖에 없다면 오류가 난다.

```python
board = [[1, 2], [3, 4]]
print(board[2])
```

인덱스는 0부터 시작하므로 가능한 행 번호는 0과 1뿐이다.

## 직접 연습

```python
board = [
    [10, 20],
    [30, 40],
    [50, 60]
]

print(board[0])
print(board[2])
print(board[1][0])
print(len(board))
print(len(board[0]))
```

실행하기 전에 각각 무엇이 나올지 먼저 예상해 본다.
