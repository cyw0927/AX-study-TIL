# 09. 자료형 변환 실전

파이썬을 배우다 보면 값이 눈으로 보기에는 비슷한데 계산이 안 되는 경우가 자주 있다.

예를 들어 아래 세 값은 서로 다르다.

```python
30
30.0
"30"
```

각각의 자료형은 다음과 같다.

```text
30      -> int
30.0    -> float
"30"    -> str
```

## 1. int

정수형이다.

```python
age = 30
```

소수점이 없는 숫자다.

## 2. float

실수형이다.

```python
price = 30.5
```

소수점이 붙은 숫자다.

## 3. str

문자열이다.

```python
age = "30"
```

숫자처럼 보여도 따옴표 안에 있으면 문자열이다.

그래서 이런 코드는 오류가 난다.

```python
"30" + 5
```

문자열과 숫자를 바로 더할 수 없기 때문이다.

## 4. 문자열을 숫자로 바꾸기

```python
age = "30"
age = int(age)
print(age + 5)
```

결과:

```text
35
```

소수라면:

```python
price = "3.14"
price = float(price)
```

## 5. 숫자를 문자열로 바꾸기

```python
age = 30
message = "나이는 " + str(age) + "살입니다."
print(message)
```

요즘은 f-string을 더 많이 사용한다.

```python
age = 30
print(f"나이는 {age}살입니다.")
```

## 6. type()으로 직접 확인하기

헷갈리면 추측하지 말고 바로 확인한다.

```python
value = "30"
print(type(value))
```

결과:

```text
<class 'str'>
```

## 7. CSV와 pandas에서 특히 조심할 점

CSV에서 숫자처럼 보이는 값도 상황에 따라 문자열로 읽힐 수 있다.

```python
print(df.dtypes)
```

으로 실제 자료형을 확인해야 한다.

숫자로 바꿀 때는 pandas에서는 다음도 많이 사용한다.

```python
df["price"] = pd.to_numeric(
    df["price"],
    errors="coerce"
)
```

잘못된 값은 `NaN`으로 바뀔 수 있으므로 이후에 반드시 확인한다.

```python
print(df["price"].isna().sum())
```

## 핵심

```text
숫자처럼 보인다고 숫자는 아니다.

30      -> int
30.0    -> float
"30"    -> str
```

오류가 나면 먼저 `type()`이나 `df.dtypes`를 확인한다.
