# 04. 리스트 완전 기초

리스트는 값 여러 개를 한꺼번에 저장하는 자료형이다.

```python
numbers = [10, 20, 30]
foods = ["짜장면", "짬뽕", "탕수육"]
```

## 왜 리스트를 쓰나?

변수를 따로 만들면:

```python
a = 10
b = 20
c = 30
```

값이 많아질수록 관리하기 불편하다.

리스트를 쓰면:

```python
numbers = [10, 20, 30]
```

한 변수에 여러 값을 모아둘 수 있다.

## 인덱스

리스트 안의 위치 번호다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]

print(foods[0])
print(foods[1])
print(foods[2])
```

Python은 0부터 센다.

```text
짜장면 → 0번
짬뽕   → 1번
탕수육 → 2번
```

## 리스트 길이 `len()`

```python
foods = ["짜장면", "짬뽕", "탕수육"]
print(len(foods))
```

결과는 3이다.

## `append()`

리스트 맨 뒤에 값을 하나 추가한다.

```python
foods = []
foods.append("짜장면")
foods.append("짬뽕")
print(foods)
```

결과:

```python
['짜장면', '짬뽕']
```

반복문에서 계산 결과를 모을 때 아주 자주 쓴다.

```python
result = []

for number in [1, 2, 3]:
    result.append(number * 10)

print(result)
```

## 값 바꾸기

리스트는 특정 위치의 값을 바꿀 수 있다.

```python
numbers = [10, 20, 30]
numbers[1] = 999
print(numbers)
```

결과:

```python
[10, 999, 30]
```

## `remove()`

특정 값을 찾아 삭제한다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]
foods.remove("짬뽕")
print(foods)
```

## `pop()`

특정 위치의 값을 꺼내면서 삭제한다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]
item = foods.pop(1)
print(item)
print(foods)
```

## 리스트 안에 리스트

리스트 안에 또 리스트를 넣을 수 있다.

```python
board = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
```

이런 구조를 2차원 리스트라고 자주 부른다.

```python
print(board[0])
print(board[1][2])
```

`board[1][2]`는 두 번째 행의 세 번째 값인 6이다.

## 반복문과 리스트

```python
foods = ["짜장면", "짬뽕", "탕수육"]

for food in foods:
    print(food)
```

리스트 안의 값을 하나씩 꺼내서 반복한다.

## `in`

리스트 안에 특정 값이 있는지 확인한다.

```python
foods = ["짜장면", "짬뽕"]
print("짜장면" in foods)
print("볶음밥" in foods)
```

## 리스트 복사에서 주의할 점

```python
a = [1, 2, 3]
b = a
b.append(4)
print(a)
```

결과는 `[1, 2, 3, 4]`다. `b = a`는 완전히 새로운 리스트를 만든 것이 아니라 같은 리스트를 함께 바라보게 되는 경우다.

초보 단계에서는 이 현상이 있다는 정도만 기억하고, 진짜 복사하려면 다음처럼 할 수 있다.

```python
b = a.copy()
```

## 직접 연습
