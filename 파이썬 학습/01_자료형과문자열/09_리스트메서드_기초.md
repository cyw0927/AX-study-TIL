# 리스트 메서드 기초

리스트는 여러 값을 한곳에 모아두는 자료형이다.

```python
foods = ["짜장면", "짬뽕"]
```

리스트 메서드는 이 리스트에 값을 추가하거나 지우고, 순서를 바꾸는 기능이다.

## `append()`

리스트 맨 뒤에 값 하나를 추가한다.

```python
foods = ["짜장면", "짬뽕"]
foods.append("탕수육")
print(foods)
```

결과:

```text
['짜장면', '짬뽕', '탕수육']
```

초보 단계에서 정말 자주 나온다.

## `insert()`

원하는 위치에 값을 끼워 넣는다.

```python
foods.insert(1, "볶음밥")
```

1번 위치에 넣는다.

## `remove()`

값을 찾아서 지운다.

```python
foods.remove("짬뽕")
```

같은 값이 여러 개 있으면 첫 번째로 찾은 값 하나를 지운다.

## `pop()`

값을 꺼내면서 리스트에서도 없앤다.

```python
numbers = [10, 20, 30]
value = numbers.pop()
print(value)
print(numbers)
```

결과:

```text
30
[10, 20]
```

위치를 지정할 수도 있다.

```python
numbers.pop(0)
```

## `sort()`

리스트 안의 값을 정렬한다.

```python
numbers = [3, 1, 5, 2]
numbers.sort()
print(numbers)
```

결과:

```text
[1, 2, 3, 5]
```

내림차순:

```python
numbers.sort(reverse=True)
```

## `reverse()`

현재 순서를 반대로 뒤집는다.

```python
numbers = [1, 2, 3]
numbers.reverse()
print(numbers)
```

## `count()`

특정 값이 몇 개인지 센다.

```python
numbers = [1, 1, 2, 3, 1]
print(numbers.count(1))
```

결과는 `3`이다.

## `index()`

특정 값이 몇 번 위치에 있는지 찾는다.

```python
foods = ["짜장면", "짬뽕", "탕수육"]
print(foods.index("짬뽕"))
```

결과는 `1`이다.

## `extend()`

리스트 뒤에 다른 리스트의 값들을 여러 개 붙인다.

```python
a = [1, 2]
b = [3, 4]
a.extend(b)
print(a)
```

결과:

```text
[1, 2, 3, 4]
```

`append(b)`를 하면 `b` 리스트 자체가 통째로 들어가는 점과 다르다.

```python
a = [1, 2]
b = [3, 4]
a.append(b)
print(a)
```

결과:

```text
[1, 2, [3, 4]]
```

## 리스트 길이 확인

메서드는 아니지만 `len()`도 아주 자주 같이 쓴다.

```python
print(len(foods))
```

## 직접 연습

```python
scores = []

scores.append(80)
scores.append(95)
scores.append(70)
print(scores)

scores.sort()
print(scores)

scores.pop()
print(scores)
```

각 줄이 실행될 때 리스트 안의 값이 어떻게 변하는지 한 줄씩 따라가 본다.
