## 기호 빠르게 찾기

```text
=    오른쪽 값을 왼쪽에 넣기
==   같은지 비교
!=   다른지 비교
>    큰지 비교
<    작은지 비교
>=   크거나 같은지 비교
<=   작거나 같은지 비교
+    더하기
-    빼기
*    곱하기
/    나누기
//   몫
%    나머지
**   제곱
[]   리스트, 인덱스 등에서 사용
{}   딕셔너리, 세트에서 사용
()   함수 호출 등에서 사용
:    if, for, def 등의 코드 블록 시작
#    주석
.    메서드나 속성 접근
```

모르는 용어를 한 번에 외우는 것이 목적이 아니다. 코드에서 실제로 만났을 때 이 표를 찾아보고, 해당 자세한 문서에서 작은 예제를 직접 실행하면 된다.
