# 01. 파이썬이 뭔가요?

이 문서는 Python을 처음 보는 사람을 기준으로 쓴다. 어려운 말을 외우기보다 **코드를 읽었을 때 무슨 일이 일어나는지** 이해하는 것이 목표다.

## Python은 무엇인가?

Python은 컴퓨터에게 일을 시키기 위해 사용하는 프로그래밍 언어다.

사람끼리는 한국어나 영어로 말하지만, 컴퓨터에게는 정해진 문법으로 명령을 써야 한다. Python은 그 문법 중 하나다.

```python
print("안녕하세요")
```

이 코드는 컴퓨터에게 "안녕하세요를 화면에 보여줘"라고 시키는 것이다.

## 코드란?

코드는 컴퓨터가 실행할 명령을 글자로 적어 놓은 것이다.

```python
print(1 + 2)
```

결과:

```text
3
```

Python은 위에서 아래로 코드를 읽는다.

```python
print("첫 번째")
print("두 번째")
print("세 번째")
```

결과도 같은 순서로 나온다.

## 프로그램이란?

코드 여러 줄을 모아 어떤 일을 하게 만든 것이 프로그램이다.

예를 들어 이름을 입력받고 인사하는 프로그램은 다음처럼 만들 수 있다.

```python
name = input("이름을 입력하세요: ")
print("안녕하세요", name)
```

여기에는 이미 세 가지 중요한 개념이 들어 있다.

- `input()` : 사용자의 입력 받기
- `name` : 입력한 값을 저장하는 변수
- `print()` : 결과를 화면에 보여주기

## 실행이란?

코드를 작성만 해서는 아무 일도 일어나지 않는다. Python에게 이 코드를 읽고 실제로 처리하라고 해야 한다. 이것을 **실행한다**고 한다.

VS Code 터미널에서 파일 이름이 `hello.py`라면 보통 다음처럼 실행한다.

```powershell
python hello.py
```

## `.py`는 무엇인가?

Python 코드 파일의 확장자다.

```text
hello.py
problem01.py
study.py
```

Windows에서 `.txt`가 메모장 파일을 뜻하는 것처럼 `.py`는 Python 코드 파일이라고 생각하면 된다.

## Python에서 가장 먼저 익힐 흐름

처음에는 모든 문법을 외울 필요가 없다. 아래 흐름만 먼저 익히면 된다.

```text
입력 받기
   ↓
변수에 저장하기
   ↓
필요한 계산하기
   ↓
조건을 확인하거나 반복하기
   ↓
결과 출력하기
```

많은 초급 Python 문제는 결국 이 구조를 조금씩 바꾼 것이다.

## 처음 배울 때 자주 하는 오해

### 1. 코드는 외워야 한다?

아니다. 처음에는 `print()`, `input()`, `if`, `for` 같은 자주 쓰는 것만 익히고 나머지는 필요할 때 찾아도 된다.

### 2. 오류가 뜨면 코드를 전부 잘못 쓴 것이다?

아니다. 괄호 하나, 따옴표 하나, 들여쓰기 한 칸 때문에 오류가 나는 경우도 많다.

### 3. 영어를 잘해야 Python을 할 수 있다?

영어 단어를 조금 알면 편하지만, 대부분의 초급 문법은 반복해서 보다 보면 익숙해진다.

## 직접 해보기

아래 코드를 하나씩 실행해 본다.

```python
print("Python 시작")
print(10)
print(3 + 7)
```

그리고 숫자를 바꾸거나 글자를 바꿔서 결과가 어떻게 달라지는지 확인한다.

## 이번 문서에서 기억할 것

- Python은 컴퓨터에게 일을 시키는 언어다.
- 코드는 위에서 아래로 실행된다.
- `.py`는 Python 코드 파일이다.
- 처음에는 입력 → 저장 → 계산 → 출력 흐름만 잡아도 충분하다.
