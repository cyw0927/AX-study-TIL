# 04. 자주 보는 기호 총정리

Python 코드를 처음 보면 영어 단어보다 기호가 더 무서울 때가 있다. 이 문서는 자주 보는 기호를 한 번에 정리한다.

## `=`
값을 변수에 넣는다.

```python
age = 20
```

읽기: `age`에 20을 넣는다.

## `==`
두 값이 같은지 비교한다.

```python
print(10 == 10)
```

결과는 `True`다.

## `!=`
같지 않은지 비교한다.

```python
print(10 != 5)
```

결과는 `True`다.

## `>`, `<`, `>=`, `<=`
크기를 비교한다.

```python
print(10 > 5)
print(10 >= 10)
```

## `+`, `-`, `*`, `/`
더하기, 빼기, 곱하기, 나누기다.

```python
print(10 + 3)
print(10 - 3)
print(10 * 3)
print(10 / 3)
```

`/`는 보통 소수점 결과가 나온다.

## `//`
몫만 구한다.

```python
print(10 // 3)
```

결과는 `3`이다.

## `%`
나머지를 구한다.

```python
print(10 % 3)
```

결과는 `1`이다.

짝수/홀수 확인할 때 많이 쓴다.

```python
number = 8
print(number % 2)
```

나머지가 0이면 짝수다.

## `()`
함수를 사용할 때 많이 본다.

```python
print("hello")
len([1, 2, 3])
```

## `[]`
리스트를 만들거나 리스트의 위치를 찾을 때 쓴다.

```python
numbers = [10, 20, 30]
print(numbers[0])
```

## `{}`
딕셔너리나 세트를 만들 때 쓴다.

```python
person = {"name": "철수", "age": 20}
```

## `:`
`if`, `for`, `while`, `def`, `class` 뒤에서 자주 본다.

```python
if age >= 20:
    print("성인")
```

`:` 다음 줄부터 들여쓴 부분이 하나의 코드 묶음이 된다.

## `,`
값을 여러 개 나눌 때 쓴다.

```python
print("철수", 20)
```

함수에 여러 값을 전달할 때도 쓴다.

## `.`
어떤 값이 가지고 있는 기능을 사용할 때 자주 본다.

```python
text = "hello"
print(text.upper())
```

읽기: `text`의 `upper()` 기능을 사용한다.

## `#`
주석이다.

```python
# 이 줄은 실행되지 않는다
print("hello")
```

## 따옴표 `' '`와 `" "`
문자열을 만든다.

```python
name1 = "철수"
name2 = '영희'
```

## 자주 헷갈리는 것

```text
=   값 넣기
==  같은지 비교

/   일반 나누기
//  몫
%   나머지

()  함수 호출에 많이 사용
[]  리스트와 인덱스
{}  딕셔너리와 세트
```

기호를 외우려고 하기보다 코드를 볼 때 하나씩 읽는 습관을 들이면 된다.
