# 05. 코드 한 줄 읽는 법

초보자는 코드를 보면 한 줄 전체가 한꺼번에 덩어리처럼 보이기 쉽다. 그런데 Python 코드는 대부분 작은 조각으로 나누면 이해할 수 있다.

## 예제 1

```python
age = int(input())
```

이걸 오른쪽부터 읽어 본다.

1. `input()`으로 키보드 입력을 받는다.
2. 입력값은 문자열이다.
3. `int(...)`로 정수로 바꾼다.
4. 결과를 `age`에 넣는다.

즉 한 문장으로 읽으면:

> 입력을 받아 숫자로 바꾼 뒤 age에 저장한다.

## 예제 2

```python
height, width = map(int, input().split())
```

처음 보면 길지만 조각내면 된다.

```python
text = input()
parts = text.split()
numbers = map(int, parts)
height, width = numbers
```

실제로는 위 과정을 한 줄로 적은 것이다.

입력이 다음이라면:

```text
3 5
```

흐름은:

```text
"3 5"
↓ split()
["3", "5"]
↓ map(int, ...)
3, 5
↓
height = 3
width = 5
```

## 예제 5

```python
for number in numbers:
```

읽기:

> numbers 안의 값을 하나씩 꺼내서 이번에는 number라고 부른다.

`number`라는 변수는 반복할 때마다 값이 바뀐다.

## 예제 6

```python
result = "1" if score >= 60 else "0"
```

이런 한 줄짜리 표현은 초보 때 굳이 바로 익힐 필요 없다. 먼저 아래처럼 읽는 편이 쉽다.

```python
if score >= 60:
    result = "1"
else:
    result = "0"
```

둘은 같은 뜻이다.

## 긴 코드 읽을 때 순서

보통 아래 순서로 보면 편하다.

```text
1. 어디서 값을 받나?

3. 무엇을 계산하나?
4. 반복문이 있나?
5. 조건문이 있나?
6. 마지막에 무엇을 출력하나?
```

## 모르는 줄이 나오면

예를 들어:

```python
r, g, b = map(int, pixel.split(","))
```

전체를 외우지 말고 다음처럼 분해한다.

```python
parts = pixel.split(",")
print(parts)

numbers = list(map(int, parts))
print(numbers)

r, g, b = numbers
print(r, g, b)
```

한 줄을 여러 줄로 풀어쓰는 것은 나쁜 코딩이 아니다. 처음 배우는 동안에는 오히려 매우 좋은 공부 방법이다.
