# 02. 진짜 기본 용어

이 문서는 Python 코드를 처음 볼 때 가장 자주 만나는 말을 아주 쉽게 설명한다. 처음부터 외우려고 하지 말고, 코드를 볼 때 모르는 단어가 나오면 여기서 찾아보는 식으로 사용하면 된다.

## `print()`

화면에 값을 보여주는 함수다.

```python
print("안녕하세요")
print(10)
print(3 + 5)
```

결과:

```text
안녕하세요
10
8
```

초보 단계에서는 계산 결과나 변수 안의 값을 확인할 때 정말 많이 사용한다.

```python
age = 20
print(age)
```

오류를 찾을 때도 자주 쓴다.

```python
x = 10
y = 20
print("x:", x)
print("y:", y)
print("합계:", x + y)
```

## `input()`

사용자가 키보드로 입력한 값을 받는 함수다.

```python
name = input()
print(name)
```

프로그램이 `input()`을 만나면 바로 다음 코드로 가지 않고 사용자가 값을 입력할 때까지 기다린다.

```python
name = input("이름을 입력하세요: ")
print("안녕하세요", name)
```

중요한 점은 `input()`으로 받은 값은 기본적으로 문자열이라는 것이다.

```python
age = input()
print(type(age))
```

20을 입력해도 결과는 다음과 같다.

```text
<class 'str'>
```

숫자로 계산하려면 정수로 바꿔야 한다.

```python
age = int(input())
```

### `input().split()`은 왜 자주 보일까?

한 줄에 값을 여러 개 입력할 때 자주 쓴다.

```python
text = "10 20 30"
print(text.split())
```

결과:

```text
['10', '20', '30']
```

아직 문자열이므로 숫자로 바꾸려면:

```python
numbers = list(map(int, "10 20 30".split()))
print(numbers)
```

처음에는 이 한 줄이 너무 길면 다음처럼 나눠서 보면 된다.

```python
text = "10 20 30"
parts = text.split()
numbers = list(map(int, parts))

print(text)
print(parts)
print(numbers)
```

## 변수

값을 저장해 두고 이름을 붙여 놓은 것이다.

```python
name = "철수"
age = 20
```

`name`에는 `"철수"`, `age`에는 `20`이 들어 있다.

변수는 상자라고 생각해도 된다.

```text
name 상자 → "철수"
age 상자  → 20
```

변수의 값은 바꿀 수도 있다.

```python
score = 70
print(score)

score = 90
print(score)
```

두 번째 `score = 90`을 실행하면 이전 70 대신 90이 들어간다.

## 변수 이름

```python
student_name = "철수"
score = 80
```

무슨 값인지 알아볼 수 있게 이름을 짓는 게 좋다.

```python
x = 80
```

처럼 짧게 써도 되지만 코드가 길어지면 무슨 뜻인지 헷갈릴 수 있다.

## `=`

오른쪽 값을 왼쪽 변수에 넣는다는 뜻이다.

```python
x = 10
```

수학에서의 "같다"와는 느낌이 조금 다르다.

## `==`

두 값이 같은지 비교한다.

```python
print(10 == 10)
print(10 == 5)
```

결과:

```text
True
False
```

정리하면:

```text
=   값을 넣는다
==  같은지 물어본다
```

## 자료형

값의 종류라고 생각하면 된다.

```text
10       → int
3.14     → float
"hello"  → str
True     → bool
[1,2,3]  → list
```

같이 생긴 값도 자료형에 따라 다르게 동작한다.

```python
print(2 + 3)
print("2" + "3")
```

결과:

```text
5
23
```

## `str`

문자열이라는 뜻이다.

```python
name = "철수"
number_text = "100"
```

`"100"`은 숫자처럼 보여도 따옴표 안에 있으므로 문자열이다.

```python
print("2" + "3")
```

결과는 5가 아니라 `23`이다.

## `int`

정수다. 소수점 없는 숫자라고 생각하면 된다.

```python
10
0
-5
1000
```

문자열 숫자를 정수로 바꿀 수도 있다.

```python
x = int("100")
print(x + 1)
```

결과:

```text
101
```

## `float`

소수점이 있는 숫자다.

```python
3.14
2.5
0.1
```

```python
x = 10 / 4
print(x)
print(type(x))
```

결과:

```text
2.5
<class 'float'>
```

## `bool`

참과 거짓을 저장하는 자료형이다.

```python
is_adult = True
is_student = False
```

조건문의 결과도 보통 `True` 또는 `False`가 된다.

```python
print(10 > 5)
```

## `type()`

값의 자료형이 무엇인지 확인한다.

```python
print(type(10))
print(type("10"))
print(type(3.14))
```

결과:

```text
<class 'int'>
<class 'str'>
<class 'float'>
```

오류가 날 때 `type()`으로 현재 값이 문자열인지 숫자인지 확인하면 도움이 많이 된다.

## 함수

어떤 일을 하도록 미리 만들어 둔 코드 묶음이다.

이미 사용한 것도 함수다.

```python
print()
input()
int()
type()
```

나중에는 직접 함수도 만들 수 있다.

```python
def hello():
    print("안녕하세요")
```

## 함수 호출

함수를 실제로 사용하는 것을 함수 호출이라고 한다.

```python
print("hello")
```

여기서는 `print` 함수를 호출한 것이다.

## 인자

함수 괄호 안에 넣어주는 값이다.

```python
print("hello")
```

여기서 `"hello"`가 `print()`에게 전달한 값이다.

처음에는 인자, 매개변수 같은 말을 완벽하게 구분하지 못해도 괜찮다. 함수 안으로 값을 전달한다는 감각부터 잡으면 된다.

## 괄호 `()`

함수를 사용할 때 자주 보인다.

```python
print("hello")
input()
int("10")
```

괄호 안에는 함수에게 전달할 값을 넣을 수 있다.

## 대괄호 `[]`

리스트를 만들거나 리스트 안의 값을 꺼낼 때 자주 본다.

```python
numbers = [10, 20, 30]
print(numbers[0])
```

첫 번째 값인데 `[0]`이라는 점이 중요하다. Python은 위치 번호를 0부터 센다.

## 중괄호 `{}`

딕셔너리나 세트를 만들 때 사용한다.

```python
person = {"name": "철수", "age": 20}
```

## 콜론 `:`

조건문, 반복문, 함수, 클래스 뒤에서 많이 보인다.

```python
if age >= 20:
    print("성인")
```

콜론 다음 줄은 들여쓰기해서 해당 코드 묶음에 포함시킨다.

## 들여쓰기

Python에서는 앞쪽의 공백도 문법이다.

```python
if True:
    print("실행됨")
```

다음처럼 들여쓰기가 없으면 오류가 날 수 있다.

```python
if True:
print("실행됨")
```

보통 스페이스 4칸을 사용한다.

## 따옴표 `" "`, `' '

문자열을 표시한다.

```python
name1 = "철수"
name2 = '영희'
```

둘 다 문자열이다.

## 주석 `#`

코드 설명을 적는 데 사용한다. Python은 `#` 뒤의 내용을 실행하지 않는다.

```python
# 나이를 저장한다
age = 20

print(age)  # 화면에 나이 출력
```

## `True`, `False`

참과 거짓을 나타낸다.

```python
print(10 > 5)
print(10 < 5)
```

결과:

```text
True
False
```

조건문에서 아주 많이 사용된다.

## `None`

"아무 값도 없음"을 나타내는 특별한 값이다.

```python
x = None
print(x)
```

0이나 빈 문자열과는 다른 값이다.

## 메서드

어떤 값에 붙여서 사용하는 함수 같은 것이다.

```python
text = "hello world"
print(text.upper())
```

여기서 `upper()`는 문자열이 가지고 있는 메서드다.

```python
numbers = []
numbers.append(10)
```

여기서 `append()`는 리스트의 메서드다.

처음에는:

```text
print()       → 그냥 함수
text.upper()  → 값 뒤에 점을 붙여 쓰는 메서드
```

정도로 구분하면 충분하다.

## `.` 점

객체가 가지고 있는 기능이나 값을 사용할 때 자주 본다.

```python
text.upper()
numbers.append(10)
df.head()
```

처음 보는 긴 코드가 있으면 점을 기준으로 잘라서 읽어보는 것도 도움이 된다.

## 직접 확인해 보기

```python
name = input("이름: ")
age = input("나이: ")

print(name)
print(age)
print(type(name))
print(type(age))
```

그다음 아래처럼 바꿔 본다.

```python
age = int(input("나이: "))
print(type(age))
```

이 차이를 이해하면 `input()` 관련 오류를 훨씬 쉽게 이해할 수 있다.

## 이 문서에서 먼저 기억할 10개

처음부터 전부 외우기 어렵다면 이것만 먼저 기억한다.

```text
print() = 화면에 출력
input() = 입력 받기
변수 = 값 저장
= = 값 넣기
== = 같은지 비교
str = 문자열
int = 정수
type() = 자료형 확인
[] = 리스트에서 자주 사용
: + 들여쓰기 = 코드 묶음 시작
```

나머지는 실제 코드에서 만날 때마다 다시 찾아보면 된다.
