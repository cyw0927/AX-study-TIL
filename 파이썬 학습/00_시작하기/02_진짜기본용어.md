# 02. 진짜 기본 용어

이 문서는 Python 코드를 처음 볼 때 가장 자주 만나는 말을 아주 쉽게 설명한다.

## `print()`

화면에 값을 보여주는 함수다.

```python
print("안녕하세요")
print(10)
print(3 + 5)
```

결과:

```text
안녕하세요
10
8
```

초보 단계에서는 계산 결과나 변수 안의 값을 확인할 때 정말 많이 사용한다.

```python
age = 20
print(age)
```

## `input()`

사용자가 키보드로 입력한 값을 받는 함수다.

```python
name = input()
print(name)
```

프로그램이 `input()`을 만나면 바로 다음 코드로 가지 않고 사용자가 값을 입력할 때까지 기다린다.

중요한 점은 `input()`으로 받은 값은 기본적으로 문자열이라는 것이다.

```python
age = input()
print(type(age))
```

20을 입력해도 결과는 다음과 같다.

```text
<class 'str'>
```

숫자로 계산하려면 정수로 바꿔야 한다.

```python
age = int(input())
```

## 변수

값을 저장해 두고 이름을 붙여 놓은 것이다.

```python
name = "철수"
age = 20
```

`name`에는 `"철수"`, `age`에는 `20`이 들어 있다.

변수는 상자라고 생각해도 된다.

```text
name 상자 → "철수"
age 상자  → 20
```

## `=`

오른쪽 값을 왼쪽 변수에 넣는다는 뜻이다.

```python
x = 10
```

수학에서의 "같다"와는 느낌이 조금 다르다.

## `==`

두 값이 같은지 비교한다.

```python
print(10 == 10)
print(10 == 5)
```

결과:

```text
True
False
```

정리하면:

```text
=   값을 넣는다
==  같은지 물어본다
```

## `str`

문자열이라는 뜻이다.

```python
name = "철수"
number_text = "100"
```

`"100"`은 숫자처럼 보여도 따옴표 안에 있으므로 문자열이다.

```python
print("2" + "3")
```

결과는 5가 아니라 `23`이다.

## `int`

정수다. 소수점 없는 숫자라고 생각하면 된다.

```python
10
0
-5
1000
```

문자열 숫자를 정수로 바꿀 수도 있다.

```python
x = int("100")
print(x + 1)
```

결과:

```text
101
```

## `float`

소수점이 있는 숫자다.

```python
3.14
2.5
0.1
```

```python
x = 10 / 4
print(x)
print(type(x))
```

결과:

```text
2.5
<class 'float'>
```

## `type()`

값의 자료형이 무엇인지 확인한다.

```python
print(type(10))
print(type("10"))
print(type(3.14))
```

결과:

```text
<class 'int'>
<class 'str'>
<class 'float'>
```

오류가 날 때 `type()`으로 현재 값이 문자열인지 숫자인지 확인하면 도움이 많이 된다.

## 함수

어떤 일을 하도록 미리 만들어 둔 코드 묶음이다.

이미 사용한 것도 함수다.

```python
print()
input()
int()
type()
```

나중에는 직접 함수도 만들 수 있다.

```python
def hello():
    print("안녕하세요")
```

## 괄호 `()`

함수를 사용할 때 자주 보인다.

```python
print("hello")
input()
int("10")
```

괄호 안에는 함수에게 전달할 값을 넣을 수 있다.

## 따옴표 `" "`, `' '

문자열을 표시한다.

```python
name1 = "철수"
name2 = '영희'
```

둘 다 문자열이다.

## 주석 `#`

코드 설명을 적는 데 사용한다. Python은 `#` 뒤의 내용을 실행하지 않는다.

```python
# 나이를 저장한다
age = 20

print(age)  # 화면에 나이 출력
```

## `True`, `False`

참과 거짓을 나타낸다.

```python
print(10 > 5)
print(10 < 5)
```

결과:

```text
True
False
```

조건문에서 아주 많이 사용된다.

## `None`

"아무 값도 없음"을 나타내는 특별한 값이다.

```python
x = None
print(x)
```

0이나 빈 문자열과는 다른 값이다.

## 직접 확인해 보기

```python
name = input("이름: ")
age = input("나이: ")

print(name)
print(age)
print(type(name))
print(type(age))
```

그다음 아래처럼 바꿔 본다.

```python
age = int(input("나이: "))
print(type(age))
```

이 차이를 이해하면 `input()` 관련 오류를 훨씬 쉽게 이해할 수 있다.
