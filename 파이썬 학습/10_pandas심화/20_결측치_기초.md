# pandas 결측치 기초

결측치는 **값이 비어 있는 데이터**다.

엑셀에서 셀이 비어 있거나, CSV에서 어떤 값이 빠져 있으면 pandas에서는 `NaN`처럼 보일 수 있다.

## 예제 데이터

```python
import pandas as pd

data = {
    "name": ["철수", "영희", "민수"],
    "score": [90, None, 80]
}

df = pd.DataFrame(data)
print(df)
```

`영희`의 점수 자리에 값이 없다.

## `isna()`

어디가 비어 있는지 확인한다.

```python
print(df.isna())
```

값이 비어 있으면 `True`, 있으면 `False`가 나온다.

특정 열만 확인:

```python
print(df["score"].isna())
```

## 결측치 개수 세기

```python
print(df.isna().sum())
```

각 열마다 몇 개가 비어 있는지 확인할 수 있다.

## `dropna()`

결측치가 있는 행을 제거한다.

```python
clean_df = df.dropna()
print(clean_df)
```

원본 `df`가 자동으로 바뀌는 것은 아니다.

## `fillna()`

빈 값을 다른 값으로 채운다.

```python
filled_df = df.fillna(0)
print(filled_df)
```

점수의 빈칸을 평균값으로 채울 수도 있다.

```python
average = df["score"].mean()
df["score"] = df["score"].fillna(average)
```

## 무조건 지우면 안 된다

결측치가 있다고 항상 행을 삭제하는 것은 아니다.

예를 들어:

- 점수가 비어 있음 → 입력 누락일 수 있음
- 전화번호가 비어 있음 → 원래 없는 사람일 수 있음
- 설문 응답이 비어 있음 → 답하지 않은 것일 수 있음

즉, **왜 비어 있는지 먼저 생각해야 한다.**

## 초보자 확인 순서

```text
1. df.head()로 데이터 확인
2. df.info() 확인
3. df.isna().sum()으로 빈 값 개수 확인
4. 지울지 채울지 결정
5. 처리 후 다시 확인
```

## 직접 연습

```python
import pandas as pd

df = pd.DataFrame({
    "product": ["A", "B", "C", "D"],
    "price": [1000, None, 3000, None]
})

print(df)
print(df.isna().sum())
print(df.fillna(0))
print(df.dropna())
```

`fillna()`와 `dropna()`의 결과가 어떻게 다른지 비교해 본다.
