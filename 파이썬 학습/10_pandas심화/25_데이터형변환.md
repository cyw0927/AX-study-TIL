# 25. pandas 데이터 형변환

CSV를 읽었는데 숫자가 숫자처럼 계산되지 않을 때가 있다. 그럴 때 먼저 **자료형**을 확인해야 한다.

## 자료형 확인

```python
print(df.dtypes)
```

예를 들어:

```text
name     object
score    object
age       int64
```

`score`가 숫자처럼 보여도 `object`라면 문자열일 수 있다.

## `astype(int)`

```python
df["score"] = df["score"].astype(int)
```

문자열 숫자를 정수로 바꾼다.

## 소수로 바꾸기

```python
df["price"] = df["price"].astype(float)
```

## 그런데 이상한 값이 섞여 있다면?

```text
80
90
없음
70
```

이런 열에 바로 `astype(int)`를 쓰면 오류가 날 수 있다.

이럴 때 `pd.to_numeric()`을 쓸 수 있다.

```python
df["score"] = pd.to_numeric(df["score"], errors="coerce")
```

숫자로 바꿀 수 없는 값은 `NaN`으로 바뀐다.

## 날짜로 바꾸기

```python
df["date"] = pd.to_datetime(df["date"])
```

문자열 날짜를 날짜 자료형으로 바꾼다.

## 왜 형변환이 중요할까?

문자열 상태에서는 숫자 계산이 이상해질 수 있다.

```python
print("10" + "20")
```

결과는 `30`이 아니라 `1020`이다.

데이터 분석에서도 같은 문제가 생긴다.

## CSV 읽은 뒤 확인 순서

```python
import pandas as pd

df = pd.read_csv("data.csv")

print(df.head())
print(df.info())
print(df.dtypes)
```

그다음 숫자인데 문자열로 읽힌 열이 있는지 확인한다.

## 자주 하는 실수

형변환을 했는데 저장하지 않는 경우:

```python
df["score"].astype(int)
```

이렇게만 하면 원래 `df`에 반영되지 않을 수 있다.

보통:

```python
df["score"] = df["score"].astype(int)
```

처럼 다시 넣어 준다.

## 직접 연습

```python
import pandas as pd

data = {
    "score": ["80", "90", "70"],
    "price": ["10.5", "20.0", "5.5"]
}

df = pd.DataFrame(data)

print(df.dtypes)

df["score"] = df["score"].astype(int)
df["price"] = df["price"].astype(float)

print(df.dtypes)
print(df["score"].mean())
```

형변환 전과 후의 `dtypes`가 어떻게 달라지는지 확인한다.
