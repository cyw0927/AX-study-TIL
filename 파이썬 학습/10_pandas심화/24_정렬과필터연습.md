# 24. pandas 정렬과 필터 연습

pandas에서 많이 하는 일은 **필요한 행만 골라 보고, 원하는 순서로 정렬하는 것**이다.

## 예제 데이터

```python
import pandas as pd

data = {
    "name": ["철수", "영희", "민수", "지수"],
    "score": [80, 95, 60, 75],
    "age": [20, 21, 19, 22]
}

df = pd.DataFrame(data)
print(df)
```

## 점수가 80 이상인 사람만 보기

```python
result = df[df["score"] >= 80]
print(result)
```

안쪽부터 보면:

```python
df["score"] >= 80
```

각 행이 조건에 맞는지 `True`, `False`로 만든다.

그 결과를 다시 `df[...]`에 넣어서 조건에 맞는 행만 가져온다.

## 나이가 20 이상인 사람

```python
result = df[df["age"] >= 20]
print(result)
```

## 조건 두 개 같이 쓰기

```python
result = df[(df["score"] >= 70) & (df["age"] >= 20)]
print(result)
```

pandas에서는 `and` 대신 `&`를 자주 사용한다.
각 조건은 괄호로 묶어 주는 것이 안전하다.

## 점수 높은 순서로 정렬

```python
result = df.sort_values("score", ascending=False)
print(result)
```

`ascending=False`는 큰 값부터 보겠다는 뜻이다.

## 점수 낮은 순서

```python
result = df.sort_values("score")
print(result)
```

기본값은 작은 값부터다.

## 여러 기준으로 정렬

```python
result = df.sort_values(["score", "age"], ascending=[False, True])
print(result)
```

먼저 점수는 높은 순서, 점수가 같다면 나이는 낮은 순서로 정렬한다.

## 필요한 열만 같이 보기

```python
result = df[df["score"] >= 70][["name", "score"]]
print(result)
```

처음에는 한 줄이 길어 보이면 두 줄로 나눠도 된다.

```python
filtered = df[df["score"] >= 70]
result = filtered[["name", "score"]]
print(result)
```

초보 단계에서는 이렇게 나눠 쓰는 편이 훨씬 이해하기 쉽다.
