# 08. 딕셔너리 — 이름표를 붙여서 값을 저장하기

리스트는 값을 순서대로 저장한다. 딕셔너리는 값마다 이름표를 붙여서 저장한다.

예를 들어 학생 정보를 저장한다고 해보자.

```python
student = {
    "name": "철수",
    "age": 20,
    "score": 85
}
```

여기서 `name`, `age`, `score`는 이름표이고, 그 뒤의 값이 실제 데이터다.

## 1. 딕셔너리는 왜 쓰나?

리스트로 학생 정보를 저장하면 이렇게 할 수도 있다.

```python
student = ["철수", 20, 85]
```

그런데 나중에 `student[1]`이 나이인지 점수인지 헷갈릴 수 있다.

딕셔너리를 쓰면:

```python
student["age"]
```

라고 적을 수 있어서 훨씬 알아보기 쉽다.

## 2. 값 꺼내기

```python
student = {
    "name": "철수",
    "age": 20
}

print(student["name"])
print(student["age"])
```

결과:

```text
철수
20
```

## 3. 값 바꾸기

```python
student["age"] = 21
```

이제 age 값은 21이 된다.

## 4. 새 값 추가하기

```python
student["city"] = "서울"
```

기존에 없던 `city`라는 이름표가 새로 추가된다.

## 5. key와 value

딕셔너리에서 이름표를 `key`, 실제 값을 `value`라고 부른다.

```python
student = {
    "name": "철수",
    "age": 20
}
```

- `name`, `age` → key
- `철수`, `20` → value

## 6. `keys()`

딕셔너리의 key만 보고 싶을 때 쓴다.

```python
print(student.keys())
```

## 7. `values()`

값만 보고 싶을 때 쓴다.

```python
print(student.values())
```

## 8. `items()`

key와 value를 같이 보고 싶을 때 쓴다.

```python
for key, value in student.items():
    print(key, value)
```

## 9. `get()`

없는 key를 꺼낼 때 오류가 나는 것을 피하고 싶으면 `get()`을 쓸 수 있다.

```python
print(student.get("phone"))
```

없는 값이면 기본적으로 `None`이 나온다.

기본값을 정할 수도 있다.

```python
print(student.get("phone", "없음"))
```

## 10. 리스트와 딕셔너리 차이

리스트:

```python
foods = ["짜장면", "짬뽕", "탕수육"]
print(foods[0])
```

딕셔너리:

```python
menu = {
    "first": "짜장면",
    "second": "짬뽕"
}
print(menu["first"])
```

리스트는 순서 번호로 찾고, 딕셔너리는 이름표로 찾는다고 생각하면 쉽다.

## 처음에는 이것만 기억

- 딕셔너리는 `{}`를 쓴다.
- `key: value` 형태로 저장한다.
- `data["key"]`로 값을 꺼낸다.
- 리스트는 번호, 딕셔너리는 이름표로 찾는다.
- `items()`를 쓰면 key와 value를 같이 반복할 수 있다.
