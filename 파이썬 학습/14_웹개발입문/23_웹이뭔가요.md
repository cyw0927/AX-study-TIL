# 23. 웹이 뭔가요?

웹개발을 시작하면 갑자기 HTML, CSS, JavaScript, 서버, 브라우저 같은 말이 한꺼번에 나온다. 처음에는 이 말들을 전부 외우려고 하지 말고 **누가 화면을 만들고, 누가 데이터를 처리하는지**부터 구분하면 된다.

## 웹사이트를 아주 단순하게 보면

우리가 브라우저에서 보는 화면은 보통 이런 흐름으로 움직인다.

```text
사용자
  ↓
브라우저
  ↓ 요청
서버
  ↓ 응답
브라우저에 화면 표시
```

예를 들어 주소창에 어떤 사이트 주소를 입력하면 브라우저가 서버에 "이 페이지 보여줘"라고 요청한다. 서버는 필요한 내용을 준비해서 브라우저에 보내고, 브라우저는 그것을 화면에 보여준다.

## 브라우저

Chrome, Edge, Safari 같은 프로그램이다.

쉽게 말하면 웹사이트를 보는 창이다.

브라우저는 서버에서 받은 HTML, CSS, JavaScript를 읽어서 화면으로 보여준다.

## HTML

웹페이지의 **뼈대**를 만든다.

```html
<h1>안녕하세요</h1>
<p>첫 웹페이지입니다.</p>
```

`h1`은 큰 제목, `p`는 문단이라고 생각하면 된다.

Python 문법은 아니다. 웹페이지 구조를 적는 별도의 언어다.

## CSS

화면의 모양을 꾸민다.

```css
h1 {
    font-size: 30px;
}
```

글자 크기, 간격, 배치, 색상 같은 것을 정한다.

초보 기준으로는 이렇게 기억하면 된다.

```text
HTML = 무엇을 보여줄까
CSS  = 어떻게 꾸밀까
```

## JavaScript

웹페이지에서 움직임이나 상호작용을 만들 때 많이 쓴다.

예를 들어 버튼을 누르면 내용이 바뀌는 기능 같은 것이다.

Python과 JavaScript는 둘 다 프로그래밍 언어지만 같은 언어는 아니다.

## 서버

사용자의 요청을 받고 필요한 처리를 한 뒤 결과를 보내주는 쪽이다.

예를 들어 로그인 화면에서 아이디와 비밀번호를 입력했다고 하자.

```text
브라우저: 로그인할게요
        ↓
서버: 계정 정보 확인
        ↓
서버: 로그인 성공/실패 결과 전달
```

Python은 이 서버 쪽 프로그램을 만드는 데도 사용할 수 있다.

## 프론트엔드와 백엔드

처음 들으면 거창하지만 크게 어렵지 않다.

### 프론트엔드

사용자가 직접 보는 화면 쪽이다.

주로:

```text
HTML
CSS
JavaScript
```

을 사용한다.

### 백엔드

화면 뒤에서 데이터를 처리하는 쪽이다.

예를 들어:

- 로그인 확인
- 회원 정보 저장
- 게시글 저장
- 데이터베이스 조회
- 계산 결과 만들기

Python은 백엔드 개발에 많이 사용된다.

## Flask는 뭐지?

Flask는 Python으로 간단한 웹 서버를 만들 수 있게 도와주는 도구다.

아주 작은 예:

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def home():
    return "안녕하세요"

app.run()
```

처음 보면 복잡해 보이지만 지금은 한 줄씩 다 이해하려고 하지 않아도 된다.

핵심은:

```text
/ 주소로 들어오면
home() 함수를 실행하고
"안녕하세요"를 돌려준다
```

정도로 이해하면 된다.

## localhost는 뭐지?

내 컴퓨터 자신을 가리키는 주소다.

웹개발을 연습할 때 서버를 인터넷에 공개하지 않고 내 컴퓨터에서만 실행할 수 있다.

```text
http://127.0.0.1:5000
```

같은 주소를 자주 보게 된다.

`127.0.0.1`은 내 컴퓨터를 뜻하고, `5000`은 프로그램이 사용하는 문 번호 같은 것이라고 생각하면 된다.

## 포트(port)

한 컴퓨터 안에서도 여러 프로그램이 네트워크를 사용할 수 있다. 포트 번호는 어느 프로그램으로 갈지 구분하는 번호처럼 생각하면 된다.

```text
127.0.0.1:5000
          ↑
        포트 번호
```

## 처음에는 여기까지만 기억

```text
브라우저 = 웹사이트를 보는 프로그램
HTML     = 화면의 뼈대
CSS      = 화면 꾸미기
JavaScript = 화면의 동작
서버     = 요청을 받아 처리하는 프로그램
Python   = 서버 프로그램을 만들 때 사용할 수 있음
Flask    = Python으로 웹 서버를 쉽게 만드는 도구
localhost = 내 컴퓨터
```

웹개발 코드를 볼 때 이 구분만 되어도 훨씬 덜 복잡해 보인다.
