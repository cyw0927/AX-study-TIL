# 파이썬 개초보 학습 폴더

목표는 코드를 외우는 것이 아니라, **코드 한 줄을 보고 '이게 왜 필요한지' 설명할 수 있게 되는 것**이다.

## 공부 방법

- 처음부터 전부 외우려고 하지 않는다.
- 예제 코드를 직접 한 줄씩 실행한다.
- 결과가 예상과 다르면 `print()`와 `type()`으로 값을 확인한다.
- 모르는 문법이 나오면 그 문법 하나만 떼어내서 작은 예제로 실행한다.
- 긴 코드를 한 번에 이해하려고 하지 말고, 입력 → 저장 → 계산 → 조건 → 출력 순서로 쪼개서 본다.

이 문서는 앞으로 Python 공부 중 새로 만나는 용어가 생길 때 계속 추가한다.
