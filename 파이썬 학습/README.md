## 공부 방법

- 처음부터 전부 외우려고 하지 않는다.
- 예제 코드를 직접 한 줄씩 실행한다.
- 실행 전에 결과를 한번 예상한다.
- 결과가 예상과 다르면 `print()`로 중간값을 본다.
- 자료형이 헷갈리면 `type()`을 사용한다.
- 리스트 크기가 헷갈리면 `len()`을 사용한다.
- 오류가 나오면 마지막 줄의 오류 이름부터 확인한다.
- 긴 코드는 입력 → 저장 → 계산 → 조건/반복 → 출력 순서로 쪼개서 본다.
- 같은 문법도 작은 예제로 여러 번 직접 바꿔 실행한다.
