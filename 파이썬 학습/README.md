# 파이썬 개초보 학습 폴더

Python을 처음 배우는 사람 기준으로 만든 용어집 + 실습 노트다.

목표는 코드를 외우는 것이 아니라 **코드 한 줄을 보고 무슨 일이 일어나는지 설명할 수 있게 되는 것**이다.

내용이 늘어나면서 한 폴더에 파일을 전부 두기보다 주제별 하위 폴더로 나누고 있다. 모르는 용어가 생기면 처음부터 전부 다시 읽지 말고 `00_시작하기/03_용어빠르게찾기.md`에서 먼저 찾아보면 된다.

## 공부 방법

- 처음부터 전부 외우려고 하지 않는다.
- 예제 코드를 직접 한 줄씩 실행한다.
- 실행 전에 결과를 한번 예상한다.
- 결과가 예상과 다르면 `print()`로 중간값을 본다.
- 자료형이 헷갈리면 `type()`을 사용한다.
- 리스트 크기가 헷갈리면 `len()`을 사용한다.
- 오류가 나오면 마지막 줄의 오류 이름부터 확인한다.
- 긴 코드는 입력 → 저장 → 계산 → 조건/반복 → 출력 순서로 쪼개서 본다.
- 같은 문법도 작은 예제로 여러 번 직접 바꿔 실행한다.
- 한 줄짜리 고급 표현보다 여러 줄로 쪼갠 코드를 먼저 이해한다.
