## 공부 방법

- 처음부터 전부 외우려고 하지 않는다.
- 코드는 직접 입력하고 실행해 본다.
- 실행 전에 결과를 한번 예상한다.
- 결과가 이상하면 `print()`로 중간값을 확인한다.
- 자료형이 헷갈리면 `type()`을 쓴다.
- 리스트 크기가 헷갈리면 `len()`을 쓴다.
- 오류 메시지는 마지막 줄의 오류 이름부터 본다.
- 긴 코드는 입력 → 저장 → 계산 → 조건/반복 → 출력으로 쪼개서 본다.
- 한 줄짜리 고급 표현보다 여러 줄로 풀어 쓴 코드를 먼저 이해한다.
- 새 문법을 만나면 작은 예제로 떼어내서 실험한다.

## 앞으로 보강할 내용

새 분야를 무작정 늘리기보다 기존 주제를 더 깊게 만든다.

```text
00_시작하기/
  ├─ 자주 보는 기호 총정리
  └─ 코드 한 줄 읽는 법

01_자료형과문자열/
  └─ 2차원 리스트 구조

02_조건문과반복문/
  └─ 중첩 반복문 더 자세히

08_객체지향입문/
  ├─ 객체와 인스턴스
  └─ 클래스 연습

10_pandas심화/
  ├─ 정렬과 필터 연습
  └─ 데이터 형변환

13_Git과GitHub/
  ├─ branch와 merge
  └─ 충돌 해결

14_웹개발입문/
  ├─ 로그인 흐름
  └─ Flask와 DB 연결

15_미니프로젝트/
  ├─ 메뉴 추천기
  ├─ 간단한 가계부
  └─ CSV 분석기

16_알고리즘문제풀이/
  ├─ 테스트케이스 만들기
  └─ 디버깅 연습
```

처음 만들었던 평면 구조 문서도 아직 남아 있다. 새 하위 폴더 문서가 더 자세한 개정판이며, 내용 비교가 끝난 뒤 기존 문서는 별도 초안 폴더로 정리할 예정이다.
