# 파이썬 개초보 학습 폴더

이 폴더는 Python을 처음 배우는 사람 기준으로 만든 용어집과 실습 노트다.

목표는 코드를 외우는 것이 아니라, **코드 한 줄을 보고 '이게 왜 필요한지' 설명할 수 있게 되는 것**이다.

처음 보는 용어가 많아도 정상이다. 한 번에 다 외우는 대신, 필요한 문법을 하나씩 작은 예제로 직접 실행해 보는 방식으로 공부한다.

## 공부 방법

- 처음부터 전부 외우려고 하지 않는다.
- 예제 코드를 직접 한 줄씩 실행한다.
- 실행 전에 결과를 한 번 예상해 본다.
- 결과가 예상과 다르면 `print()`와 `type()`으로 값을 확인한다.
- 모르는 문법이 나오면 그 문법 하나만 떼어내서 작은 예제로 실행한다.
- 긴 코드를 한 번에 이해하려고 하지 말고, 입력 → 저장 → 계산 → 조건 → 출력 순서로 쪼개서 본다.
- 오류 메시지가 나오면 코드 전체를 뜯어고치기보다 마지막 줄과 오류가 난 위치부터 확인한다.
