# 미니프로젝트 - 메뉴 추천기

이번에는 아주 작은 프로그램을 직접 묶어 본다.

목표는 여러 문법을 한 번에 많이 쓰는 것이 아니라, 지금까지 배운 기초를 연결하는 것이다.

## 1단계: 메뉴 리스트 만들기

```python
menus = ["짜장면", "짬뽕", "탕수육", "볶음밥"]
print(menus)
```

## 2단계: 번호로 고르기

```python
number = int(input("0~3 중 숫자 입력: "))
print(menus[number])
```

여기서는 리스트와 인덱스를 사용한다.

## 3단계: 범위를 벗어나면?

```python
number = int(input("0~3 중 숫자 입력: "))

if 0 <= number < len(menus):
    print("추천 메뉴:", menus[number])
else:
    print("잘못된 번호입니다.")
```

`len(menus)`는 메뉴 개수다.

## 4단계: 랜덤 추천

```python
import random

menus = ["짜장면", "짬뽕", "탕수육", "볶음밥"]
choice = random.choice(menus)

print("오늘의 추천:", choice)
```

`random.choice()`는 리스트에서 하나를 고른다.

## 5단계: 카테고리 추가

```python
menus = {
    "면": ["짜장면", "짬뽕"],
    "밥": ["볶음밥", "잡채밥"]
}
```

이제 딕셔너리 안에 리스트가 들어 있다.

```python
category = input("면 또는 밥 입력: ")

if category in menus:
    print(random.choice(menus[category]))
else:
    print("없는 카테고리입니다.")
```

## 이 프로젝트에서 복습하는 것

- 리스트
- 인덱스
- `len()`
- `input()`
- `int()`
- `if`
- 딕셔너리
- `import`
- 함수 호출
