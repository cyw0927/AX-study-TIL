# 27. 첫 미니프로젝트 — 점수 평균 프로그램

문법을 따로따로 공부하다 보면 `input`, `list`, `for`, `if`, 함수가 왜 필요한지 감이 잘 안 올 수 있다. 그래서 작은 프로그램 하나를 직접 만들어 보는 게 좋다.

이번에는 **학생 점수를 입력받아 평균을 계산하고, 평균에 따라 메시지를 출력하는 프로그램**을 만든다.

## 완성 목표

예를 들어 점수 3개를 입력한다고 하자.

```text
80
90
70
```

프로그램은 평균을 계산한다.

```text
(80 + 90 + 70) / 3 = 80
```

그리고 평균이 60 이상이면 통과라고 출력한다.

## 1단계: 점수 하나 받기

```python
score = int(input("점수: "))
print(score)
```

먼저 입력값 하나가 제대로 숫자로 들어오는지만 확인한다.

## 2단계: 점수 여러 개 저장하기

```python
scores = []

score1 = int(input("첫 번째 점수: "))
score2 = int(input("두 번째 점수: "))
score3 = int(input("세 번째 점수: "))

scores.append(score1)
scores.append(score2)
scores.append(score3)

print(scores)
```

여기서 `append()`는 리스트 끝에 값을 하나 추가한다.

## 3단계: 합계 구하기

```python
total = 0

for score in scores:
    total += score

print("합계:", total)
```

`total`은 처음에 0이고, 반복문이 돌 때마다 점수를 더한다.

## 4단계: 평균 구하기

```python
average = total / len(scores)
print("평균:", average)
```

`len(scores)`는 점수가 몇 개인지 알려준다.

## 5단계: 조건 붙이기

```python
if average >= 60:
    print("통과")
else:
    print("재시험")
```

평균이 60 이상이면 통과, 아니면 재시험이다.

## 6단계: 반복문으로 입력도 줄여 보기

아까는 점수 3개를 따로 입력했다.

이번에는 반복문을 써 본다.

```python
scores = []

for i in range(3):
    score = int(input("점수: "))
    scores.append(score)

print(scores)
```

`range(3)`이므로 입력을 3번 받는다.

## 7단계: 전체 코드

```python
scores = []

for i in range(3):
    score = int(input("점수: "))
    scores.append(score)

total = 0

for score in scores:
    total += score

average = total / len(scores)

print("점수:", scores)
print("합계:", total)
print("평균:", average)

if average >= 60:
    print("통과")
else:
    print("재시험")
```

## 코드가 움직이는 순서

```text
빈 리스트 만들기
→ 점수 3개 입력
→ 리스트에 저장
→ 점수 전부 더하기
→ 평균 계산
→ 60 이상인지 확인
→ 결과 출력
```

## 일부러 바꿔 볼 것

### 입력 개수를 5개로 바꾸기

```python
for i in range(5):
```

### 통과 기준을 70으로 바꾸기

```python
if average >= 70:
```

### 최고점도 출력하기

```python
print("최고점:", max(scores))
```

### 최저점도 출력하기

```python
print("최저점:", min(scores))
```

## 함수로 나누는 건 그다음

처음부터 함수로 쪼갤 필요는 없다. 전체 흐름이 이해된 뒤에 함수로 나누는 게 더 쉽다.

예:

```python
def calc_average(scores):
    total = 0
    for score in scores:
        total += score
    return total / len(scores)
```

이 함수는 점수 리스트를 받아 평균을 계산해서 돌려준다.

## 이 프로젝트에서 사용한 것

```text
input()   사용자 입력
int()     문자열을 정수로 바꾸기
list      점수 여러 개 저장
append()  리스트에 점수 추가
for       반복하기
range()   반복 횟수 만들기
len()     점수 개수 세기
if/else   조건에 따라 결과 나누기
```

작은 프로그램이라도 이런 식으로 여러 문법이 연결되기 시작하면 Python 코드 전체가 훨씬 덜 낯설어진다.
