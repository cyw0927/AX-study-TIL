# NumPy 2차원 배열 기초

2차원 배열은 표처럼 행과 열이 있는 데이터라고 생각하면 된다.

```python
import numpy as np

arr = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(arr)
```

결과:

```text
[[1 2 3]
 [4 5 6]]
```

## shape

```python
print(arr.shape)
```

결과:

```text
(2, 3)
```

행이 2개, 열이 3개라는 뜻이다.

## 값 하나 꺼내기

```python
print(arr[0, 0])
print(arr[1, 2])
```

결과:

```text
1
6
```

Python의 리스트에서는 `arr[0][0]`처럼 쓰는 경우가 많지만 NumPy 배열에서는 `arr[0, 0]`처럼도 쓸 수 있다.

## 한 행 꺼내기

```python
print(arr[0])
```

결과:

```text
[1 2 3]
```

## 한 열 꺼내기

```python
print(arr[:, 1])
```

결과:

```text
[2 5]
```

여기서 `:`는 모든 행을 뜻한다.

## 합계

```python
print(arr.sum())
```

전체 합계를 구한다.

```python
print(arr.sum(axis=0))
print(arr.sum(axis=1))
```

`axis`는 처음 보면 헷갈리기 쉽다.

초보 단계에서는 결과를 직접 출력해 보고, `axis=0`과 `axis=1`이 각각 어떻게 다른지 눈으로 확인하는 것이 가장 좋다.

2차원 배열은 나중에 이미지 데이터와 표 데이터를 이해할 때 자주 나온다.
